# Git & GitHub for DevOps Syllabus

## Git Basics

- Installation and setup
- Repository initialization (git init)
- Cloning repositories (git clone)
- Staging and committing changes (git add, git commit)
- Branching and merging (git branch, git checkout, git merge)
- Viewing history (git log, git diff)
- Resolving conflicts
- Remote repositories (git remote, git fetch, git pull, git push)
- Tags and releases
- Stashing changes (git stash)
- Cherry-pick, rebase, bisect

## GitHub Usage

- Creating repositories
- Forking and cloning
- Pull requests and code reviews
- Issues and project boards
- Actions and workflows (CI/CD)
- Managing collaborators and permissions
- GitHub Pages for documentation

## Git & GitHub in VS Code

- Installing Git and GitHub extensions
- Cloning, pushing, pulling from VS Code
- Source Control panel usage
- Branch management in VS Code
- Resolving merge conflicts visually
- Using GitHub Codespaces
- Integrating CI/CD workflows
- Viewing and managing pull requests
