## 🚀 Pro Tips from FAANG Engineers

### Tip 1: Memorize These Time Complexities
```
Bubble Sort:    O(n²) - O(n²) - O(n)
Selection Sort: O(n²) - O(n²) - O(n²)
Insertion Sort: O(n²) - O(n²) - O(n)
Merge Sort:     O(n log n) - O(n log n) - O(n log n)
Quick Sort:     O(n²) - O(n log n) - O(n log n)
```

### Tip 2: In Interviews, Default to Merge Sort
Why? Guaranteed O(n log n), easy to explain, widely known

### Tip 3: Practice Explaining While Coding
Set 5-min timer, explain merge sort out loud

### Tip 4: Know Java's Built-in Sorting
```java
Arrays.sort(primitives);  // Quick sort (not stable)
Arrays.sort(objects);     // Merge sort (stable)
Collections.sort(list);   // Merge sort (stable)
```
