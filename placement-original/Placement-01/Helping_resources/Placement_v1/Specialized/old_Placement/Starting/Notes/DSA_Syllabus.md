# SECTION 1: Core CS Subjects

## 1. Data Structures & Algorithms (DSA)

### A. Arrays & Strings

- Array declaration, initialization, memory layout
- Array operations: insertion, deletion, search, traversal
- Multi-dimensional arrays, jagged arrays
- String manipulation: concatenation, substring, replace, split, join
- Pattern matching: indexOf, contains, regex
- Character encoding: ASCII, Unicode
- Array rotation, reversal, sliding window technique
- Practice: Two Sum, Maximum Subarray, Longest Substring, Kadane’s Algorithm

### B. Linked Lists

- Types: singly, doubly, circular
- Node structure, memory allocation
- Insertion/deletion (beginning, middle, end)
- Traversal (iterative and recursive)
- Reversing a linked list (iterative and recursive)
- Detecting cycles (Floyd’s algorithm)
- Merging sorted lists, finding middle element

### C. Stacks and Queues

- Stack: LIFO, implementation (array, linked list)
- Applications: expression evaluation, parentheses matching, function call stack
- Queue: FIFO, types (simple, circular, priority, deque)
- Implementation (array, linked list)

### D. Trees

- Binary Tree: structure, traversals (inorder, preorder, postorder, level order)
- Binary Search Tree (BST): insertion, deletion, search, validation
- AVL Tree: rotations, balancing
- Segment Tree: range queries, point updates

### E. Graphs

- Representation: adjacency matrix, adjacency list
- Traversals: BFS, DFS
- Shortest Path: Dijkstra, Floyd-Warshall
- Minimum Spanning Tree: Kruskal, Prim
- Topological sorting, cycle detection

### F. Heaps & Priority Queues

- Min-heap, max-heap
- Heap operations: insert, delete, heapify
- Priority queue implementation

### G. Hashing & Hash Maps

- Hash functions, collision resolution (chaining, open addressing)
- HashMap, HashSet usage in Java

### H. Sliding Window, Two-pointer, Backtracking

- Sliding window: fixed/variable window problems
- Two-pointer: fast-slow, left-right pointer
- Backtracking: N-Queens, Sudoku, permutations

### I. Recursion & Dynamic Programming

- Recursion: base/recursive case, call stack
- DP: memoization, tabulation, 1D/2D DP, advanced DP

### J. Greedy Algorithms

- Greedy choice property, optimal substructure
- Problems: activity selection, fractional knapsack, Huffman coding

### K. Bit Manipulation

- Bitwise operators, XOR, bit masking, power of 2

### L. Time and Space Complexity (Big-O Analysis)

- Best/average/worst case analysis
- Space complexity, trade-offs

### M. Practice Platforms

- Leetcode, GeeksforGeeks, Codeforces, CodeChef
