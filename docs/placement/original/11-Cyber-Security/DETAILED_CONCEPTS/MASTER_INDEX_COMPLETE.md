## 🔬 LAB ENVIRONMENT SETUP

### Virtualization Platform
- **VMware Workstation Pro** or **VirtualBox** (free)
- **Minimum Resources:** 16GB RAM, 500GB storage

### Essential VMs

1. **Kali Linux** (Attack machine)
   - Pre-installed security tools
   - Regular updates via `apt update && apt upgrade`

2. **Metasploitable 2/3** (Vulnerable targets)
   - Practice exploitation safely

3. **Windows 10/11** (Target/Analysis)
   - Activate evaluation license
   - Install Sysmon for logging

4. **Windows Server 2019/2022** (Enterprise target)
   - Active Directory setup
   - Practice lateral movement

5. **Ubuntu Server** (Linux target)
   - LAMP stack vulnerabilities
   - Privilege escalation practice

6. **SIEM Platform**
   - Splunk (free 500MB/day license)
   - ELK Stack (open source)

7. **Malware Analysis VM**
   - Windows 10 with Cuckoo Sandbox
   - REMnux Linux distribution

### Network Configuration
```
[Internet] <-- NAT --> [pfSense Firewall] <-- Internal Network -->
    |
    +-- [Kali Linux] (192.168.10.100)
    +-- [Metasploitable] (192.168.10.101)
    +-- [Windows 10] (192.168.10.102)
    +-- [Windows Server] (192.168.10.103)
    +-- [Ubuntu Server] (192.168.10.104)
    +-- [SIEM] (192.168.10.105)
```

### Safety Practices
⚠️ **CRITICAL:**
- Always use isolated virtual networks
- Take VM snapshots before tests
- Never test on production systems
- Disconnect from internet when analyzing malware
- Follow responsible disclosure for real vulnerabilities
