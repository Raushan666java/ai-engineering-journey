# 🐧 Linux System Administration - Individual Subject Syllabus

## 📋 **SUBJECT 1: Linux Architecture**
### Duration: 1 Hour
### Topics:
- Linux Kernel Architecture
- System Calls
- User Space vs Kernel Space
- Linux Boot Process
- System Components

## 📋 **SUBJECT 2: Linux Distributions**
### Duration: 1 Hour
### Topics:
- Ubuntu/Debian Family
- RHEL/CentOS Family
- SUSE Family
- Arch Linux
- Distribution Selection

## 📋 **SUBJECT 3: File System Hierarchy**
### Duration: 2 Hours
### Topics:
- Root Directory (/)
- /bin, /sbin, /usr, /var
- /etc, /home, /tmp
- /proc, /sys filesystems
- Mount Points

## 📋 **SUBJECT 4: Command Line Interface**
### Duration: 2 Hours
### Topics:
- Terminal and Shell
- Command Structure
- Command Options
- Command History
- Tab Completion
- Man Pages

## 📋 **SUBJECT 5: File Operations**
### Duration: 2 Hours
### Topics:
- ls, cp, mv, rm
- mkdir, rmdir
- find, locate
- file, stat
- ln (links)

## 📋 **SUBJECT 6: Directory Navigation**
### Duration: 1 Hour
### Topics:
- pwd, cd commands
- Absolute vs Relative Paths
- . and .. directories
- ~ (home) shortcut
- Path Variables

## 📋 **SUBJECT 7: Text Processing**
### Duration: 3 Hours
### Topics:
- cat, less, more, head, tail
- grep (pattern matching)
- sed (stream editor)
- awk (text processing)
- sort, uniq, cut
- tr (translate)

## 📋 **SUBJECT 8: Process Management**
### Duration: 2 Hours
### Topics:
- ps (process status)
- top, htop
- kill, killall
- jobs, bg, fg
- nohup
- Process States

## 📋 **SUBJECT 9: System Monitoring**
### Duration: 2 Hours
### Topics:
- uptime, who, w
- df, du (disk usage)
- free (memory)
- iostat, vmstat
- netstat, ss
- lsof

## 📋 **SUBJECT 10: User Management**
### Duration: 2 Hours
### Topics:
- useradd, usermod, userdel
- passwd, chage
- su, sudo
- id, whoami
- /etc/passwd, /etc/shadow

## 📋 **SUBJECT 11: Permission Management**
### Duration: 2 Hours
### Topics:
- File Permissions (rwx)
- chmod (change mode)
- chown, chgrp
- umask
- Special Permissions (sticky, setuid, setgid)

## 📋 **SUBJECT 12: Network Configuration**
### Duration: 2 Hours
### Topics:
- ip command
- ifconfig (legacy)
- ping, traceroute
- wget, curl
- ssh, scp
- Network Files (/etc/hosts, /etc/resolv.conf)

## 📋 **SUBJECT 13: Package Management**
### Duration: 2 Hours
### Topics:
- APT (Debian/Ubuntu)
- YUM/DNF (RHEL/CentOS)
- Package Installation/Removal
- Repository Management
- Package Updates

## 📋 **SUBJECT 14: Service Management**
### Duration: 2 Hours
### Topics:
- systemd
- systemctl commands
- Service Status
- Enable/Disable Services
- journalctl (logs)

## 📋 **SUBJECT 15: Shell Scripting Basics**
### Duration: 2 Hours
### Topics:
- Shebang (#!)
- Variables
- Command Line Arguments
- Conditional Statements
- Loops
- Functions

## 📋 **SUBJECT 16: System Security**
### Duration: 2 Hours
### Topics:
- User Security
- File Permissions Security
- SSH Security
- Firewall Basics (ufw, iptables)
- Security Updates

## 📋 **SUBJECT 17: Performance Tuning**
### Duration: 1 Hour
### Topics:
- System Resource Monitoring
- Performance Bottlenecks
- Kernel Parameters
- System Optimization
- Resource Limits

## 📋 **SUBJECT 18: Log Management**
### Duration: 1 Hour
### Topics:
- System Logs (/var/log)
- syslog, rsyslog
- Log Rotation (logrotate)
- journalctl
- Log Analysis
