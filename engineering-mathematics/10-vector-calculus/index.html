Theory​

10.1 Scalar and Vector Fields​

Scalar Field: f:R3→Rf: \mathbb{R}^3 \to \mathbb{R}f:R3→R, assigns a scalar to each point (temperature, pressure, potential).

Vector Field: F:R3→R3\mathbf{F}: \mathbb{R}^3 \to \mathbb{R}^3F:R3→R3, assigns a vector to each point (velocity, force, electric field).

Gradient of Scalar Field: ∇f=⟨∂f∂x,∂f∂y,∂f∂z⟩\nabla f = \left\langle \frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z} \right\rangle∇f=⟨∂x∂f​,∂y∂f​,∂z∂f​⟩

Divergence of Vector Field: ∇⋅F=∂P∂x+∂Q∂y+∂R∂z\nabla \cdot \mathbf{F} = \frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z}∇⋅F=∂x∂P​+∂y∂Q​+∂z∂R​

Curl of Vector Field: ∇×F=∣ijk∂∂x∂∂y∂∂zPQR∣\nabla \times \mathbf{F} = \begin{vmatrix} \mathbf{i} & \mathbf{j} & \mathbf{k} \\ \frac{\partial}{\partial x} & \frac{\partial}{\partial y} & \frac{\partial}{\partial z} \\ P & Q & R \end{vmatrix}∇×F=​i∂x∂​P​j∂y∂​Q​k∂z∂​R​​

Laplacian: ∇2f=∇⋅(∇f)=∂2f∂x2+∂2f∂y2+∂2f∂z2\nabla^2 f = \nabla \cdot (\nabla f) = \frac{\partial^2 f}{\partial x^2} + \frac{\partial^2 f}{\partial y^2} + \frac{\partial^2 f}{\partial z^2}∇2f=∇⋅(∇f)=∂x2∂2f​+∂y2∂2f​+∂z2∂2f​

10.2 Line Integrals​

Scalar Line Integral: ∫Cf ds=∫abf(r(t))∥r′(t)∥ dt\int_C f\,ds = \int_a^b f(\mathbf{r}(t)) \|\mathbf{r}'(t)\|\,dt∫C​fds=∫ab​f(r(t))∥r′(t)∥dt

Used to integrate a scalar function along a curve (e.g., mass of a wire).

Vector Line Integral (Work): ∫CF⋅dr=∫abF(r(t))⋅r′(t) dt\int_C \mathbf{F} \cdot d\mathbf{r} = \int_a^b \mathbf{F}(\mathbf{r}(t)) \cdot \mathbf{r}'(t)\,dt∫C​F⋅dr=∫ab​F(r(t))⋅r′(t)dt

Measures the work done by force F\mathbf{F}F moving along path CCC.

Properties:

  • ∫−CF⋅dr=−∫CF⋅dr\int_{-C} \mathbf{F} \cdot d\mathbf{r} = -\int_C \mathbf{F} \cdot d\mathbf{r}∫−C​F⋅dr=−∫C​F⋅dr
  • ∫C1+C2=∫C1+∫C2\int_{C_1 + C_2} = \int_{C_1} + \int_{C_2}∫C1​+C2​​=∫C1​​+∫C2​​

10.3 Conservative Vector Fields​

A vector field F\mathbf{F}F is conservative if F=∇ϕ\mathbf{F} = \nabla \phiF=∇ϕ for some scalar potential ϕ\phiϕ.

Equivalent Conditions:

  1. ∇×F=0\nabla \times \mathbf{F} = 0∇×F=0 (in simply connected domain)
  2. ∮CF⋅dr=0\oint_C \mathbf{F} \cdot d\mathbf{r} = 0∮C​F⋅dr=0 for any closed curve CCC
  3. Path independence: ∫C1F⋅dr=∫C2F⋅dr\int_{C_1} \mathbf{F} \cdot d\mathbf{r} = \int_{C_2} \mathbf{F} \cdot d\mathbf{r}∫C1​​F⋅dr=∫C2​​F⋅dr for any paths with same endpoints
  4. F=∇ϕ\mathbf{F} = \nabla \phiF=∇ϕ for some ϕ\phiϕ

Finding the Potential: Integrate ∇ϕ=F\nabla \phi = \mathbf{F}∇ϕ=F component by component.

10.5 Green's Theorem​

For a positively oriented, piecewise smooth simple closed curve CCC in R2\mathbb{R}^2R2:

∮CF⋅dr=∬D(∂Q∂x−∂P∂y) dA\oint_C \mathbf{F} \cdot d\mathbf{r} = \iint_D \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)\,dA∮C​F⋅dr=∬D​(∂x∂Q​−∂y∂P​)dA

where F=⟨P,Q⟩\mathbf{F} = \langle P, Q \rangleF=⟨P,Q⟩ and DDD is the region enclosed by CCC.

Area Formula: A=12∮Cx dy−y dxA = \frac{1}{2}\oint_C x\,dy - y\,dxA=21​∮C​xdy−ydx

Divergence Form (2D): ∮CF⋅n ds=∬D∇⋅F dA\oint_C \mathbf{F} \cdot \mathbf{n}\,ds = \iint_D \nabla \cdot \mathbf{F}\,dA∮C​F⋅nds=∬D​∇⋅FdA

10.6 Stokes' Theorem​

∮CF⋅dr=∬S(∇×F)⋅dS\oint_C \mathbf{F} \cdot d\mathbf{r} = \iint_S (\nabla \times \mathbf{F}) \cdot d\mathbf{S}∮C​F⋅dr=∬S​(∇×F)⋅dS

The line integral around a closed curve CCC equals the flux of curl through any surface SSS bounded by CCC.

Physical Interpretation: The circulation of F\mathbf{F}F around CCC equals the total "rotation" (curl) passing through SSS.

Curl-Free Fields: If ∇×F=0\nabla \times \mathbf{F} = 0∇×F=0, then F\mathbf{F}F is conservative.

10.7 Divergence Theorem (Gauss's Theorem)​

∬SF⋅dS=∭E(∇⋅F) dV\iint_S \mathbf{F} \cdot d\mathbf{S} = \iiint_E (\nabla \cdot \mathbf{F})\,dV∬S​F⋅dS=∭E​(∇⋅F)dV

The net outward flux of F\mathbf{F}F through closed surface SSS equals the triple integral of divergence inside the volume EEE.

Physical Interpretation: Net outflow = total sources inside minus total sinks inside.

Conservation Laws: If ∇⋅F=0\nabla \cdot \mathbf{F} = 0∇⋅F=0 (divergence-free), then net flux through any closed surface is zero ? incompressible flow.

function gradient(f: (x: number, y: number, z: number) => number,
                  p: Vector3, h: number = 1e-5): Vector3 {
  const [x, y, z] = p;
  return [
    (f(x + h, y, z) - f(x - h, y, z)) / (2 * h),
    (f(x, y + h, z) - f(x, y - h, z)) / (2 * h),
    (f(x, y, z + h) - f(x, y, z - h)) / (2 * h),
  ];
}

function divergence(F: (p: Vector3) => Vector3,
                    p: Vector3, h: number = 1e-5): number {
  const [x, y, z] = p;
  const Fval = F(p);
  // Numerical divergence using central differences
  const dFdx = (F([x + h, y, z])[0] - F([x - h, y, z])[0]) / (2 * h);
  const dFdy = (F([x, y + h, z])[1] - F([x, y - h, z])[1]) / (2 * h);
  const dFdz = (F([x, y, z + h])[2] - F([x, y, z - h])[2]) / (2 * h);
  return dFdx + dFdy + dFdz;
}

Real-World Application: Computational Fluid Dynamics​

Vector calculus is the mathematical foundation of computational fluid dynamics (CFD), used to simulate airflow over aircraft, blood flow in arteries, and weather patterns.

The Navier-Stokes Equations in Vector Form:

ρ(∂v∂t+v⋅∇v)=−∇p+μ∇2v+ρg\rho\left(\frac{\partial \mathbf{v}}{\partial t} + \mathbf{v} \cdot \nabla \mathbf{v}\right) = -\nabla p + \mu \nabla^2 \mathbf{v} + \rho \mathbf{g}ρ(∂t∂v​+v⋅∇v)=−∇p+μ∇2v+ρg

Key Vector Calculus Operations in CFD:

  • Gradient ∇p\nabla p∇p: Pressure gradient drives fluid flow from high to low pressure
  • Laplacian ∇2v\nabla^2 \mathbf{v}∇2v: Viscous diffusion smooths velocity gradients
  • Divergence ∇⋅v\nabla \cdot \mathbf{v}∇⋅v: For incompressible flow, ∇⋅v=0\nabla \cdot \mathbf{v} = 0∇⋅v=0 (continuity)
  • Curl ∇×v\nabla \times \mathbf{v}∇×v: Vorticity measures local rotation of fluid elements

Vorticity-Streamfunction Formulation: For 2D incompressible flow, define vorticity ω=∇×v\omega = \nabla \times \mathbf{v}ω=∇×v (scalar in 2D) and streamfunction ψ\psiψ such that v=∇⊥ψ=⟨−∂ψ/∂y,∂ψ/∂x⟩\mathbf{v} = \nabla^\perp \psi = \langle -\partial \psi/\partial y, \partial \psi/\partial x \ranglev=∇⊥ψ=⟨−∂ψ/∂y,∂ψ/∂x⟩. The Navier-Stokes equations become:

∂ω∂t+v⋅∇ω=ν∇2ω,∇2ψ=−ω\frac{\partial \omega}{\partial t} + \mathbf{v} \cdot \nabla \omega = \nu \nabla^2 \omega, \quad \nabla^2 \psi = -\omega∂t∂ω​+v⋅∇ω=ν∇2ω,∇2ψ=−ω

This eliminates pressure and automatically satisfies incompressibility.

Finite Element Methods: PDEs are discretized using basis functions ϕi(x,y)\phi_i(x,y)ϕi​(x,y). The weak form uses integration by parts (divergence theorem) to reduce continuity requirements:

type Vector3 = [number, number, number];

function curl(
  F: (p: Vector3) => Vector3,
  p: Vector3,
  h: number = 1e-5
): Vector3 {
  const [x, y, z] = p;
  // dFz/dy - dFy/dz
  const curlX = (F([x, y+h, z])[2] - F([x, y-h, z])[2]) / (2*h)
              - (F([x, y, z+h])[1] - F([x, y, z-h])[1]) / (2*h);
  // dFx/dz - dFz/dx
  const curlY = (F([x, y, z+h])[0] - F([x, y, z-h])[0]) / (2*h)
              - (F([x+h, y, z])[2] - F([x-h, y, z])[2]) / (2*h);
  // dFy/dx - dFx/dy
  const curlZ = (F([x+h, y, z])[1] - F([x-h, y, z])[1]) / (2*h)
              - (F([x, y+h, z])[0] - F([x, y-h, z])[0]) / (2*h);
  return [curlX, curlY, curlZ];
}

Example 7: Line Integral Computation​

type ParametricCurve = (t: number) => Vector3;

function lineIntegral(
  F: (p: Vector3) => Vector3,
  curve: ParametricCurve,
  tStart: number,
  tEnd: number,
  steps: number = 1000
): number {
  const dt = (tEnd - tStart) / steps;
  let integral = 0;
  for (let i = 0; i < steps; i++) {
    const t = tStart + i * dt;
    const p = curve(t);
    // Numerical derivative of curve
    const pNext = curve(t + dt);
    const dr: Vector3 = [
      pNext[0] - p[0],
      pNext[1] - p[1],
      pNext[2] - p[2],
    ];
    const field = F(p);
    // Dot product F ? dr
    integral += field[0] * dr[0] + field[1] * dr[1] + field[2] * dr[2];
  }
  return integral;
}

// F(x,y) = [y, x], curve: unit circle from t=0 to t=pi/2
const F1 = (p: Vector3): Vector3 => [p[1], p[0], 0];
const circle = (t: number): Vector3 => [Math.cos(t), Math.sin(t), 0];
const work = lineIntegral(F1, circle, 0, Math.PI / 2);
console.log(`Work along quarter-circle: ${work.toFixed(6)}`); // ? 0

Example 6: Conservation Laws and Divergence-Free Fields​

Show that F=⟨y2,x2,0⟩\mathbf{F} = \langle y^2, x^2, 0 \rangleF=⟨y2,x2,0⟩ is not divergence-free.

Solution: ∇⋅F=∂(y2)∂x+∂(x2)∂y+∂(0)∂z=0+0+0=0\nabla \cdot \mathbf{F} = \frac{\partial(y^2)}{\partial x} + \frac{\partial(x^2)}{\partial y} + \frac{\partial(0)}{\partial z} = 0 + 0 + 0 = 0∇⋅F=∂x∂(y2)​+∂y∂(x2)​+∂z∂(0)​=0+0+0=0

This field IS divergence-free! This means the net flux through any closed surface is zero, representing an incompressible flow in 2D.

Physical interpretation: A divergence-free vector field represents a source-free flow ? whatever flows into a region must flow out. This is the mathematical basis of incompressible fluid dynamics and conservation of mass.

TypeScript: Parametrized Surface Area​

type SurfaceParam = (u: number, v: number) => [number, number, number];

function cross(a: number[], b: number[]): number[] {
  return [
    a[1] * b[2] - a[2] * b[1],
    a[2] * b[0] - a[0] * b[2],
    a[0] * b[1] - a[1] * b[0],
  ];
}

function magnitude(v: number[]): number {
  return Math.sqrt(v[0] ** 2 + v[1] ** 2 + v[2] ** 2);
}

function surfaceArea(
  r: SurfaceParam,
  uRange: [number, number],
  vRange: [number, number],
  nu: number,
  nv: number
): number {
  const du = (uRange[1] - uRange[0]) / nu;
  const dv = (vRange[1] - vRange[0]) / nv;
  let area = 0;

  for (let i = 0; i < nu; i++) {
    for (let j = 0; j < nv; j++) {
      const u = uRange[0] + i * du;
      const v = vRange[0] + j * dv;

      const rU = derivativeU(r, u, v, 1e-5);
      const rV = derivativeV(r, u, v, 1e-5);
      const dS = magnitude(cross(rU, rV));

      area += dS * du * dv;
    }
  }
  return area;
}

function derivativeU(r: SurfaceParam, u: number, v: number, h: number): number[] {
  const p1 = r(u + h, v);
  const p2 = r(u - h, v);
  return [(p1[0] - p2[0]) / (2 * h), (p1[1] - p2[1]) / (2 * h), (p1[2] - p2[2]) / (2 * h)];
}

function derivativeV(r: SurfaceParam, u: number, v: number, h: number): number[] {
  const p1 = r(u, v + h);
  const p2 = r(u, v - h);
  return [(p1[0] - p2[0]) / (2 * h), (p1[1] - p2[1]) / (2 * h), (p1[2] - p2[2]) / (2 * h)];
}

// Surface area of a sphere of radius R
// Parametrization: r(u,v) = (R sin u cos v, R sin u sin v, R cos u)
const sphere: SurfaceParam = (u, v) => [
  2 * Math.sin(u) * Math.cos(v),
  2 * Math.sin(u) * Math.sin(v),
  2 * Math.cos(u),
];

const sphereArea = surfaceArea(sphere, [0, Math.PI], [0, 2 * Math.PI], 40, 60);
console.log(`Sphere (R=2) surface area ? ${sphereArea.toFixed(4)} (expected: ${(4 * Math.PI * 4).toFixed(4)})`);

function tripleIntegral(
  integrand: (x: number, y: number, z: number) => number,
  xRange: [number, number],
  yRange: [number, number],
  zRange: [number, number],
  nx: number,
  ny: number,
  nz: number
): number {
  const dx = (xRange[1] - xRange[0]) / nx;
  const dy = (yRange[1] - yRange[0]) / ny;
  const dz = (zRange[1] - zRange[0]) / nz;
  let sum = 0;

  for (let i = 0; i < nx; i++) {
    for (let j = 0; j < ny; j++) {
      for (let k = 0; k < nz; k++) {
        const x = xRange[0] + (i + 0.5) * dx;
        const y = yRange[0] + (j + 0.5) * dy;
        const z = zRange[0] + (k + 0.5) * dz;
        sum += integrand(x, y, z) * dx * dy * dz;
      }
    }
  }
  return sum;
}
