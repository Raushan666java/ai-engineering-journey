# Day 50 Notes: Backtracking

## Overview
Day 50 focuses on backtracking problems and optimization techniques such as pruning, ordering, and bitmask optimizations for N-Queens.

## Key Patterns
- State-space exploration via recursion
- Pruning with bounding conditions and ordering choices
- Using bitmasks for N-Queens (fast solution counting)
- Translate backtracking to iterative when needed to avoid deep recursion

## Test Strategy
- Exhaustive tests for small inputs and randomized pruning tests
- Validate correctness by comparing to brute-force outputs for small n
