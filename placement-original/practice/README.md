## 🎯 Practice Guidelines

### Daily Practice Routine
1. **Morning (2-3 hours):** DSA Problems
   - 2 Easy problems (Beginner)
   - 1 Medium + 1 Easy (Intermediate)
   - 1 Medium + 1 Hard (Advanced)

2. **Afternoon (1-2 hours):** Core Subjects
   - Java/DBMS/OS/CN concepts
   - Practice questions

3. **Evening (30-60 mins):** Review & System Design

### Problem Naming Convention
- Format: `{difficulty}_{topic}_{problem_name}.java`
- Example: `Easy_Array_TwoSum.java`
- Difficulty: Easy, Medium, Hard

### Question Categories
- **Easy:** Foundation building, basic concepts
- **Medium:** Interview standard, pattern recognition
- **Hard:** Advanced problem-solving, optimization

## 📊 Progress Tracking
- Mark completed questions with ✅
- Track time taken for each problem
- Note down alternate solutions
- Review difficult problems weekly
