# Textbook Template

Every chapter across all courses follows this exact university textbook format:

---

## Learning Objectives

- Bullet list of 4-6 concrete, measurable objectives for this chapter
- What the student will be able to DO after studying

---

## Theory

### [Section 1 Title]
Detailed explanation with definitions, mathematical notation where relevant, and conceptual diagrams described in words.

### [Section 2 Title]
Progressive build-up of concepts. Each section introduces ONE new idea, explains it thoroughly, then connects it to previously learned material.

---

## Examples

### Example 1: [Descriptive Title]
Walk through a complete, realistic example with:
- Step-by-step explanation
- Code snippets (in fenced code blocks with language)
- Expected output
- What the example demonstrates

### Example 2: [Descriptive Title]
Second worked example that builds on the first, showing a variation or extension.

---

## Summary

- 5-8 bullet points recapping all key concepts from the chapter
- Each bullet = one complete takeaway, not a fragment

---

## Exercises

### Review Questions (4-5)
Short-answer questions testing conceptual understanding.

### Application Problems (3-4)
Medium-difficulty problems requiring the student to apply concepts.

### Challenge Problem (1)
Harder problem that may combine multiple concepts or require creative thinking.
