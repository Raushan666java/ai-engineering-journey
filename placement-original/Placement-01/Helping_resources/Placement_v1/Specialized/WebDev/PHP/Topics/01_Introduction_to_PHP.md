# 1. Introduction to PHP

## What is PHP?
- PHP stands for "PHP: Hypertext Preprocessor" (recursive acronym)
- Server-side scripting language designed for web development
- Embedded in HTML and used to create dynamic web pages
- Platform-independent: runs on Windows, Linux, macOS
- PHP files have the `.php` extension and are executed on the server

## History and Evolution
- Created by Rasmus Lerdorf in 1994
- Originally a set of Common Gateway Interface (CGI) binaries
- Major versions evolution: PHP 3, 4, 5, 7, and 8
- PHP 8.x introduces JIT compilation, attributes, union types

## PHP in Web Development
- Powers over 75% of websites with known server-side language
- Foundation for popular CMS like WordPress, Drupal, Joomla
- Commonly used for web forms, content management, database interaction
- Supports procedural and object-oriented programming paradigms

## Setting Up Development Environment
- Local development options:
  - XAMPP (cross-platform Apache, MySQL, PHP, Pearl)
  - WAMP (Windows, Apache, MySQL, PHP)
  - MAMP (Mac, Apache, MySQL, PHP)
  - Docker-based PHP environments
- PHP configuration via php.ini
- Development tools: VS Code, PhpStorm, Sublime Text

## PHP Basics
- PHP tags: `<?php ?>` and short tags `<?= ?>`
- Echo and print statements
- Variables and data types
- Basic syntax and operators
- Including external files

## PHP Coding Standards
- PSR standards (PHP Standard Recommendations)
- PSR-1: Basic Coding Standard
- PSR-12: Extended Coding Style
- PSR-4: Autoloading Standard

## Best Learning Methods
- Set up a local server (XAMPP, WAMP, LAMP)
- Write and run simple PHP scripts
- Build small projects (contact form, calculator, etc.)
- Follow structured tutorials
- Explore official documentation: https://www.php.net/manual/en/
- Interactive learning: PHP exercises and challenges
