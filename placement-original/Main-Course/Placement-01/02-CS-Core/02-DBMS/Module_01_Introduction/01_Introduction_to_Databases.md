# Module 1: Introduction to Databases

## What is a Database?
A database is an organized collection of structured information stored electronically in a computer system.

## Key Concepts
- **Data**: Raw facts and figures
- **Information**: Processed data with meaning
- **Database**: Collection of related data
- **DBMS**: Software to manage databases

## Types of Data
1. **Structured Data**: Organized in tables (SQL databases)
2. **Semi-structured Data**: JSON, XML
3. **Unstructured Data**: Images, videos, text

## Database vs File System
| Database | File System |
|----------|-------------|
| Data integrity | Data redundancy |
| Concurrent access | Limited sharing |
| Security features | Basic security |
| Query capabilities | No query language |

## DBMS Components
1. **Hardware**: Physical storage
2. **Software**: DBMS software
3. **Data**: Actual information
4. **Procedures**: Rules and instructions
5. **Users**: Database administrators, developers, end-users

## Popular DBMS
- **Relational**: MySQL, PostgreSQL, Oracle, SQL Server
- **NoSQL**: MongoDB, Cassandra, Redis
- **NewSQL**: CockroachDB, VoltDB
