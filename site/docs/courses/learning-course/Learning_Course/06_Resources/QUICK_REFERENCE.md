# ⚡ Quick Reference Guide

## Learning Techniques Cheat Sheet

### Memory
- **Spaced Repetition:** Review at 1, 3, 7, 21, 60 days
- **Active Recall:** Test yourself, don't re-read
- **Memory Palace:** Link information to familiar locations
- **Chunking:** Group related information

### Study Methods
- **Feynman:** Explain simply, identify gaps, review
- **SQ3R:** Survey, Question, Read, Recite, Review
- **Cornell Notes:** Notes | Cues | Summary
- **Pomodoro:** 25min work + 5min break

### Time Management
- **Time Blocking:** Assign specific times to tasks
- **Eisenhower Matrix:** Urgent/Important quadrants
- **2-Minute Rule:** Do it now if takes <2 minutes
- **Batch Processing:** Group similar tasks

### Mindset
- **Growth Mindset:** "I can learn this"
- **Process Focus:** Effort over outcome
- **Failure Reframe:** Learning opportunity
- **Small Wins:** Celebrate progress

## Emergency Learning Kit

### When Overwhelmed
1. Break task into 2-minute chunks
2. Use Pomodoro technique
3. Focus on one thing at a time
4. Take breaks to activate diffuse mode

### When Stuck
1. Use Feynman technique
2. Explain to someone else
3. Take a walk (diffuse mode)
4. Try different approach

### When Forgetting
1. Increase active recall
2. Shorten review intervals
3. Create stronger associations
4. Use multiple senses

### When Procrastinating
1. Start with easiest part
2. Set 10-minute timer
3. Remove distractions
4. Use implementation intentions
