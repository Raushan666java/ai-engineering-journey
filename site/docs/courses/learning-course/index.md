# Learning Course - AI-Enhanced Learning System

> **Mission:** Learn to learn 3x-5x faster with an AI partnership model — instant feedback, personalized content, and a complete AI-enhanced learning system.

## What Makes This Course Different

**Traditional Learning:** Human-only methods, slow feedback, generic content
**AI-Enhanced Learning:** AI partnership, instant feedback, personalized content

## Course Structure

| Phase | Folder | Focus |
|-------|--------|-------|
| Setup | 01_AI_Setup | AI tools setup (30 min) |
| Basics | 02_AI_Learning_Basics | Learning science + AI learning methods |
| Advanced | 03_Advanced_AI_Learning | Prompt engineering, advanced techniques |
| Mastery | 04_AI_System_Mastery | Personal AI learning systems |
| Practice | 05_AI_Practice | Daily AI exercises |

## How to Use

1. Start with [AI Setup](01_AI_Setup/AI_Tools_Setup.md) — 30 minutes
2. Complete [AI Learning Basics](02_AI_Learning_Basics/Learning_Science.md) — Week 1
3. Practice daily with [Daily AI Exercises](05_AI_Practice/Daily_AI_Exercises.md)
4. Advance through [Prompt Engineering](03_Advanced_AI_Learning/Prompt_Engineering.md)

## Learning Paths

### AI Beginner — Learn to learn 3x faster with AI assistance
**Time:** 30 min setup + 1 hour/day

### AI Intermediate — Master advanced AI learning for 5x acceleration
**Time:** 1 hour setup + 1.5 hours/day

### AI Advanced — Build a full personal AI learning system
**Time:** 2 hours setup + 2 hours/day
