# AI/ML Complete Course

16-week course from Python basics to AI/ML deployment.

## Structure

**Phase 1: Python (Weeks 1-4)**
- Week 1: Python Basics
- Week 2: Advanced Python  
- Week 3: NumPy
- Week 4: Pandas

**Phase 2: ML (Weeks 5-8)**
- Week 5: ML Introduction
- Week 6: Regression
- Week 7: Classification
- Week 8: Unsupervised

**Phase 3: Deep Learning (Weeks 9-12)**
- Week 9: Neural Networks
- Week 10: TensorFlow
- Week 11: CNNs
- Week 12: RNNs

**Phase 4: Advanced (Weeks 13-16)**
- Week 13: NLP
- Week 14: Computer Vision
- Week 15: MLOps
- Week 16: Capstone

## Setup
1. Install Python 3.9+
2. `pip install -r 07-Tools-Setup/requirements.txt`
3. Start Week 1

## Materials
Each week: Lectures, Labs, Assignments, Projects

**Time:** 20 hours/week
