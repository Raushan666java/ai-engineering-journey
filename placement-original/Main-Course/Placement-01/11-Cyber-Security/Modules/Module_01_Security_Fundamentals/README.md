## 📝 Key Takeaways

### CIA Triad
- **Confidentiality:** Protecting sensitive data from unauthorized access
- **Integrity:** Ensuring data accuracy and preventing tampering
- **Availability:** Ensuring systems and data are accessible when needed

### Security Principles
- **Defense in Depth:** Multiple layers of security
- **Least Privilege:** Minimum necessary access
- **Separation of Duties:** No single point of control
- **Fail Secure:** Fail in a secure state

### Common Threat Actors
- Nation-State Actors (APT groups)
- Cybercriminals (financial motivation)
- Hacktivists (political/social causes)
- Script Kiddies (low-skill attackers)
- Insider Threats (malicious employees)
