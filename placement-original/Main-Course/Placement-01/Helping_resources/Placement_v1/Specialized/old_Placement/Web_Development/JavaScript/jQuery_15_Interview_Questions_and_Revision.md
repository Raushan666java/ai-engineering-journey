# 15. jQuery Interview Questions & Revision Notes

## Revision Notes
- jQuery is a fast, small JavaScript library for DOM manipulation, event handling, AJAX, and effects.
- Use `$()` to select elements, chain methods for efficiency.
- Supports cross-browser compatibility and plugin development.
- AJAX methods: `$.ajax()`, `$.get()`, `$.post()`.
- Event handling: `.on()`, `.off()`, `.click()`, `.hover()`.
- Animations: `.hide()`, `.show()`, `.fadeIn()`, `.slideToggle()`, `.animate()`.
- Utilities: `.each()`, `.map()`, `.extend()`, `.data()`.
- Best practices: Use event delegation, cache selectors, avoid global scope pollution, and ensure accessibility.
