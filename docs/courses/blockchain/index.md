# Blockchain Technology: A Comprehensive University Textbook

## Course Overview
This course provides a rigorous, university-level introduction to blockchain technology. We move from the mathematical and cryptographic foundations to the architectures of leading networks like Bitcoin and Ethereum, eventually exploring decentralized finance and enterprise applications.
