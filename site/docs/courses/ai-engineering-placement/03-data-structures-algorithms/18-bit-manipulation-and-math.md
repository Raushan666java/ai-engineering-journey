## Revision Notes

- & = AND, | = OR, ^ = XOR, ~ = NOT
- << = multiply by 2, >> = divide by 2
- XOR: a ^ a = 0, a ^ 0 = a
- n & (n-1) clears lowest set bit
- Used for subset enumeration and optimization
