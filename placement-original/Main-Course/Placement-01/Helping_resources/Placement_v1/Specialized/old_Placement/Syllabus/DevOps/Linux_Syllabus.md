# Linux for DevOps Syllabus

- Linux basics: distributions, installation, package management
- File system structure: directories, files, permissions
- Essential commands: ls, cd, pwd, cp, mv, rm, mkdir, rmdir, touch, cat, less, head, tail, grep, find, chmod, chown
- Process management: ps, top, kill, nice, jobs, bg, fg
- Networking: ifconfig/ip, ping, netstat, ssh, scp, curl, wget
- Disk management: df, du, mount, umount, fdisk
- Scripting: bash basics, variables, loops, conditionals, functions
- System monitoring: uptime, free, vmstat, iostat, dmesg, journalctl
- User and group management: useradd, usermod, passwd, groupadd
- Service management: systemctl, service
- Log files: /var/log, log rotation
- Security: firewalls (ufw, iptables), SELinux/AppArmor basics
- Automation: cron, at
