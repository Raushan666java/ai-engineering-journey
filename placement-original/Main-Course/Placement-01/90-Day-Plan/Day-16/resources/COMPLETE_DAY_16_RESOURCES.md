## 📖 CODE TEMPLATES (MEMORIZE THESE)

### Template 1: Standard Binary Search (Most Common)
```java
public int binarySearch(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    
    while (left <= right) {  // Note: <=
        int mid = left + (right - left) / 2;  // Avoid overflow
        
        if (nums[mid] == target) {
            return mid;
        } else if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    
    return -1;  // Not found
}
```

### Template 2: Find Lower Bound (Left-most occurrence)
```java
public int lowerBound(int[] nums, int target) {
    int left = 0, right = nums.length;
    
    while (left < right) {  // Note: <
        int mid = left + (right - left) / 2;
        
        if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid;  // Don't exclude mid
        }
    }
    
    return left;
}
```

### Template 3: Find Upper Bound (Right-most occurrence)
```java
public int upperBound(int[] nums, int target) {
    int left = 0, right = nums.length;
    
    while (left < right) {
        int mid = left + (right - left) / 2;
        
        if (nums[mid] <= target) {  // Note: <=
            left = mid + 1;
        } else {
            right = mid;
        }
    }
    
    return left - 1;
}
```

### Template 4: Binary Search on Answer (IMPORTANT!)
```java
public int binarySearchOnAnswer(int[] nums, int condition) {
    int left = MIN_POSSIBLE;
    int right = MAX_POSSIBLE;
    int answer = -1;
    
    while (left <= right) {
        int mid = left + (right - left) / 2;
        
        if (isPossible(nums, mid, condition)) {
            answer = mid;
            right = mid - 1;  // Try to minimize (or left = mid + 1 to maximize)
        } else {
            left = mid + 1;
        }
    }
    
    return answer;
}

}
```

**Example: Koko Eating Bananas**
```java
public int minEatingSpeed(int[] piles, int h) {
    int left = 1;  // Min speed
    int right = Arrays.stream(piles).max().getAsInt();  // Max speed
    
    while (left < right) {
        int mid = left + (right - left) / 2;
        
        if (canFinish(piles, mid, h)) {
            right = mid;  // Try slower speed
        } else {
            left = mid + 1;  // Need faster speed
        }
    }
    
    return left;
}

private boolean canFinish(int[] piles, int speed, int h) {
    int hours = 0;
    for (int pile : piles) {
        hours += (pile + speed - 1) / speed;  // Ceiling division
    }
    return hours <= h;
}
```

## 🏆 INTERVIEW QUESTIONS (PREPARE ANSWERS)

### Conceptual (MUST KNOW)

1. **Explain binary search in 1 minute**
   - *Answer: Divide search space in half repeatedly. Compare middle element with target. If equal, found. If target is smaller, search left half. If larger, search right half. Time: O(log n).*

2. **Why is it O(log n)?**
   - *Answer: Each iteration reduces search space by half. To reduce n to 1, we need log₂(n) divisions. Example: 1000 elements → 10 comparisons max (2^10 = 1024).*

3. **When can you use binary search?**
   - *Answer: Array must be sorted (or monotonic property exists). Need random access (arrays, not linked lists).*

4. **Why mid = left + (right - left) / 2?**
   - *Answer: Prevents integer overflow. (left + right) / 2 can overflow if left + right > INT_MAX.*

5. **Difference between left <= right and left < right?**
   - *Answer: left <= right for finding exact match. left < right for finding boundaries/bounds.*

6. **What is "Binary Search on Answer"?**
   - *Answer: When answer space is sorted, use BS to find optimal answer. Example: Koko bananas - speed range is sorted, find minimum speed.*

7. **How to handle duplicates in binary search?**
   - *Answer: Use lower bound for first occurrence, upper bound for last occurrence.*

### Coding Patterns

**Pattern 1**: Find element in sorted array → Template 1
**Pattern 2**: Find first/last occurrence → Template 2 & 3
**Pattern 3**: Rotated sorted array → Modified BS with two halves
**Pattern 4**: 2D matrix → Convert to 1D index
**Pattern 5**: Binary search on answer → Template 4
**Pattern 6**: Peak element → BS on unsorted (monotonic property)

## 📊 WHEN TO USE BINARY SEARCH

### ✅ Use Binary Search When:
1. Array/list is sorted
2. Need O(log n) time complexity
3. Searching for element or position
4. **Answer space is monotonic** (KEY!)
5. Have random access to elements

### ❌ Don't Use Binary Search When:
1. Array is unsorted (unless searching for peak)
2. Linked list (no random access)
3. Need to find ALL occurrences (use linear)
4. Small dataset (< 10 elements, linear is fine)

### 🔥 Hidden Binary Search Problems
Some problems don't look like BS but ARE:
- Sqrt(x)
- Koko Eating Bananas
- Capacity to Ship Packages
- Minimum Days to Make Bouquets
- Aggressive Cows (Classic!)

**KEY IDENTIFIER**: "Find minimum/maximum value such that condition is satisfied"

## 💡 PRO TIPS FROM FAANG ENGINEERS

### Tip 1: Master the Rotated Array Pattern
Problems #33, #81, #153, #154 are ALL variations. Learn the pattern once, apply everywhere.

**Pattern**: 
- Find which half is sorted
- Check if target is in sorted half
- If yes, search there; else search other half

### Tip 2: Practice "Binary Search on Answer"
This is where 70% of students fail! 

**Questions to ask:**
1. What is the search space? (min to max)
2. Is it monotonic? (if x works, does x+1 work? or vice versa)
3. How to check if a value works? (write isPossible function)

### Tip 3: Draw the Array
In interviews, ALWAYS draw the array and pointers on whiteboard/paper.
```
[1, 2, 3, 4, 5, 6, 7]
 L        M        R
```

### Tip 4: Memorize These Numbers
```
2^10 = 1024  (10 comparisons for ~1000 items)
2^20 = 1M    (20 comparisons for 1 million items)
2^30 = 1B    (30 comparisons for 1 billion items)
```
This shows the POWER of binary search!

### Tip 5: Common Mistakes to Avoid
```java
// ❌ WRONG: Can overflow
int mid = (left + right) / 2;

// ✅ CORRECT: Safe from overflow
int mid = left + (right - left) / 2;

// ❌ WRONG: Infinite loop possible
while (left < right) {
    int mid = (left + right) / 2;
    left = mid;  // Can cause infinite loop!
}

// ✅ CORRECT: Use left = mid + 1
```
