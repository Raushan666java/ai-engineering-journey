# Cloud Computing — Comprehensive Course Textbook

**Course Code:** CLOUD-401
**Level:** Undergraduate / Graduate
**Duration:** 16 Weeks
**Prerequisites:** Operating Systems, Computer Networks, Basic Linux Administration

## Course Description

This course provides a comprehensive study of cloud computing, covering foundational concepts through advanced architectural patterns across the three major cloud providers: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). Students will gain theoretical understanding and practical exposure to compute, storage, database, networking, security, serverless, containerization, monitoring, and multi-cloud strategies. The course culminates in a capstone project requiring students to design and deploy a three-tier web application using infrastructure as code.

## Learning Outcomes

Upon completion of this course, students will be able to:

1. Explain the essential characteristics, service models, and deployment models of cloud computing.
2. Differentiate between hypervisor types and understand the role of virtualization in cloud infrastructure.
3. Deploy and manage compute resources using EC2, Azure VMs, and Compute Engine.
4. Implement scalable storage solutions using S3, Blob Storage, and Cloud Storage.
5. Design database architectures using RDS, DynamoDB, Azure SQL, Cloud SQL, and BigQuery.
6. Construct secure and scalable network topologies using VPCs, load balancers, and DNS services.
7. Enforce identity and access management policies using IAM, Azure AD, and GCP IAM.
8. Build serverless applications using Lambda, Azure Functions, and Cloud Functions.
9. Deploy containerized workloads using ECS, EKS, AKS, and GKE.
10. Implement monitoring, logging, and cost optimization strategies.
11. Apply architectural best practices using the Well-Architected Framework.
12. Design multi-cloud and hybrid architectures using cloud-agnostic tooling.

## How to Use This Textbook

Each chapter is structured to progress from theoretical foundations to practical application. Learning Objectives define the competencies to be mastered. The Theory section presents core concepts with architectural context. Examples provide concrete CLI commands, configuration snippets, and architectural walkthroughs. Summaries recapitulate key points. Exercises are tiered: Review Questions test recall, Application Problems require synthesis and analysis, and Challenge Problems demand multi-step problem solving.

## Cloud Provider Access

Students require an AWS account (free tier eligible), an Azure subscription (student subscription available), and a GCP account (free tier with $300 credit). All three platforms offer substantial free tiers sufficient to complete the exercises in this course.
