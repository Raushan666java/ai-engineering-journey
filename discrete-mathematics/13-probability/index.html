Theory​

13.1 Sample Space and Events​

The sample space SSS is the set of all possible outcomes of an experiment. An event is a subset E⊆SE \subseteq SE⊆S.

If all outcomes are equally likely, the probability of event EEE is: P(E)=∣E∣∣S∣P(E) = \frac{|E|}{|S|}P(E)=∣S∣∣E∣​

Operations on events:

  • E∪FE \cup FE∪F: at least one occurs.
  • E∩FE \cap FE∩F: both occur.
  • E′E'E′ (or E‾\overline{E}E): EEE does not occur.
  • EEE and FFF are mutually exclusive (disjoint) if E∩F=∅E \cap F = \emptysetE∩F=∅.

One-Sentence Takeaway: The sample space contains all possible outcomes; events are subsets, and for equally likely outcomes, probability is the size ratio.

13.2 Axioms of Probability​

Kolmogorov's axioms:

  1. 0≤P(E)≤10 \leq P(E) \leq 10≤P(E)≤1 for any event EEE.
  2. P(S)=1P(S) = 1P(S)=1.
  3. If E1,E2,…E_1, E_2, \dotsE1​,E2​,… are pairwise disjoint, then P(⋃iEi)=∑iP(Ei)P(\bigcup_i E_i) = \sum_i P(E_i)P(⋃i​Ei​)=∑i​P(Ei​) (countable additivity).

Theorem 13.1 (Basic rules).

  • P(∅)=0P(\emptyset) = 0P(∅)=0.
  • P(E′)=1−P(E)P(E') = 1 - P(E)P(E′)=1−P(E) (complement rule).
  • If E⊆FE \subseteq FE⊆F, then P(E)≤P(F)P(E) \leq P(F)P(E)≤P(F).
  • P(E∪F)=P(E)+P(F)−P(E∩F)P(E \cup F) = P(E) + P(F) - P(E \cap F)P(E∪F)=P(E)+P(F)−P(E∩F) (addition rule).
  • 0≤P(E)≤10 \leq P(E) \leq 10≤P(E)≤1.

One-Sentence Takeaway: Every probability rule ? complement, addition, inclusion-exclusion ? follows from Kolmogorov's three axioms.

13.3 Conditional Probability​

The conditional probability of AAA given BBB is: P(A∣B)=P(A∩B)P(B)P(A \mid B) = \frac{P(A \cap B)}{P(B)}P(A∣B)=P(B)P(A∩B)​ provided P(B)>0P(B) > 0P(B)>0.

Multiplication rule: P(A∩B)=P(A∣B)⋅P(B)=P(B∣A)⋅P(A)P(A \cap B) = P(A \mid B) \cdot P(B) = P(B \mid A) \cdot P(A)P(A∩B)=P(A∣B)⋅P(B)=P(B∣A)⋅P(A).

Generalized multiplication rule: P(A1∩A2∩⋯∩An)=P(A1)⋅P(A2∣A1)⋅P(A3∣A1∩A2)⋯P(An∣A1∩⋯∩An−1)P(A_1 \cap A_2 \cap \dots \cap A_n) = P(A_1) \cdot P(A_2 \mid A_1) \cdot P(A_3 \mid A_1 \cap A_2) \cdots P(A_n \mid A_1 \cap \dots \cap A_{n-1})P(A1​∩A2​∩⋯∩An​)=P(A1​)⋅P(A2​∣A1​)⋅P(A3​∣A1​∩A2​)⋯P(An​∣A1​∩⋯∩An−1​)

One-Sentence Takeaway: Conditional probability updates the probability of AAA given knowledge that BBB occurred ? it renormalizes P(A∩B)P(A \cap B)P(A∩B) over P(B)P(B)P(B).

13.4 Independence​

Events AAA and BBB are independent if any of the following equivalent conditions hold:

  1. P(A∩B)=P(A)⋅P(B)P(A \cap B) = P(A) \cdot P(B)P(A∩B)=P(A)⋅P(B).
  2. P(A∣B)=P(A)P(A \mid B) = P(A)P(A∣B)=P(A).
  3. P(B∣A)=P(B)P(B \mid A) = P(B)P(B∣A)=P(B).

Theorem 13.2 (Independence of complements). If AAA and BBB are independent, then AAA and B′B'B′, A′A'A′ and BBB, A′A'A′ and B′B'B′ are also independent.

Events A1,A2,…,AnA_1, A_2, \dots, A_nA1​,A2​,…,An​ are mutually independent if for every subset {i1,…,ik}\{i_1, \dots, i_k\}{i1​,…,ik​}: P(Ai1∩⋯∩Aik)=P(Ai1)⋯P(Aik)P(A_{i_1} \cap \dots \cap A_{i_k}) = P(A_{i_1}) \cdots P(A_{i_k})P(Ai1​​∩⋯∩Aik​​)=P(Ai1​​)⋯P(Aik​​)

One-Sentence Takeaway: Independence means the occurrence of one event does not affect the probability of another ? the joint probability is the product of marginals.

13.5 Bayes' Theorem​

Bayes' theorem: P(H∣E)=P(E∣H)⋅P(H)P(E)P(H \mid E) = \frac{P(E \mid H) \cdot P(H)}{P(E)}P(H∣E)=P(E)P(E∣H)⋅P(H)​

For a partition H1,H2,…,HnH_1, H_2, \dots, H_nH1​,H2​,…,Hn​ of the sample space: P(Hj∣E)=P(E∣Hj)⋅P(Hj)∑i=1nP(E∣Hi)⋅P(Hi)P(H_j \mid E) = \frac{P(E \mid H_j) \cdot P(H_j)}{\sum_{i=1}^n P(E \mid H_i) \cdot P(H_i)}P(Hj​∣E)=∑i=1n​P(E∣Hi​)⋅P(Hi​)P(E∣Hj​)⋅P(Hj​)​

Terminology:

  • P(H)P(H)P(H): prior probability (before evidence).
  • P(H∣E)P(H \mid E)P(H∣E): posterior probability (after evidence).
  • P(E∣H)P(E \mid H)P(E∣H): likelihood.
  • P(E)P(E)P(E): marginal likelihood (normalization constant).

One-Sentence Takeaway: Bayes' theorem tells us how to update our belief in a hypothesis given new evidence ? it is the foundation of inference, spam filtering, and machine learning.

13.6 Random Variables​

A random variable XXX is a function X:S→RX: S \rightarrow \mathbb{R}X:S→R that assigns a real number to each outcome.

Discrete random variable: Takes countably many values (e.g., {0,1,2,… }\{0,1,2,\dots\}{0,1,2,…}).

Probability mass function (PMF): p(x)=P(X=x)p(x) = P(X = x)p(x)=P(X=x).

Cumulative distribution function (CDF): F(x)=P(X≤x)F(x) = P(X \leq x)F(x)=P(X≤x).

Theorem 13.3 (Properties of PMFs).

  • 0≤p(x)≤10 \leq p(x) \leq 10≤p(x)≤1.
  • ∑xp(x)=1\sum_x p(x) = 1∑x​p(x)=1.

One-Sentence Takeaway: A random variable maps outcomes to numbers; its probability mass function describes how total probability is distributed across possible values.

13.7 Expected Value and Variance​

Expected value (mean): μ=E[X]=∑xx⋅p(x)\mu = E[X] = \sum_x x \cdot p(x)μ=E[X]=∑x​x⋅p(x).

Theorem 13.4 (Linearity of expectation). For any random variables XXX and YYY:

  • E[aX+b]=aE[X]+bE[aX + b] = aE[X] + bE[aX+b]=aE[X]+b.
  • E[X+Y]=E[X]+E[Y]E[X + Y] = E[X] + E[Y]E[X+Y]=E[X]+E[Y] (even if XXX and YYY are not independent).

Variance: σ2=Var(X)=E[(X−μ)2]=E[X2]−μ2\sigma^2 = \text{Var}(X) = E[(X - \mu)^2] = E[X^2] - \mu^2σ2=Var(X)=E[(X−μ)2]=E[X2]−μ2.

Standard deviation: σ=Var(X)\sigma = \sqrt{\text{Var}(X)}σ=Var(X)​.

Theorem 13.5 (Variance properties).

  • Var(aX+b)=a2⋅Var(X)\text{Var}(aX + b) = a^2 \cdot \text{Var}(X)Var(aX+b)=a2⋅Var(X).
  • If XXX and YYY are independent: Var(X+Y)=Var(X)+Var(Y)\text{Var}(X + Y) = \text{Var}(X) + \text{Var}(Y)Var(X+Y)=Var(X)+Var(Y).
interface Distribution {
  values: number[];
  probs: number[];
}

function expectedValue(dist: Distribution): number {
  let ev = 0;
  for (let i = 0; i < dist.values.length; i++) {
    ev += dist.values[i] * dist.probs[i];
  }
  return ev;
}

function variance(dist: Distribution): number {
  const mu = expectedValue(dist);
  let varSum = 0;
  for (let i = 0; i < dist.values.length; i++) {
    varSum += (dist.values[i] - mu) ** 2 * dist.probs[i];
  }
  return varSum;
}

// Example: fair die
const die: Distribution = {
  values: [1, 2, 3, 4, 5, 6],
  probs: [1/6, 1/6, 1/6, 1/6, 1/6, 1/6],
};
console.log(expectedValue(die)); // 3.5
console.log(variance(die));      // ~2.917

One-Sentence Takeaway: Expected value is the probability-weighted average; variance measures spread ? linearity of expectation holds regardless of independence.

13.8 Bernoulli and Binomial Distributions​

Bernoulli trial: A single experiment with two outcomes: success (1) with probability ppp, failure (0) with probability 1−p1-p1−p.

  • P(X=1)=pP(X = 1) = pP(X=1)=p, P(X=0)=1−pP(X = 0) = 1-pP(X=0)=1−p.
  • E[X]=pE[X] = pE[X]=p, Var(X)=p(1−p)\text{Var}(X) = p(1-p)Var(X)=p(1−p).

Binomial distribution: Number of successes in nnn independent Bernoulli trials, each with success probability ppp.

  • PMF: P(X=k)=(nk)pk(1−p)n−kP(X = k) = \binom{n}{k} p^k (1-p)^{n-k}P(X=k)=(kn​)pk(1−p)n−k, for k=0,1,…,nk = 0, 1, \dots, nk=0,1,…,n.
  • E[X]=npE[X] = npE[X]=np, Var(X)=np(1−p)\text{Var}(X) = np(1-p)Var(X)=np(1−p).
function binomialProb(n: number, k: number, p: number): number {
  // P(X = k) for Binomial(n, p)
  return binomialCoeff(n, k) * Math.pow(p, k) * Math.pow(1 - p, n - k);
}

function binomialCoeff(n: number, k: number): number {
  if (k < 0 || k > n) return 0;
  if (k === 0 || k === n) return 1;
  k = Math.min(k, n - k);
  let result = 1;
  for (let i = 1; i <= k; i++) {
    result = result * (n - k + i) / i;
  }
  return result;
}

console.log(binomialProb(10, 3, 0.5)); // P(3 heads in 10 fair coin flips)

One-Sentence Takeaway: The binomial distribution counts successes in nnn independent Bernoulli trials; its mean is npnpnp and variance is np(1−p)np(1-p)np(1−p).

13.9 Geometric Distribution​

The number of trials until the first success in independent Bernoulli trials.

PMF: P(X=k)=(1−p)k−1pP(X = k) = (1-p)^{k-1} pP(X=k)=(1−p)k−1p, for k=1,2,3,…k = 1, 2, 3, \dotsk=1,2,3,….

Properties:

  • E[X]=1/pE[X] = 1/pE[X]=1/p.
  • Var(X)=(1−p)/p2\text{Var}(X) = (1-p)/p^2Var(X)=(1−p)/p2.
  • Memoryless property: P(X>n+m∣X>n)=P(X>m)P(X > n + m \mid X > n) = P(X > m)P(X>n+m∣X>n)=P(X>m).

One-Sentence Takeaway: The geometric distribution models "waiting time" until the first success; it is memoryless ? past failures do not affect future probability.

13.10 Inclusion-Exclusion for Probability​

Principle of inclusion-exclusion for probability: P\left(\bigcup_{i=1}^n A_i\right) = \sum_i P(A_i) - \sum_{i&lt;j} P(A_i \cap A_j) + \sum_{i<j<k} P(A_i \cap A_j \cap A_k) - \cdots + (-1)^{n+1} P(A_1 \cap \dots \cap A_n)

For n=3n = 3n=3: P(A∪B∪C)=P(A)+P(B)+P(C)−P(A∩B)−P(A∩C)−P(B∩C)+P(A∩B∩C)P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(A\cap B) - P(A\cap C) - P(B\cap C) + P(A \cap B \cap C)P(A∪B∪C)=P(A)+P(B)+P(C)−P(A∩B)−P(A∩C)−P(B∩C)+P(A∩B∩C)

One-Sentence Takeaway: Inclusion-exclusion computes the probability of a union by alternating sums and subtractions of intersections of increasing size.

function bayesTheorem(
  prior: number,
  likelihood: number,
  falsePositiveRate: number
): number {
  const numerator = likelihood * prior;
  const denominator = numerator + falsePositiveRate * (1 - prior);
  return numerator / denominator;
}

13.11 Law of Total Probability​

The law of total probability expresses the probability of an event AAA as a weighted average over a partition of the sample space:

P(A)=∑iP(A∣Bi)⋅P(Bi)P(A) = \sum_{i} P(A \mid B_i) \cdot P(B_i)P(A)=∑i​P(A∣Bi​)⋅P(Bi​)

where {B1,B2,…,Bn}\{B_1, B_2, \dots, B_n\}{B1​,B2​,…,Bn​} is a partition of SSS (disjoint and covering all outcomes).

Theorem 13.6 (Law of Total Probability). If B1,B2,…,BnB_1, B_2, \dots, B_nB1​,B2​,…,Bn​ partition SSS, then for any event AAA: P(A)=P(A∩B1)+P(A∩B2)+⋯+P(A∩Bn)=∑iP(A∣Bi)P(Bi)P(A) = P(A \cap B_1) + P(A \cap B_2) + \cdots + P(A \cap B_n) = \sum_i P(A \mid B_i) P(B_i)P(A)=P(A∩B1​)+P(A∩B2​)+⋯+P(A∩Bn​)=∑i​P(A∣Bi​)P(Bi​)

function totalProbability(
  conditionalProbs: number[],
  priorProbs: number[]
): number {
  let total = 0;
  for (let i = 0; i < conditionalProbs.length; i++) {
    total += conditionalProbs[i] * priorProbs[i];
  }
  return total;
}

13.12 Monte Carlo Simulation​

Monte Carlo methods use random sampling to approximate probabilities when analytical computation is intractable.

function monteCarloPi(samples: number): number {
  let inside = 0;
  for (let i = 0; i < samples; i++) {
    const x = Math.random() * 2 - 1;
    const y = Math.random() * 2 - 1;
    if (x * x + y * y <= 1) inside++;
  }
  return 4 * inside / samples;
}

console.log(monteCarloPi(100000)); // ~3.14159

function simulateDiceSum(target: number, trials: number): number {
  let successes = 0;
  for (let t = 0; t < trials; t++) {
    const d1 = Math.floor(Math.random() * 6) + 1;
    const d2 = Math.floor(Math.random() * 6) + 1;
    if (d1 + d2 === target) successes++;
  }
  return successes / trials;
}

13.13 Conditional Expectation​

The conditional expectation E[X∣Y=y]E[X \mid Y = y]E[X∣Y=y] is the expected value of XXX given that Y=yY = yY=y:

E[X∣Y=y]=∑xx⋅P(X=x∣Y=y)E[X \mid Y = y] = \sum_x x \cdot P(X = x \mid Y = y)E[X∣Y=y]=∑x​x⋅P(X=x∣Y=y)

Theorem 13.7 (Law of Total Expectation / Tower Law). E[X]=E[E[X∣Y]]=∑yE[X∣Y=y]⋅P(Y=y)E[X] = E[E[X \mid Y]] = \sum_y E[X \mid Y = y] \cdot P(Y = y)E[X]=E[E[X∣Y]]=∑y​E[X∣Y=y]⋅P(Y=y)

function conditionalExpectation(
  xValues: number[],
  givenY: (y: number) => number[],
  yProbs: number[],
  yValues: number[]
): number {
  let total = 0;
  for (let i = 0; i < yValues.length; i++) {
    const condProbs = givenY(yValues[i]);
    let condExp = 0;
    for (let j = 0; j < xValues.length; j++) {
      condExp += xValues[j] * condProbs[j];
    }
    total += condExp * yProbs[i];
  }
  return total;
}

function markovBound(mean: number, a: number): number {
  if (a <= 0) return 1;

13.15 Probability in Machine Learning: Naive Bayes​

Naive Bayes classifiers apply Bayes' theorem with a "naive" assumption of conditional independence:

P(class∣features)∝P(class)⋅∏iP(featurei∣class)P(\text{class} \mid \text{features}) \propto P(\text{class}) \cdot \prod_i P(\text{feature}_i \mid \text{class})P(class∣features)∝P(class)⋅∏i​P(featurei​∣class)

interface NaiveBayesModel {
  classProbs: Map<string, number>;
  featureProbs: Map<string, Map<string, Map<string, number>>>;
}

function predictNB(
  model: NaiveBayesModel,
  features: Record<string, string>
): string {
  let bestClass = "";
  let bestProb = -1;
  for (const [cls, prior] of model.classProbs) {
    let prob = Math.log(prior);
    const clsProbs = model.featureProbs.get(cls)!;
    for (const [feat, val] of Object.entries(features)) {
      prob += Math.log(clsProbs.get(feat)?.get(val) ?? 1e-10);
    }
    if (prob > bestProb) { bestProb = prob; bestClass = cls; }
  }
  return bestClass;
}

function factorial(n: number): number {
  if (n <= 1) return 1;
  return n * factorial(n - 1);

function nCr(n: number, r: number): number {
  if (r < 0 || r > n) return 0;
  return factorial(n) / (factorial(r) * factorial(n - r));

function expectedValue(values: number[], probs: number[]): number {
  if (values.length !== probs.length) throw new Error('Mismatched lengths');
  return values.reduce((sum, v, i) => sum + v * probs[i], 0);

function bayesTheorem(
  priorA: number,        // P(A)
  probBGivenA: number,   // P(B|A)
  probBGivenNotA: number // P(B|?A)
): number {
  const probNotA = 1 - priorA;
  const probB = probBGivenA * priorA + probBGivenNotA * probNotA;
  return (probBGivenA * priorA) / probB; // P(A|B)
}

// --- Markov Chain Simulator ---
function markovChain(
  transMatrix: number[][],
  initialState: number,
  steps: number
): { states: number[]; stationary: number[] } {
  const n = transMatrix.length;
  let state = initialState;
  const states = [state];
  for (let s = 0; s < steps; s++) {
    const r = Math.random();
    let cum = 0;
    for (let j = 0; j < n; j++) {
      cum += transMatrix[state][j];
      if (r < cum) { state = j; break; }
    }
    states.push(state);
  }
  // Power iteration for stationary distribution
  let pi = new Array(n).fill(1 / n);
  for (let iter = 0; iter < 100; iter++) {
    pi = pi.map((_, j) => pi.reduce((s, p, i) => s + p * transMatrix[i][j], 0));
  }
  return { states, stationary: pi.map(v => +v.toFixed(4)) };
}

Summary​

  • Probability measures likelihood from 0 to 1; all rules derive from Kolmogorov's axioms.
  • Conditional probability updates beliefs given evidence.
  • Bayes' theorem reverses conditional probabilities.
  • Random variables map outcomes to numbers; expected value and variance describe the distribution.
  • Bernoulli, binomial, and geometric distributions model sequences of independent trials.
  • Inclusion-exclusion computes union probabilities by alternating intersections.

Practical Takeaways​

  1. Complement is your best friend ? P(at least one)P(\text{at least one})P(at least one) is almost always easier as 1−P(none)1 - P(\text{none})1−P(none).
  2. Linearity of expectation works without independence ? this is the most powerful tool in probability.
  3. Bayes' theorem avoids false positives ? always account for the base rate (prior).
  4. Binomial counts successes in 0/1 trials ? check independence and constant ppp before using.
  5. Variance is not linear ? Var(X+Y)=Var(X)+Var(Y)\text{Var}(X+Y) = \text{Var}(X) + \text{Var}(Y)Var(X+Y)=Var(X)+Var(Y) only for independent variables.
