# Database Management System (DBMS) Detailed Syllabus

## A. Database Concepts

- Data, database, DBMS, database system
- Database vs file system
- Users: DBA, designers, end users
- Architecture: three-level, data independence

## B. Data Models

- Relational: tables, keys, relationships
- ER model: entities, attributes, relationships, diagrams
- Enhanced ER: inheritance, specialization, generalization

## C. SQL

- DDL, DML, DCL, TCL
- Joins, subqueries, views, indexes
- Set operations, window functions, aggregate, string/date functions

## D. Normalization & Design

- 1NF, 2NF, 3NF, BCNF, denormalization
- Indexing: B-tree, hash, bitmap
- Query optimization, execution plans

## E. Transactions & Concurrency

- ACID properties
- Transaction states, operations
- Concurrency control: locks, isolation levels
- Deadlock: detection, prevention, recovery

## F. NoSQL & Administration

- NoSQL: MongoDB, Redis, Cassandra, Neo4j
- CAP theorem
- Backup/recovery, security, performance tuning, replication, clustering
