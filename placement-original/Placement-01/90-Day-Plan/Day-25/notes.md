# Day 25 Notes: Java Collections

## Key Points
- ArrayList is backed by dynamic array: O(1) average add, O(n) remove at index
- LinkedList has O(1) insert/remove at ends, O(n) random access
- HashMap & HashSet: O(1) average insert/get/remove, depends on good hash functions
- TreeMap & TreeSet: O(log n) operations, ordered
