अध्याय 01: परिचय — ओशो का दृष्टिकोण​

mermaid mindmap root((VBT परिचय<br/>ओशो का दृष्टिकोण)) तंत्र क्या है संप्रदाय नहीं प्रयोगात्मक विज्ञान अनुभव-आधारित कोई विश्वास नहीं ओशो की भूमिका व्याख्याता आधुनिक संदर्भ प्रयोगकर्ता 112 विधियाँ शिव द्वारा प्रकट ५ श्रेणियाँ आज भी प्रासंगिक मुख्य सिद्धांत अभ्यास से अनुभव साक्षी भाव स्वयं को जानो आधुनिक दृष्टि वैज्ञानिक दृष्टिकोण मनोवैज्ञानिक आधार व्यावहारिक मार्ग

मुख्य बिंदु (Key Takeaways)​

  1. तंत्र एक धर्म नहीं, एक विज्ञान है — ओशो तंत्र को एक प्रयोगात्मक विज्ञान के रूप में प्रस्तुत करते हैं।
  2. विज्ञान भैरव तंत्र का महत्व — सबसे प्राचीन ध्यान शास्त्र, 112 ध्यान विधियाँ।
  3. ओशो का आधुनिक संदर्भ — प्राचीन विधियों को आधुनिक संदर्भ में पुनः व्याख्यायित।
  4. कोई पूर्वापेक्षा नहीं — किसी दीक्षा या विश्वास की आवश्यकता नहीं।
  5. ध्यान = अनुभव — करने और अनुभव करने की चीज़ है।
  6. प्रत्येक व्यक्ति अलग — अपनी प्रकृति के अनुसार विधि चुनें।
  7. प्रयोगशाला के रूप में जीवन — स्वयं पर प्रयोग करें।
  8. शास्त्र से अधिक अनुभव — स्वयं अनुभव किया हुआ ही सत्य है।

अध्याय 02: ओशो की तंत्र दृष्टि​

mermaid flowchart TD A["तंत्र दृष्टि"] --> B["स्वीकार का मार्ग"] A --> C["ऊर्जा का रूपांतरण"] A --> D["साक्षी चेतना"] B --> B1["जीवन को नकारो मत"] B --> B2["सब कुछ पवित्र है"] B --> B3["कोई पाप नहीं"] C --> C1["काम से समाधि"] C --> C2["क्रोध से करुणा"] C --> C3["भय से स्वतंत्रता"] D --> D1["करने वाला नहीं"] D --> D2["देखने वाला बनो"] D --> D3["गवाह बनो"]

मुख्य बिंदु​

  1. तंत्र = स्वीकार — जीवन को वैसे स्वीकार करना जैसा वह है।
  2. त्याग नहीं, उपयोग — हर चीज़ का उपयोग करो, ऊर्जा का रूपांतरण करो।
  3. कोई पाप नहीं — केवल अज्ञान और ज्ञान है।
  4. काम और समाधि — यौन ऊर्जा को आध्यात्मिक ऊर्जा में रूपांतरित करना।
  5. नैतिकता vs. तंत्र — नैतिकता बाहर से लादी जाती है, तंत्र भीतर से जागता है।
  6. यहीं और अभी — इसी क्षण में मुक्त होना सिखाता है।
  7. पूर्ण जागरूकता — हर क्रिया को पूर्ण जागरूकता से करना।

मुख्य बिंदु​

  1. पाँच मुख्य श्रेणियाँ — श्वास, शारीरिक, दृश्य, ध्वनि, भाव/साक्षी।
  2. श्वास विधियाँ (20) — श्वास पर ध्यान, प्राणायाम, श्वास-विचार संबंध।
  3. शारीरिक विधियाँ (22) — शरीर गतिविधियाँ, संवेदनाएँ।
  4. दृश्य विधियाँ (18) — प्रकाश, रंग, आकाश, दृश्य प्रतिमाएँ।

  6. भाव और साक्षी (36) — भावनाएँ, रस, शुद्ध साक्षी भाव।
  7. प्रगतिशील क्रम — पहले श्वास-शरीर, फिर दृश्य-ध्वनि, अंत में साक्षी।
  8. उपाय का सिद्धांत — प्रत्येक साधक अपनी प्रकृति अनुसार चुन सकता है।

mermaid flowchart TB subgraph Breath["श्वास-प्रज्ञा प्रवाह"] direction TB A["चरण 1: श्वास देखना"] --> B["चरण 2: श्वास लय"] B --> C["चरण 3: श्वास और विचार"] C --> D["चरण 4: श्वास और ऊर्जा"] D --> E["चरण 5: श्वास और चेतना"] end A --> A1["बस देखो, कोई बदलाव नहीं"] B --> B1["श्वास लेना-छोड़ना-अंतराल"] C --> C1["विचार और श्वास का संबंध"] D --> D1["प्राण ऊर्जा का अनुभव"] E --> E1["श्वास = चेतना, द्वैत का अंत"]

मुख्य बिंदु​

  1. श्वास = पुल — शरीर और मन के बीच का पुल है।
  2. चार श्वास विधियाँ — देखना, रोकना, लंबाई बदलना, अंतराल में झाँकना।
  3. श्वास और विचार — जब विचार बदलता है, श्वास बदलती है।
  4. श्वास के चार चरण — लेना, भीतर रोकना, छोड़ना, बाहर रोकना।
  5. अंतराल में समाधि — कुंभक वह द्वार है जहाँ से समाधि में प्रवेश होता है।
  6. बिना प्रयास के — श्वास को बदलना नहीं, बस जागरूकता से देखना।
  7. प्राण और चेतना — श्वास से प्राण, प्राण से चेतना को समझना।

मुख्य बिंदु​

  1. शरीर = मंदिर — शरीर कोई बाधा नहीं, चेतना का निवास है।
  2. शरीर से दोस्ती — पहला कदम शरीर से दोस्ती करना है।
  3. संवेदना ध्यान — एक संवेदना पर ध्यान केंद्रित करना।
  4. निश्चलता की शक्ति — पूरी तरह स्थिर रखकर ध्यान करना।
  5. शवासन ध्यान — लेटकर पूरी तरह ढीला छोड़ना।
  6. शरीर से परे — शरीर की चेतना पूर्ण होने पर शरीर से बाहर।
  7. चक्र जागरण — ऊर्जा केंद्रों पर ध्यान।

संस्कृत शब्दावली​

TypeScript: Chapter Revision Card Randomizer​

This TypeScript utility generates random revision cards from all 18 chapters for quick review.

` ypescript interface RevisionCard { chapterNumber: number; chapterTitle: string; category: 'keyPoint' | 'sanskritTerm'; content: string; detail: string; }

interface ChapterData { number: number; title: string; keyPoints: { point: string; detail: string }[]; sanskritTerms: { term: string; definition: string }[]; }

class RevisionCardGenerator { private cards: RevisionCard[] = []; private drawnCards: RevisionCard[] = []; private history: string[] = [];

constructor() { this.initializeCards(); }

private initializeCards(): void { const chapters: ChapterData[] = [ { number: 1, title: 'परिचय: ओशो का दृष्टिकोण', keyPoints: [ { point: 'तंत्र एक प्रयोगात्मक विज्ञान है', detail: 'अंध-विश्वास नहीं, प्रयोग करके देखें' }, { point: 'कोई पूर्वापेक्षा नहीं', detail: 'दीक्षा या विश्वास ज़रूरी नहीं' }, { point: 'ध्यान = अनुभव', detail: 'करने की चीज़ है, सोचने की नहीं' }, { point: 'प्रत्येक व्यक्ति अलग', detail: 'अपनी प्रकृति अनुसार विधि चुनें' }, { point: 'जीवन एक प्रयोगशाला', detail: 'स्वयं पर प्रयोग करें' }, ], sanskritTerms: [ { term: 'विज्ञान', definition: 'प्रत्यक्ष अनुभव-आधारित ज्ञान' }, { term: 'भैरव', definition: 'चेतना जो भय से परे है' }, { term: 'तंत्र', definition: 'स्वीकार करने की कला, विस्तार' }, ], }, { number: 2, title: 'ओशो की तंत्र दृष्टि', keyPoints: [ { point: 'तंत्र = स्वीकार', detail: 'जीवन को वैसे स्वीकार करो जैसा है' }, { point: 'त्याग नहीं, उपयोग', detail: 'हर चीज़ का उपयोग करो' }, { point: 'कोई पाप नहीं', detail: 'केवल अज्ञान और ज्ञान है' }, { point: 'यहीं और अभी', detail: 'इसी क्षण में मुक्ति' }, ], sanskritTerms: [ { term: 'शिव', definition: 'चेतना का शुद्ध रूप' }, { term: 'शक्ति', definition: 'ब्रह्मांड की मूल ऊर्जा' }, { term: 'समाधि', definition: 'द्वैत का अंत' }, ], }, { number: 3, title: '112 विधियाँ: ओशो का वर्गीकरण', keyPoints: [ { point: 'पाँच श्रेणियाँ', detail: 'श्वास, शारीरिक, दृश्य, ध्वनि, भाव/साक्षी' }, { point: 'श्वास (20) + शारीरिक (22)', detail: 'श्वास और शरीर आधारित विधियाँ' }, { point: 'दृश्य (18) + ध्वनि (16)', detail: 'प्रकाश, रंग, मंत्र, नाद' }, { point: 'भाव और साक्षी (36)', detail: 'भावना और शुद्ध साक्षी' }, ], sanskritTerms: [ { term: 'उपाय', definition: 'साधन, साध्य नहीं' }, { term: 'प्राणायाम', definition: 'प्राण का विस्तार' }, { term: 'मंत्र', definition: 'ध्वनि उपकरण' }, ], }, ];

for (const ch of chapters) {
  for (const kp of ch.keyPoints) {
    this.cards.push({
      chapterNumber: ch.number,
      chapterTitle: ch.title,
      category: 'keyPoint',
      content: kp.point,
      detail: kp.detail,
    });
  }
  for (const st of ch.sanskritTerms) {
    this.cards.push({
      chapterNumber: ch.number,
      chapterTitle: ch.title,
      category: 'sanskritTerm',
      content: st.term,
      detail: st.definition,
    });
  }
}

}

shuffle(): void { for (let i = this.cards.length - 1; i > 0; i--) { const j = Math.floor(Math.random() * (i + 1)); [this.cards[i], this.cards[j]] = [this.cards[j], this.cards[i]]; } this.drawnCards = []; this.history = []; }

drawCard(): RevisionCard | null { if (this.cards.length === 0) return null; const index = Math.floor(Math.random() * this.cards.length); const card = this.cards[index]; this.drawnCards.push(card); this.history.push('[Ch' + card.chapterNumber + '] ' + card.content); return card; }

drawFromChapter(chapterNumber: number): RevisionCard | null { const chapterCards = this.cards.filter(c => c.chapterNumber === chapterNumber); if (chapterCards.length === 0) return null; const index = Math.floor(Math.random() * chapterCards.length); const card = chapterCards[index]; this.drawnCards.push(card); this.history.push('[Ch' + card.chapterNumber + '] ' + card.content); return card; }

drawByCategory(category: 'keyPoint' | 'sanskritTerm'): RevisionCard | null { const filtered = this.cards.filter(c => c.category === category); if (filtered.length === 0) return null; const index = Math.floor(Math.random() * filtered.length); const card = filtered[index]; this.drawnCards.push(card); return card; }

getTotalCards(): number { return this.cards.length; } getDrawnCount(): number { return this.drawnCards.length; } getHistory(): string[] { return [...this.history]; }

getChapterStats(): { chapterNumber: number; chapterTitle: string; cardCount: number }[] { const stats = new Map<number, { title: string; count: number }>(); for (const card of this.cards) { if (!stats.has(card.chapterNumber)) { stats.set(card.chapterNumber, { title: card.chapterTitle, count: 0 }); } stats.get(card.chapterNumber)!.count++; } return Array.from(stats.entries()).map(([num, data]) => ({ chapterNumber: num, chapterTitle: data.title, cardCount: data.count, })); }

getDailySet(): RevisionCard[] { const used = new Set(); const set: RevisionCard[] = []; const shuffled = [...this.cards].sort(() => Math.random() - 0.5); for (const card of shuffled) { if (set.length >= 5) break; if (!used.has(card.chapterNumber)) { used.add(card.chapterNumber); set.push(card); } } return set; } }

export { RevisionCardGenerator, RevisionCard, ChapterData }; `

Osho के 7 सुनहरे नियम (7 Golden Rules)​

  1. स्वीकार करो — जीवन को वैसे स्वीकार करो जैसा वह है।
  2. प्रयोग करो — किसी भी बात को अंध-विश्वास से मत मानो।
  3. साक्षी बनो — कर्ता मत बनो, द्रष्टा बनो।
  4. निर्णय मत दो — अनुभव को अच्छा या बुरा मत कहो।
  5. नियमित रहो — एक बार में बहुत नहीं, बल्कि नियमित करो।
  6. धैर्य रखो — ध्यान कोई व्यवसाय नहीं, धीरे-धीरे फल देता है।
  7. हँसते रहो — ध्यान को गंभीर मत बनाओ, इसे आनंद बनाओ।

"याद रखो — तुम वही हो जिसकी तुम खोज कर रहे हो। बाहर मत देखो, भीतर देखो।" — ओशो

"जीवन कोई पहेली नहीं है जिसे सुलझाना है — वह एक रहस्य है जिसे जीना है।" — ओशो

✿ अध्याय-वार माइंड मैप समाप्त ✿

यह गाइड आपकी VBT यात्रा में एक साथी की तरह है। इसे बार-बार पलटें, हर बार नई गहराई दिखेगी।
