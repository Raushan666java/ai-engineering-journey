> **Exam Weightage:** 3-5 Qs in IBPS SO Mains PK, 8-10% in GATE CS
>
> **Difficulty:** Moderate (logic-heavy, some numerics)
>
> **Focus Areas:** CPU organization, Memory hierarchy, Pipelining, I/O

## 🎯 Strategy

1. Master number system conversions (decimal/binary/hex/octal)
2. Understand register-transfer level descriptions
3. Cache mapping problems are common — practice numericals
4. Pipeline hazards — understand stalls and forwarding
