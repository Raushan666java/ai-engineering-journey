# 17. Practice & Projects

- Build mini projects to apply PHP concepts:
  - Login system with sessions and password hashing
  - CRUD app (Create, Read, Update, Delete) with MySQL
  - Contact form with validation and email sending
  - File upload and image gallery
- Practice problems:
  - Write a function to reverse a string
  - Validate an email address
  - Read and display contents of a file
  - Connect to a database and fetch records

## Best Learning Methods
- Work on real-world projects and share on GitHub.
- Solve coding challenges on platforms like HackerRank, LeetCode.
- Reference: https://www.php.net/manual/en/tutorial.php
