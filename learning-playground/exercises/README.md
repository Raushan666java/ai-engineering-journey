# Exercises

Your work goes here — not in `lessons/`. Each file is yours alone; break it freely.

## Rules

1. No tutorial while solving. Docs and error messages only.
2. 30-minute rule: if stuck 30 minutes, write the exact error in a comment and try the dumbest fix.
3. Every exercise ends with either a passing test or a written note explaining the failure.
