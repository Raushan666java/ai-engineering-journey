# Day 24 Study Plan: Advanced Graphs (Part 2)

## Daily Schedule (9 hours total)

### Morning Session (3 hours)
- Topic: Max Flow Algorithms
  - Understand residual graphs, augmenting paths
  - Implement Edmonds-Karp (BFS-based augmenting path)

### Afternoon Session (3 hours)
- Topic: Bridges & Articulation Points
  - Implement Tarjan's low-link algorithm
  - Use to find critical edges and nodes

### Evening Session (3 hours)
- Topic: LCA & Binary Lifting
  - Implement LCA with preprocessing for O(1) queries
  - Test with tree queries and edge cases

## Learning Objectives
- Understand flow networks and max-flow min-cut theorem
- Learn Tarjan's algorithm to find bridges and articulation points
- Learn LCA query preprocessing and O(log N) queries via binary lifting

**Expected Outcome:** Demos and visualizers for Flow, Tarjan, and LCA with unit tests for quick verification.
