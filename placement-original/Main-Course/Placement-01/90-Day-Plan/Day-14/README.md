## 🏆 90-Minute Coding Contest

### Contest Format

**Time:** 90 minutes  
**Problems:** 5 (2 Easy + 2 Medium + 1 Hard)  
**Scoring:** 100 points each (500 total)  
**Partial Credit:** Yes (for partial solutions)  

### Contest Problems

**Problem 1 (Easy - 100 pts):** Array Manipulation
- Two Sum variant or Remove Duplicates
- Expected Time: 10-15 minutes

**Problem 2 (Easy - 100 pts):** Linked List Basic
- Reverse or Merge linked lists
- Expected Time: 15 minutes

**Problem 3 (Medium - 100 pts):** HashMap/HashSet
- Frequency counting or anagram problem
- Expected Time: 20 minutes

**Problem 4 (Medium - 100 pts):** Tree Problem
- Traversal or BST operation
- Expected Time: 25 minutes

**Problem 5 (Hard - 100 pts):** Heap or Advanced Tree
- Top-K or complex tree problem
- Expected Time: 20 minutes (may not finish)

### Contest Strategy

1. **Read all problems first (5 min)**
2. **Solve Easy problems quickly (25 min)**
3. **Tackle Medium problems (45 min)**
4. **Attempt Hard problem (15 min)**
5. **Debug and optimize (remaining time)**

### Scoring Benchmarks

- **400-500 pts:** Excellent (Top 10%)
- **300-399 pts:** Good (Top 30%)
- **200-299 pts:** Average (Top 50%)
- **<200 pts:** Needs improvement
