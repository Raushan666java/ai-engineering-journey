### Resume Tips

<details>
<summary><strong>ATS-Friendly Format</strong> — Resume parse ho jaye, reject nahi</summary>

- **File type**: PDF upload karo (not Word). PDF formatting preserve rakhta hai.
- **Template**: Simple, single-column, no graphics/icons. ATS inhe parse nahi kar pata.
- **Sections**: Contact → Summary → Skills → Experience → Projects → Education → Certifications.
- **File name**: `FirstName_LastName_Company_Role.pdf` — not `resume_final_v3.pdf`.
- **Keywords**: Job description se relevant keywords nikaalo aur resume mein use karo (skills, tools, frameworks).
</details>

<details>
<summary><strong>Project Descriptions with Impact Metrics</strong></summary>

- **Format**: Action Verb + Task + Technology + Impact (numeric).
- **Bad**: "Built a chat application using Laravel."
- **Good**: "Built a real-time chat application using Laravel + WebSockets serving 500+ concurrent users, reducing response time by 40%."
- **Use numbers**: users, requests/second, response time, test coverage, revenue impact.
- **Technical depth**: Mention architecture decisions, trade-offs, and scaling strategies.
</details>

<details>
<summary><strong>Skills Section Optimization</strong></summary>

- **Categorize**: Languages | Frameworks | Tools | Databases | Cloud.
- **Relevancy**: Only list skills relevant to the role you're applying for.
- **Proficiency**: Avoid "beginner/intermediate/expert" — just list the skill.
- **ATS Keywords**: Match skills from job description exactly. If they say "Node.js", write "Node.js" not "Node".
</details>

### Interview Preparation Timeline

```
Month 1-2:  Coding Prep (DSA)
  ├── Arrays, Strings, Hashing
  ├── Linked Lists, Stacks, Queues
  ├── Trees, Graphs, Tries
  ├── DP, Recursion, Backtracking
  └── Practice: 2 problems/day → 4 problems/day

Month 3:    CS Fundamentals
  ├── OS — processes, threads, memory, concurrency
  ├── DBMS — normalization, SQL, indexing, transactions
  ├── Networks — TCP/IP, HTTP, DNS, load balancers
  └── OOP — SOLID, design patterns, composition vs inheritance

Month 4:    Projects + Portfolio
  ├── Build 2-3 full-stack projects
  ├── Deploy on cloud (AWS/GCP)
  ├── Write clean README + documentation
  └── Push to GitHub + showcase on LinkedIn

Month 5:    System Design
  ├── Scalability fundamentals
  ├── Design: URL shortener, Chat system, Rate limiter
  ├── Design: Twitter, YouTube, Uber
  └── Practice: 1 design per week

Month 6:    Behavioral + Mock Interviews
  ├── STAR format — 10 common behavioral questions
  ├── Mock interviews with peers (Pramp / interviewing.io)
  ├── Company-specific research
  └── Resume finalize + start applying
```

### Salary Negotiation Tips

- **Research First**: Glassdoor, Levels.fyi, AmbitionBox, Blind — market rates dekho for role + location.
- **Never Give First Number**: When they ask "expected salary", say "I'm flexible, what's your budget for this role?"
- **Know Your Worth**: Calculate based on: base salary + bonus + stock (RSU/ESOP) + signing bonus + relocation.
- **Leverage Offers**: Multiple offers = best negotiation power. Delay decisions until all offers are in.
- **Negotiate in Stages**:
  1. First, negotiate base salary
  2. Then, negotiate joining bonus
  3. Then, negotiate stock/RSUs
  4. Finally, negotiate perks (WFH budget, learning allowance)
- **Timing**: Discuss salary only after you have a written offer, not in first interview.
- **Common Mistakes**: Accepting first offer, not negotiating at all, lying about other offers, being aggressive.
- **For Freshers**: Less room for negotiation but still ask — companies often have some flexibility.

### DSA Cheat Sheet — Time Complexities

| Data Structure | Access | Search | Insert | Delete |
|----------------|--------|--------|--------|--------|
| **Array** | O(1) | O(n) | O(n) | O(n) |
| **Stack** | O(n) | O(n) | O(1) push | O(1) pop |
| **Queue** | O(n) | O(n) | O(1) enqueue | O(1) dequeue |
| **Singly Linked List** | O(n) | O(n) | O(1) | O(1) |
| **Doubly Linked List** | O(n) | O(n) | O(1) | O(1) |
| **Hash Table** | N/A | O(1) avg | O(1) avg | O(1) avg |
| **BST (balanced)** | O(log n) | O(log n) | O(log n) | O(log n) |
| **Heap (min/max)** | O(1) peek | O(n) | O(log n) | O(log n) extract |
| **Graph (adj list)** | O(V) iterate | O(V+E) DFS/BFS | O(1) | O(V+E) |
| **Trie** | O(k) | O(k) | O(k) | O(k) |

**Algorithm Complexities:**
- **Sorting**: Quick/Merge O(n log n), Bubble/Selection/Insertion O(n²)
- **Binary Search**: O(log n)
- **DFS/BFS**: O(V+E)
- **Dijkstra**: O((V+E) log V)
- **DP**: Depends on state space — typically O(n²) or O(n×m)
- **Backtracking**: O(2^n) or O(n!) — exponential
