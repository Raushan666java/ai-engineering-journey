# BSNL SET (Telecom) 2027 — Complete Preparation Course

This course covers **every topic the BSNL SET (Telecom) paper can ask**, in the order that maximises marks per study hour for a Computer Science graduate.

It is not a GATE CSE course. Roughly 30% of the paper is material you already know; the other 70% is telecom-domain knowledge that no GATE course teaches. This course is built around that split.

## Who this is for

- B.Tech CSE (or IT/ECE), targeting **SET (Telecom)** — 95 of the 120 posts in the 2026 cycle were Telecom.
- Starting from beginner-to-intermediate on telecom, strong on networking.
- Target: **120+/200** with a floor of 110, against an SC qualifying bar of 90.

## What the exam actually is

| Item | Value |
|---|---|
| Questions / marks | 200 / 200 (+1 each) |
| Duration | 180 minutes |
| Negative marking | −0.25 per wrong |
| Part I | Aptitude — 40 Q (quant, reasoning, English, GA) |
| Part II | Technical Telecom — 160 Q |
| SC qualifying | 35% Part I (14) · 35% Part II (56) · 45% overall (90) |
| Interview | None |

Full evidence, cutoffs and competition numbers: [`../BSNL-EXAM-ANALYSIS.md`](../BSNL-EXAM-ANALYSIS.md).

## How to use this course

1. **Read `00-exam-decode.md` first.** It changes how you attempt the paper more than any chapter will.
2. **Follow `02-study-plan-32-weeks.md`.** Do not improvise the order; the order is the strategy.
3. **After each chapter, do the quiz and exercises before moving on.** Reading without retrieval is the main reason people study 500 hours and score 95.
4. **Log every wrong answer** in the error log described in `03-revision-mocks-and-error-log.md`. Your error log is worth more than this course in month six.
