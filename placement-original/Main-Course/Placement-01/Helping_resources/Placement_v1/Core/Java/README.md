# ☕ Java Programming

## Learning Path

### [Fundamentals](Fundamentals/) (3 weeks)
**Week 1: Core Java**
- Syntax, data types, operators
- Control structures, arrays
- OOP: classes, objects, constructors
- **Practice:** 20 basic coding problems

**Week 2: Advanced OOP**
- Inheritance, polymorphism, abstraction
- Interfaces, abstract classes
- Exception handling, file I/O
- **Practice:** 25 OOP problems

**Week 3: Collections Framework**
- List: ArrayList, LinkedList, Vector
- Set: HashSet, TreeSet, LinkedHashSet
- Map: HashMap, TreeMap, LinkedHashMap
- **Practice:** 30 collection problems

### [Advanced](Advanced/) (2 weeks)
**Week 4: Concurrency**
- Threads, synchronization
- ExecutorService, thread pools
- Concurrent collections
- **Project:** Multi-threaded application

**Week 5: Modern Java**
- Lambda expressions, streams
- Optional, method references
- JVM internals, garbage collection
- **Project:** Stream-based data processing

### [Projects](Projects/)
**Beginner Projects:**
1. **Library Management System**
   - Classes, inheritance, file I/O
   - Collections for data storage
   - Exception handling

2. **Banking System**
   - Account management
   - Transaction processing
   - Data persistence

**Advanced Projects:**
3. **Multi-threaded Web Crawler**
   - Concurrent processing
   - Thread synchronization
   - Producer-consumer pattern

4. **REST API with Spring Boot**
   - Web services
   - Database integration
   - Modern Java features

## Interview Focus Areas

### Core Concepts
- **OOP Principles:** Inheritance, polymorphism, encapsulation, abstraction
- **Memory Management:** Heap vs stack, garbage collection
- **Collections:** ArrayList vs LinkedList, HashMap internals
- **Multithreading:** Synchronization, deadlocks, concurrent collections
- **Exception Handling:** Checked vs unchecked exceptions

### Coding Questions
- String manipulation problems
- Collection operations
- Multithreading scenarios
- Design pattern implementations
- Algorithm implementations in Java

### System Design
- Java application architecture
- Spring framework basics
- Database connectivity (JDBC)
- RESTful web services
- Microservices concepts
