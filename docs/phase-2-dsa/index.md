## Key Patterns

| Pattern | When to Use |
|---------|-------------|
| Two Pointer | Sorted arrays, palindromes |
| Sliding Window | Subarray/substring problems |
| HashMap | O(1) lookup needed |
| Fast/Slow Pointer | Cycle detection |
| DFS | Tree traversal, path finding |
| BFS | Level-order, shortest path |
| Binary Search | Sorted data, O(log n) |
