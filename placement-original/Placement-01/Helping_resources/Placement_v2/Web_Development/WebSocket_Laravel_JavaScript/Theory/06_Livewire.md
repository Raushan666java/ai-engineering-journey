# Livewire

## Introduction
Livewire is a full-stack framework for Laravel that makes building dynamic interfaces simple, without leaving Laravel.

## Key Topics
- Components & lifecycle
- Data binding
- Events & actions
- File uploads
- Polling & real-time updates
- Integrating with JavaScript
- Using Livewire with broadcasting

---

## Details
- **Components:** `php artisan make:livewire ComponentName`
- **Data Binding:** `wire:model`
- **Events:** `wire:click`, `emit`, `on`
- **Broadcasting:** Integrate with Laravel Echo for real-time features.
