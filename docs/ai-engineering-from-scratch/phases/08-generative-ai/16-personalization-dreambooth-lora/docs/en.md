# Personalization — DreamBooth, Textual Inversion, LoRA

> A pretrained diffusion model generates anything you describe in text. A personalized one generates *your cat, in your living room, wearing a top hat, at any angle.* The problem isn't teaching the model photography — it's teaching it one specific subject without forgetting everything it already knows.

**Type:** Learn
**Languages:** Python
**Prerequisites:** Phase 8 . 1 (Generative Models Taxonomy), Phase 8 . 15 (Diffusion Models and Stable Diffusion)
**Time:** ~50 minutes

## The Problem

A text-to-image model like Stable Diffusion learns a mapping from textual descriptions to images across billions of training pairs. It internalizes a vast distribution over visual concepts: objects, styles, viewpoints, lighting conditions. When you ask it to generate a picture of "a dog," it produces a statistically plausible dog — but not your dog. The problem is *identity preservation*: the model has never seen your specific subject, so it cannot reproduce it.

The naive approach — finetune the entire model on 3-5 images of your subject — causes catastrophic forgetting. The model overfits to those few examples and collapses its ability to generalize: it learns that "a dog" now means only your dog, and it can no longer generate dogs in new contexts, styles, or poses.

Three solutions have emerged, each making a different tradeoff between expressiveness, compute cost, and generalization:

1. **DreamBooth** — full finetuning of the UNet with a regularization trick that prevents forgetting.
2. **Textual Inversion** — no model weights change; you learn a new embedding token that plugs into the text encoder.
3. **LoRA** — freeze the base model and train small rank-decomposition matrices that steer the output.

## The Concept

All three methods operate on the same backbone — a latent diffusion model (see Lesson 15). Their differences reduce to *what gets updated* and *how overfitting is controlled*.

### Textual Inversion

Textual Inversion (Gal et al., 2022) is the lightest approach. The text encoder maps each word token to an embedding vector. Textual Inversion introduces a new placeholder token `S*` and learns its embedding vector `v_*` while keeping the entire diffusion model frozen.

The loss is the standard diffusion denoising objective, but only `v_*` is updated:

```
L = E_{z_t, c, epsilon, t} [ || epsilon - epsilon_theta(z_t, c, t) ||^2 ]
```

where `c` is the conditioning vector produced by the text encoder with the learned `v_*` inserted. Since the embedding is only a few thousand parameters (typically 768 or 1024 dimensions per token, times 1-4 tokens), training takes 5-15 minutes on a single GPU and produces a file under 100 KB.

The tradeoff: because the base model weights never change, Textual Inversion cannot represent visual details that fall outside the model's existing latent space. It captures the *gist* of a subject — its texture palette, rough shape, category affiliation — but often fails at exact identity replication. Faces, logos, and fine-grained objects tend to blur into the model's prior.

### DreamBooth

DreamBooth (Ruiz et al., 2023) takes the opposite approach: finetune the full UNet on your subject images. To prevent catastrophic forgetting, it introduces *prior preservation loss*.

During training, you supply two batches: (a) your subject images paired with the prompt `a [identifier] [class noun]` (e.g., "a sks dog"), and (b) generic images of the class generated by the frozen base model paired with the prompt `a [class noun]` (e.g., "a dog"). The loss becomes:

```
L = L_subject + lambda * L_prior
```

The prior term penalizes the model for deviating too far from its original behavior on the class. Conceptually: "Learn what makes this specific dog different from all other dogs, but stay close to what a dog looks like in general."

The identifier token is chosen to be rare in the tokenizer's vocabulary (e.g., "sks") so that it doesn't collide with existing semantic meanings. The class noun anchors the subject to its category.

DreamBooth delivers the highest fidelity — the generated subject is recognizably the same individual across poses, lighting, and styles. The cost is a full finetuning pass (200-1000 MB checkpoint) and a 15-30 minute training run.

### LoRA

Low-Rank Adaptation (LoRA, Hu et al., 2022) originated in large language models and was adapted to diffusion models. Instead of updating full weight matrices `W in R^{m x n}`, LoRA freezes `W` and learns a low-rank decomposition:

```
W' = W + B * A
```

where `B in R^{m x r}`, `A in R^{r x n}`, and `r << min(m, n)`. Typical ranks are 4, 8, 16, or 64. During training, only `A` and `B` receive gradients. At inference, `B*A` can be merged into `W` with zero additional latency.

For Stable Diffusion, LoRA is typically applied to the cross-attention projection matrices (`Q`, `K`, `V`, `out`) in the UNet. A rank-16 LoRA on SDXL adds roughly 3-5 million trainable parameters — about 0.1% of the full model. Training takes 10-20 minutes; the output is a 5-50 MB file.

LoRA strikes the middle ground: higher fidelity than Textual Inversion, smaller checkpoint than DreamBooth, and fast enough to iterate on. It is the most popular personalization method in the open-source ecosystem as of 2026.

### Comparison

| Method | Parameters trained | Output size | Training time | Identity fidelity | Generalization |
|--------|-------------------|-------------|---------------|-------------------|----------------|
| Textual Inversion | 1-4 embedding vectors | ~50-100 KB | 5-15 min | Low | Excellent |
| LoRA | 3-5M (rank-dep.) | ~5-50 MB | 10-20 min | High | Very good |
| DreamBooth | 860M+ (full UNet) | ~200-1000 MB | 15-30 min | Highest | Good (prior preserved) |

## The Build

The code below trains a LoRA on a set of subject images using Hugging Face diffusers. It follows the standard pipeline: load a base Stable Diffusion model, freeze all weights except the LoRA adapters, train on subject images with class prior preservation, and save the adapter.

```python
# lesson 16: Personalization — DreamBooth, Textual Inversion, LoRA
# Trains a LoRA adapter on a small set of subject images using diffusers.
# Reference: Hu et al. 2022 (LoRA), Ruiz et al. 2023 (DreamBooth prior preservation)

import torch
from diffusers import StableDiffusionXLPipeline, DDPMScheduler, AutoencoderKL
from diffusers.loaders import LoraLoaderMixin
from diffusers.models.attention_processor import LoRAAttnProcessor
from diffusers.optimization import get_scheduler
from transformers import CLIPTokenizer, CLIPTextModel
from torch.utils.data import Dataset, DataLoader
from PIL import Image
import os, math

# --- Configuration ---
SUBJECT_DIR = "./subject_images"      # 3-5 images of your subject
CLASS_DIR = "./class_images"           # pre-generated class images (prior preservation)
PLACEHOLDER_TOKEN = "sks"
CLASS_TOKEN = "dog"
RESOLUTION = 1024
LEARNING_RATE = 1e-4
TRAIN_BATCH_SIZE = 1
GRADIENT_ACCUMULATION_STEPS = 4
MAX_TRAIN_STEPS = 800
RANK = 16                             # LoRA rank

# --- Data preparation ---
# Generate class images using the frozen base model if not already present
def generate_class_images():
    if os.path.exists(CLASS_DIR) and len(os.listdir(CLASS_DIR)) >= 200:
        return
    pipe = StableDiffusionXLPipeline.from_pretrained(
        "stabilityai/stable-diffusion-xl-base-1.0",
        torch_dtype=torch.float16
    ).to("cuda")
    os.makedirs(CLASS_DIR, exist_ok=True)
    for i in range(200):
        image = pipe(f"a photo of a {CLASS_TOKEN}").images[0]
        image.save(f"{CLASS_DIR}/{i:04d}.png")
    del pipe

# --- Dataset ---
class SubjectDataset(Dataset):
    def __init__(self, image_dir, tokenizer, size=1024):
        self.paths = [os.path.join(image_dir, f) for f in os.listdir(image_dir)
                      if f.endswith((".png", ".jpg", ".jpeg"))]
        self.tokenizer = tokenizer
        self.size = size

    def __len__(self):
        return len(self.paths)

    def __getitem__(self, idx):
        image = Image.open(self.paths[idx]).convert("RGB").resize((self.size, self.size))
        pixel_values = torch.from_numpy(np.array(image)).float() / 127.5 - 1.0
        pixel_values = pixel_values.permute(2, 0, 1)
        prompt = f"a photo of {PLACEHOLDER_TOKEN} {CLASS_TOKEN}"
        tokens = self.tokenizer(prompt, padding="max_length", max_length=77,
                                truncation=True, return_tensors="pt")
        return {"pixel_values": pixel_values, "input_ids": tokens.input_ids.squeeze(0)}

# --- Model loading with LoRA preparation ---
model_id = "stabilityai/stable-diffusion-xl-base-1.0"
tokenizer = CLIPTokenizer.from_pretrained(model_id, subfolder="tokenizer")
text_encoder = CLIPTextModel.from_pretrained(model_id, subfolder="text_encoder").to("cuda")
vae = AutoencoderKL.from_pretrained(model_id, subfolder="vae").to("cuda")
pipe = StableDiffusionXLPipeline.from_pretrained(
    model_id, torch_dtype=torch.float16
).to("cuda")

# Freeze VAE and text encoder
vae.requires_grad_(False)
text_encoder.requires_grad_(False)

# Inject LoRA layers into cross-attention
lora_attn_procs = {}
for name in pipe.unet.attn_processors.keys():
    cross_attention_dim = None if name.endswith("attn1.processor") else pipe.unet.config.cross_attention_dim
    if name.startswith("mid_block"):
        hidden_size = pipe.unet.config.block_out_channels[-1]
    elif name.startswith("up_blocks"):
        block_id = int(name[len("up_blocks.")])
        hidden_size = list(reversed(pipe.unet.config.block_out_channels))[block_id]
    elif name.startswith("down_blocks"):
        block_id = int(name[len("down_blocks.")])
        hidden_size = pipe.unet.config.block_out_channels[block_id]
    lora_attn_procs[name] = LoRAAttnProcessor(
        hidden_size=hidden_size, cross_attention_dim=cross_attention_dim, rank=RANK
    )
pipe.unet.set_attn_processor(lora_attn_procs)
pipe.unet.to(dtype=torch.float16)

# Only LoRA parameters trainable
params_to_optimize = list(filter(lambda p: p.requires_grad, pipe.unet.parameters()))
optimizer = torch.optim.AdamW(params_to_optimize, lr=LEARNING_RATE)

# --- Dataset loaders ---
subject_dataset = SubjectDataset(SUBJECT_DIR, tokenizer, RESOLUTION)
class_dataset = SubjectDataset(CLASS_DIR, tokenizer, RESOLUTION)
subject_loader = DataLoader(subject_dataset, batch_size=TRAIN_BATCH_SIZE, shuffle=True)

# --- Noise scheduler ---
noise_scheduler = DDPMScheduler(
    beta_start=0.00085, beta_end=0.012, beta_schedule="scaled_linear",
    num_train_timesteps=1000, prediction_type="epsilon"
)

# --- Training loop ---
pipe.unet.train()
global_step = 0
while global_step < MAX_TRAIN_STEPS:
    for batch in subject_loader:
        with torch.no_grad():
            latents = vae.encode(batch["pixel_values"].to("cuda", dtype=torch.float16)).latent_dist.sample()
            latents = latents * vae.config.scaling_factor
        noise = torch.randn_like(latents)
        timesteps = torch.randint(0, noise_scheduler.config.num_train_timesteps,
                                  (latents.shape[0],), device="cuda").long()
        noisy_latents = noise_scheduler.add_noise(latents, noise, timesteps)
        encoder_hidden_states = text_encoder(batch["input_ids"].to("cuda"))[0]
        noise_pred = pipe.unet(noisy_latents, timesteps, encoder_hidden_states).sample
        loss_subject = torch.nn.functional.mse_loss(noise_pred, noise)

        # Prior preservation loss on class images
        class_batch = next(iter(DataLoader(class_dataset, batch_size=TRAIN_BATCH_SIZE, shuffle=True)))
        with torch.no_grad():
            class_latents = vae.encode(class_batch["pixel_values"].to("cuda", dtype=torch.float16)).latent_dist.sample()
            class_latents = class_latents * vae.config.scaling_factor
        class_noise = torch.randn_like(class_latents)
        class_noisy = noise_scheduler.add_noise(class_latents, class_noise, timesteps)
        class_encoding = text_encoder(class_batch["input_ids"].to("cuda"))[0]
        # For class images, replace placeholder with class-only prompt
        with torch.no_grad():
            frozen_pred = pipe.unet(class_noisy, timesteps, class_encoding).sample.detach()
        noise_pred_class = pipe.unet(class_noisy, timesteps, class_encoding).sample
        loss_prior = torch.nn.functional.mse_loss(noise_pred_class, frozen_pred)

        loss = loss_subject + 1.0 * loss_prior
        loss.backward()
        optimizer.step()
        optimizer.zero_grad()
        global_step += 1
        if global_step >= MAX_TRAIN_STEPS:
            break

# --- Save LoRA weights ---
pipe.unet.save_attn_procs("./lora-subject-checkpoint")
print(f"LoRA saved to ./lora-subject-checkpoint — load with load_lora_weights()")

# --- Inference with the saved LoRA ---
pipe.unet.load_attn_procs("./lora-subject-checkpoint")
image = pipe(f"a photo of {PLACEHOLDER_TOKEN} {CLASS_TOKEN} in a forest").images[0]
image.save("output-lora-subject.png")

# Training is similar but only the embedding tensor (not UNet params) receives gradients.
#
# embed = torch.nn.Embedding(1, tokenizer.model_max_length)
# optimizer = torch.optim.AdamW([embed.weight], lr=5e-4)
# ... same diffusion loss, but no prior preservation needed (model stays frozen).

# # The difference from LoRA: the entire UNet is unfrozen:
#   pipe.unet.requires_grad_(True)
# # and the checkpoint is saved as the full model, not just adapters.
```
