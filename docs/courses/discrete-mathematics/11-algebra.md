## Theory

### 11.1 Binary Operations

A **binary operation** $\ast$ on a set $S$ is a function $\ast: S \times S \rightarrow S$ (closure).

**Properties:**
- **Associative:** $(a \ast b) \ast c = a \ast (b \ast c)$.
- **Commutative:** $a \ast b = b \ast a$.
- **Identity element:** $e \ast a = a \ast e = a$ for all $a$.
- **Inverse:** $a \ast b = b \ast a = e$ (if identity $e$ exists).

### 11.2 Semigroups and Monoids

**Semigroup:** $(S, \ast)$ with associative $\ast$.

**Monoid:** A semigroup with an identity element.

Examples: $(\mathbb{Z}, +)$ is a monoid (identity 0). $(\mathbb{N}, \cdot)$ is a monoid (identity 1). $(\mathbb{Z}, -)$ is not a semigroup (not associative).

**Theorem 11.1.** The identity element in a monoid is unique.

### 11.3 Groups

**Group:** $(G, \ast)$ where $\ast$ is associative, there is an identity $e$, and every element has an inverse.

**Abelian group:** A group where $\ast$ is commutative.

**Theorem 11.2 (Uniqueness of inverses).** In a group, each element has exactly one inverse.

**Theorem 11.3 (Cancellation).** In a group, $a \ast b = a \ast c \implies b = c$ and $b \ast a = c \ast a \implies b = c$.

### 11.4 Subgroups

A **subgroup** $H \subseteq G$ is a subset that is itself a group under the same operation.

**Theorem 11.4 (Subgroup test).** $H \subseteq G$ is a subgroup iff: (1) $H \neq \emptyset$; (2) $a, b \in H \implies a \ast b \in H$; (3) $a \in H \implies a^{-1} \in H$.

**Order of element $g$:** smallest positive $n$ such that $g^n = e$ (or $\infty$ if none).

### 11.5 Cosets and Lagrange's Theorem

**Left coset** of $H$ by $g$: $gH = \{g \ast h \mid h \in H\}$.

**Theorem 11.5 (Lagrange).** For a finite group $G$ and subgroup $H$, $|H|$ divides $|G|$. The index $[G:H] = |G|/|H|$ is the number of cosets.

### 11.6 Normal Subgroups and Quotient Groups

A subgroup $N$ is **normal** if $g N g^{-1} = N$ for all $g \in G$. The set of cosets $G/N = \{gN \mid g \in G\}$ forms the **quotient group** under $(gN)(hN) = (gh)N$.

### 11.7 Rings and Fields

**Ring:** $(R, +, \cdot)$ where $(R, +)$ is an abelian group, $\cdot$ is associative, and distributivity holds: $a(b+c) = ab + ac$, $(a+b)c = ac + bc$.

- **Commutative ring:** $\cdot$ is commutative.
- **Ring with unity:** $\cdot$ has identity (usually $1$).
- **Integral domain:** commutative ring with unity, no zero divisors ($ab = 0 \implies a = 0$ or $b = 0$).

**Field:** A commutative ring with unity where every nonzero element has a multiplicative inverse.

Examples: $\mathbb{Q}, \mathbb{R}, \mathbb{C}, \mathbb{Z}_p$ (where $p$ is prime) are fields. $\mathbb{Z}$ is an integral domain but not a field.

### 11.8 Homomorphisms

**Group homomorphism:** $\phi: G \rightarrow H$ with $\phi(a \ast b) = \phi(a) \ast \phi(b)$.

**Ring homomorphism:** preserves both $+$ and $\cdot$.

**Isomorphism:** bijective homomorphism. Isomorphic structures are algebraically identical ($G \cong H$).

**Kernel:** $\ker \phi = \{g \in G \mid \phi(g) = e_H\}$.

**Theorem 11.6 (First Isomorphism Theorem).** $G / \ker \phi \cong \text{im } \phi$.

### 11.9 Applications in CS

- **Cyclic groups** underpin Diffie-Hellman key exchange and ElGamal encryption.
- **Finite fields** $\mathbb{F}_{2^k}$ are the foundation of AES and Reed-Solomon codes.
- **Semigroups and monoids** model automata (transition monoids) and formal languages.
- **Group theory** is essential in symmetry analysis and computational chemistry.

## Examples

**Example 11.1** (Group check). Is $(\mathbb{Z}, -)$ a group?

*Solution.* No: subtraction is not associative. $(3 - 2) - 1 = 0$ but $3 - (2 - 1) = 2$. Also, there is no identity (no $e$ such that $a - e = a$ for all $a$).

**Example 11.2** (Cyclic group). $(\mathbb{Z}_6, +)$ is a cyclic group of order 6, generated by $1$ (or $5$). Subgroup generated by $2$: $\{0, 2, 4\}$ of order 3 (divides 6).

**Example 11.3** ($\mathbb{Z}_p$ as field). $\mathbb{Z}_7$ is a field. Every nonzero element $1,2,3,4,5,6$ has a multiplicative inverse: $1\cdot1=1$, $2\cdot4=8\equiv1$, $3\cdot5=15\equiv1$, $6\cdot6=36\equiv1$.

**Example 11.4** (Homomorphism). $\phi: \mathbb{Z} \rightarrow \mathbb{Z}_n$ defined by $\phi(k) = k \bmod n$ is a group homomorphism (addition) and a ring homomorphism. $\ker \phi = n\mathbb{Z}$ (multiples of $n$). By the first isomorphism theorem: $\mathbb{Z} / n\mathbb{Z} \cong \mathbb{Z}_n$.

**Example 11.5** (Permutation group). $S_3$ (symmetric group on 3 elements) has order 6. Its subgroups: $\{e\}$ (order 1), three subgroups of order 2 (transpositions), $A_3 = \{e, (123), (132)\}$ (order 3), and itself.

**Example 11.6** (Lagrange's theorem). In $S_3$ of order 6, possible subgroup orders are 1, 2, 3, 6. There is no subgroup of order 4, since 4 does not divide 6.

## Summary

- Groups have associativity, identity, and inverses. Abelian groups are commutative.
- Subgroup orders divide group order (Lagrange). Cosets partition the group.
- Rings have two operations; fields are rings with multiplicative inverses.
- Homomorphisms preserve structure; isomorphisms indicate structural identity.
- Finite fields $\mathbb{F}_{p^k}$ and cyclic groups are essential in cryptography.

9. Let $\phi: G \rightarrow H$ be a group homomorphism. Prove: $\ker \phi$ is a normal subgroup of $G$.
