# Operating Systems (OS) Detailed Syllabus

## A. Process Management

- Process Concept: definition, life cycle, states, state transition diagram
- Process Control Block (PCB): fields and structure
- Threads: user vs kernel, models, benefits, libraries
- Multithreading: creation, synchronization, issues
- Scheduling Algorithms: FCFS, SJF, SRTF, Priority, RR, Multilevel Queue, Feedback Queue, criteria, Gantt charts
- Context Switching: steps, overhead
- Orphan and Zombie Processes: definitions, handling

## B. Inter-Process Communication (IPC)

- Pipes, shared memory, message queues
- Signals, semaphores, monitors
- Sockets, RPC

## C. Deadlock

- Deadlock conditions, prevention, avoidance, detection, recovery
- Banker's algorithm, wait-for graph

## D. Memory Management

- Memory hierarchy, address binding
- Contiguous allocation, fragmentation
- Paging, segmentation, page tables
- Virtual memory, demand paging, page replacement algorithms
- Thrashing, locality of reference

## E. File System & I/O Management

- File concepts, directory structures
- File allocation methods, free space management
- I/O devices, device controllers, DMA
- Disk scheduling algorithms, RAID levels

## F. Synchronization

- Critical section problem
- Mutex, semaphore, monitors
- Condition variables
- Classic problems: producer-consumer, readers-writers, dining philosophers, sleeping barber

## G. Linux Commands

- Basic commands: ls, cd, pwd, cp, mv, rm, grep, chmod, ps, top, kill, man, touch, mkdir, rmdir
- File permissions, process management, networking commands
