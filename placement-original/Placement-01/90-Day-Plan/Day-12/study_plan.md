# Day 12 Study Plan — Trees (Part 1)

## Overview
Day 12 covers **Binary Trees and Binary Search Trees** — traversal algorithms (inorder, preorder, postorder), level order traversal, and BST insertion/search. Trees are foundational for many algorithms and large-scale data structure problems.

## Daily Schedule (9 hours total)

### Morning Session (3 hours) — Binary Tree Basics
**Time: 9:00 AM - 12:00 PM**
- **Hour 1**: Binary tree structure & node design. Create basic binary tree class, implement `insertLeft`, `insertRight`.
- **Hour 2**: Depth, height, and tree traversal theory. Learn recursion use for traversals.
- **Hour 3**: Implement `tree_traversals.java` — preorder, inorder, postorder; dry-run examples on small trees.

### Afternoon Session (3 hours) — Level Order & BST basics
**Time: 1:00 PM - 4:00 PM**
- **Hour 1**: Level order (BFS) traversal using Queue; practice with `binary_tree_basics.java`.
- **Hour 2**: Binary Search Tree theory (insertion, search). Understand ordering invariants and time complexity.
- **Hour 3**: Implement `bst_operations.java` — insert, search, min/max, delete (conceptual); run small tests.

### Evening Session (3 hours) — Practice problems & interview prep
**Time: 5:00 PM - 8:00 PM**
- **Hour 1**: Run `tree_problems.java` — solve typical tree problems (max depth, balanced tree check, symmetric tree)
- **Hour 2**: `practice_problems.java` — 10 tree problems; practice on LeetCode or local environment
- **Hour 3**: Interview prep: explain traversals, implement recursive and iterative traversals, analyze complexity

## Learning Objectives
- Implement Binary Tree node and different traversal strategies (recursion & iteration)  
- Implement BFS level order traversal using Queue  
- Understand and implement BST insertion & search  
- Analyze time and space complexity for common tree operations  
- Solve tree problems like max depth, is symmetric, lowest common ancestor (LCA) basics

## Resources Required
- `binary_tree_basics.java` — Basic tree creation & level order traversal
- `tree_traversals.java` — Inorder, Preorder, Postorder (recursive & iterative) implementation
- `bst_operations.java` — BST insert/search examples
- `tree_problems.java` — Suggested problems to practice
- `practice_problems.java` — 10 tree problems for the day

## Expected Outcomes
- Be able to implement tree traversals both recursively and iteratively  
- Be able to build and test a BST implementation and perform basic operations  
- Understand BFS and DFS variations on trees and their complexities  
- Solve basic to intermediate tree problems used frequently on interviews

## Notes
- Focus on understanding recursion stack usage for traversals (space complexity)  
- For iterative traversals, practice using stacks and queues  
- Watch out for null-handling in traversal implementations  
- Review Day 9 and Day 10 linked list concepts for cross-topic reinforcement
