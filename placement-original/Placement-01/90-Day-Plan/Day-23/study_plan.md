# Day 23 Study Plan: Advanced Graphs

## Daily Schedule (9 hours total)

### Morning Session (3 hours)
- Topic: Topological sort & cycle detection
  - Read Kahn and DFS-based topological sorts
  - Implement cycle detection using DFS

### Afternoon Session (3 hours)
- Topic: Strongly Connected Components (SCCs)
  - Implement Kosaraju's algorithm
  - Test SCC grouping

### Evening Session (3 hours)
- Topic: Negative weights & all-pairs paths
  - Implement Bellman-Ford (single source with negative weights)
  - Implement Floyd-Warshall (all pairs shortest path)

## Learning Objectives
- Learn to detect cycles and perform topological sorting.
- Understand SCCs and their applications.
- Recognize when to use Bellman-Ford vs Dijkstra.

## Expected Outcomes
- Working Java demonstration of each algorithm and simple test cases for validation.
