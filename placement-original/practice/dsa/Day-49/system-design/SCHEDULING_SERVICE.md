# Day 49 System Design: Scheduling Service (Greedy Applications)

## Overview
Design a scheduling system that assigns tasks to resources using greedy algorithms for efficiency and fairness.

## Components
- API for task submission
- Scheduler: greedy algorithm (e.g., earliest finish first, highest priority)
- Queue management with priority queues
- Monitoring: task completion times and SLA tracking

## Considerations
- Use approximation when optimal scheduling is NP-hard
- Consider fairness constraints and SLA prioritization
- Use batching and backpressure to handle spikes
