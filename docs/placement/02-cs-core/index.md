## OS — Operating Systems

**Location**: `Placement/Placement-01/02-CS-Core/04-OS/`

Topics karo:

- Process Management (states, scheduling algorithms)
- Memory Management (paging, segmentation, virtual memory)
- File Systems (allocation, inodes)
- Synchronization (semaphores, mutex, deadlock)
- CPU Scheduling (FCFS, SJF, Round Robin, Priority)

## DBMS — Database Management Systems

**Location**: `Placement/Placement-01/02-CS-Core/02-DBMS/`

Topics:

- SQL: DDL, DML, Joins, Subqueries, Window Functions
- Normalization: 1NF → BCNF
- ACID Properties, Transactions, Concurrency Control
- Indexing strategies
- NoSQL intro: MongoDB, Cassandra, CAP Theorem

## CN — Computer Networks

**Location**: `Placement/Placement-01/02-CS-Core/03-CN/`

Topics:

- OSI Model (7 layers ka dhyaan rakho)
- TCP/IP Model
- HTTP/HTTPS, DNS, DHCP
- TCP vs UDP
- IP Addressing, Subnetting
- Network Security basics (Firewall, VPN, SSL/TLS)

## CO — Computer Organization

Basic architecture: Von Neumann, CPU, Memory Hierarchy, Pipelining. Reference `Placement/Placement-01/02-CS-Core/` mein related docs.

## TOC — Theory of Computation

Automata theory, Regular Languages, Context Free Grammars, Turing Machines. Basic concepts kaafi hain.

## 90-Day Plan Alignment

`Placement/Placement-01/90-Day-Plan/` mein har din ka topic likha hai:

- Days 31-60: Advanced DSA + OS + DBMS
- Days 61-90: CN + System Design + Interview Prep
