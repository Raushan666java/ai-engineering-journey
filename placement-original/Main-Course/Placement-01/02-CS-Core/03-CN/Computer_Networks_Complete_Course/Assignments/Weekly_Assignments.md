# Weekly Assignments - Computer Networks Course

## Assignment Structure
Each week includes theoretical questions, practical labs, and design projects to reinforce learning.

## Week 1: Network Fundamentals
**Assignment 1.1: Network Topology Design**
- Design network topologies for small office (20 users)
- Compare bus, star, ring, and mesh topologies
- Calculate cost-benefit analysis for each topology

**Assignment 1.2: OSI Model Analysis**
- Create detailed comparison of OSI vs TCP/IP models
- Map real-world protocols to each layer
- Analyze data encapsulation process

## Week 2: Physical Layer
**Assignment 2.1: Cable Selection Project**
- Design cabling infrastructure for 3-story building
- Select appropriate cable types for different scenarios
- Calculate cable lengths and attenuation

**Assignment 2.2: Signal Analysis**
- Analyze different encoding schemes (Manchester, NRZ)
- Calculate bandwidth requirements for various applications
- Design multiplexing solution for multiple data streams

## Week 3: Data Link Layer
**Assignment 3.1: Ethernet Frame Analysis**
- Capture and analyze Ethernet frames using Wireshark
- Identify frame fields and their purposes
- Calculate frame efficiency for different payload sizes

**Assignment 3.2: VLAN Design Project**
- Design VLAN structure for medium enterprise (200 users)
- Configure VLANs in Packet Tracer
- Implement inter-VLAN routing

## Week 4: Network Layer
**Assignment 4.1: Subnetting Challenge**
- Subnet 172.16.0.0/16 for company with 5 departments
- Use VLSM for optimal address utilization
- Document IP addressing scheme

**Assignment 4.2: Routing Protocol Comparison**
- Compare RIP, OSPF, and EIGRP protocols
- Configure each protocol in simulation
- Analyze convergence times and scalability

## Week 5: Transport Layer
**Assignment 5.1: TCP vs UDP Analysis**
- Implement file transfer using both TCP and UDP
- Compare performance and reliability
- Analyze packet captures for both protocols

**Assignment 5.2: Socket Programming**
- Create client-server application using sockets
- Implement error handling and flow control
- Test with multiple concurrent connections

## Week 6: Application Layer
**Assignment 6.1: DNS Server Setup**
- Configure DNS server with forward and reverse zones
- Implement DNS hierarchy with multiple domains
- Test DNS resolution and caching

**Assignment 6.2: Web Server Configuration**
- Set up Apache/Nginx web server
- Configure HTTPS with SSL certificates
- Implement virtual hosts for multiple domains

## Week 7: Network Security
**Assignment 7.1: Firewall Configuration**
- Design firewall rules for enterprise network
- Implement DMZ with web and email servers
- Test security policies with penetration testing tools

**Assignment 7.2: VPN Implementation**
- Configure site-to-site VPN between two offices
- Set up remote access VPN for mobile users
- Analyze VPN performance and security

## Week 8: Wireless Networks
**Assignment 8.1: WiFi Site Survey**
- Conduct wireless site survey for office building
- Plan optimal access point placement
- Configure enterprise WiFi with multiple SSIDs

**Assignment 8.2: IoT Network Design**
- Design IoT network for smart building
- Select appropriate wireless technologies
- Implement security for IoT devices

## Week 9: Network Management
**Assignment 9.1: SNMP Monitoring Setup**
- Configure SNMP on network devices
- Set up network monitoring with open-source tools
- Create custom dashboards and alerts

**Assignment 9.2: Network Documentation**
- Create comprehensive network documentation
- Develop troubleshooting procedures
- Design change management process

## Week 10: Enterprise Networking
**Assignment 10.1: Campus Network Design**
- Design hierarchical network for university campus
- Implement redundancy and high availability
- Configure QoS for different traffic types

**Assignment 10.2: WAN Connectivity**
- Compare MPLS, SD-WAN, and Internet VPN solutions
- Design WAN architecture for multi-site company
- Calculate costs and performance metrics

## Week 11: Cloud Networking
**Assignment 11.1: AWS VPC Design**
- Design multi-tier VPC architecture
- Configure hybrid connectivity with Direct Connect
- Implement security groups and NACLs

**Assignment 11.2: Container Networking**
- Deploy Kubernetes cluster with custom networking
- Configure network policies for microservices
- Implement service mesh with Istio

## Week 12: Emerging Technologies
**Assignment 12.1: SDN Implementation**
- Set up OpenDaylight SDN controller
- Program custom network applications
- Compare SDN vs traditional networking

**Assignment 12.2: 5G Network Planning**
- Design 5G network for smart city
- Implement network slicing for different use cases
- Analyze performance requirements

## Week 13: Labs and Simulation
**Assignment 13.1: Comprehensive Lab**
- Build complete enterprise network in GNS3
- Implement all learned technologies
- Perform comprehensive testing and optimization

**Assignment 13.2: Automation Project**
- Create network automation scripts using Python
- Implement configuration management with Ansible
- Develop monitoring and alerting system

## Week 14: Capstone Project
**Assignment 14.1: Final Project**
- Choose from provided capstone project options
- Complete design, implementation, and documentation
- Present solution to panel of experts

## Assignment Submission Guidelines
- All assignments must be submitted by Sunday 11:59 PM
- Include both documentation and configuration files
- Provide screenshots and packet captures as evidence
- Follow professional documentation standards

## Grading Rubric
- **Technical Accuracy** (40%): Correct implementation and configuration
- **Documentation Quality** (25%): Clear, comprehensive documentation
- **Analysis and Insight** (20%): Understanding of concepts and trade-offs
- **Presentation** (15%): Professional presentation of work
