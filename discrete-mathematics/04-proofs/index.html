Theory​

4.1 Direct Proof​

A direct proof of P  ⟹  QP \implies QP⟹Q assumes PPP is true and uses logical reasoning, definitions, and known theorems to derive QQQ.

Theorem 4.1. If nnn is an even integer, then n2n^2n2 is even.

Proof. Let nnn be an even integer. Then n=2kn = 2kn=2k for some integer kkk. Then n2=(2k)2=4k2=2(2k2)n^2 = (2k)^2 = 4k^2 = 2(2k^2)n2=(2k)2=4k2=2(2k2), which is even. □\square□

Theorem 4.2 (Sum of evens). The sum of two even integers is even.

Proof. Let a=2ka = 2ka=2k and b=2mb = 2mb=2m be even. Then a+b=2k+2m=2(k+m)a + b = 2k + 2m = 2(k + m)a+b=2k+2m=2(k+m), which is even. □\square□

One-Sentence Takeaway: A direct proof starts from the hypothesis and applies definitions and theorems step-by-step to reach the conclusion.

4.2 Proof by Contrapositive​

The contrapositive of P  ⟹  QP \implies QP⟹Q is ¬Q  ⟹  ¬P\neg Q \implies \neg P¬Q⟹¬P. Since they are logically equivalent, proving the contrapositive proves the original statement.

Theorem 4.3. If n2n^2n2 is odd, then nnn is odd.

Proof. We prove the contrapositive: if nnn is even, then n2n^2n2 is even. This is Theorem 4.1 above. □\square□

Theorem 4.4. If xxx and yyy are real numbers and xyxyxy is irrational, then at least one of xxx or yyy is irrational.

Proof. Contrapositive: if both xxx and yyy are rational, then xyxyxy is rational. Let x=a/bx = a/bx=a/b and y=c/dy = c/dy=c/d with integers a,b,c,da,b,c,da,b,c,d and b,d≠0b,d \neq 0b,d=0. Then xy=(ac)/(bd)xy = (ac)/(bd)xy=(ac)/(bd), which is rational. □\square□

One-Sentence Takeaway: Proving the contrapositive ¬Q→¬P\neg Q \rightarrow \neg P¬Q→¬P is logically equivalent to proving P→QP \rightarrow QP→Q, and is often more direct.

4.3 Proof by Contradiction​

A proof by contradiction assumes the negation of the statement to be proved and derives a logical contradiction (F≡falseF \equiv \text{false}F≡false). This shows the original statement must be true.

Theorem 4.5. 2\sqrt{2}2​ is irrational.

Proof. Assume, for contradiction, that 2\sqrt{2}2​ is rational. Then 2=a/b\sqrt{2} = a/b2​=a/b where a,b∈Za, b \in \mathbb{Z}a,b∈Z, b≠0b \neq 0b=0, and gcd⁡(a,b)=1\gcd(a,b) = 1gcd(a,b)=1 (fraction in lowest terms). Squaring gives 2=a2/b22 = a^2 / b^22=a2/b2, so a2=2b2a^2 = 2b^2a2=2b2. Thus a2a^2a2 is even, so aaa is even. Write a=2ka = 2ka=2k. Then (2k)2=2b2  ⟹  4k2=2b2  ⟹  b2=2k2(2k)^2 = 2b^2 \implies 4k^2 = 2b^2 \implies b^2 = 2k^2(2k)2=2b2⟹4k2=2b2⟹b2=2k2, so b2b^2b2 is even and bbb is even. But then aaa and bbb share the factor 2, contradicting gcd⁡(a,b)=1\gcd(a,b) = 1gcd(a,b)=1. Hence 2\sqrt{2}2​ is irrational. □\square□

Theorem 4.6. There are infinitely many primes.

Proof. Assume, to the contrary, that there are finitely many primes p1,p2,…,pkp_1, p_2, \ldots, p_kp1​,p2​,…,pk​. Consider N=p1p2⋯pk+1N = p_1 p_2 \cdots p_k + 1N=p1​p2​⋯pk​+1. Since N>1N > 1N>1, NNN has a prime divisor ppp. But ppp cannot be any pip_ipi​ because N≡1(modpi)N \equiv 1 \pmod{p_i}N≡1(modpi​) for each iii. Hence ppp is a prime not in our list ? contradiction. □\square□

function isPrime(n: number): boolean {
  if (n < 2) return false;
  for (let i = 2; i * i <= n; i++) {
    if (n % i === 0) return false;
  }
  return true;
}

// Show that there exist primes beyond any given bound
function findPrimeBeyond(N: number): number {
  // Construct M = N! + 1 (like the Euclid construction)
  let factorial = 1;
  for (let i = 2; i <= N; i++) factorial *= i;
  const M = factorial + 1;
  // Find its smallest prime factor
  for (let i = 2; i * i <= M; i++) {
    if (M % i === 0) return i;
  }
  return M; // M itself is prime
}

console.log(findPrimeBeyond(10)); // some prime > 10

One-Sentence Takeaway: Proof by contradiction assumes the statement is false, derives an impossible consequence, and concludes the statement must be true.

4.4 Counterexample​

To disprove a universally quantified statement ∀x  P(x)\forall x\; P(x)∀xP(x), it suffices to find a single element ccc (a counterexample) for which P(c)P(c)P(c) is false.

Example 4.1. Disprove: "All prime numbers are odd."

Counterexample. 2 is prime and not odd. □\square□

Example 4.2. Disprove: "n2+n+41n^2 + n + 41n2+n+41 is prime for all positive integers nnn."

Counterexample. For n=41n = 41n=41, we get 412+41+41=41(41+1+1)=41⋅4341^2 + 41 + 41 = 41(41 + 1 + 1) = 41 \cdot 43412+41+41=41(41+1+1)=41⋅43, which is composite. □\square□

One-Sentence Takeaway: One carefully chosen counterexample is sufficient to refute any universal claim ? you never need to disprove "all" by checking everything.

4.5 Mathematical Induction​

Principle of Mathematical Induction. Let P(n)P(n)P(n) be a statement for each integer n≥n0n \geq n_0n≥n0​. If:

  1. Base case: P(n0)P(n_0)P(n0​) is true, and
  2. Inductive step: For all k≥n0k \geq n_0k≥n0​, P(k)  ⟹  P(k+1)P(k) \implies P(k+1)P(k)⟹P(k+1),

then P(n)P(n)P(n) is true for all n≥n0n \geq n_0n≥n0​.

Theorem 4.7. For all n≥1n \geq 1n≥1, ∑i=1ni=n(n+1)2\sum_{i=1}^{n} i = \frac{n(n+1)}{2}∑i=1n​i=2n(n+1)​.

Proof. (Base) n=1n = 1n=1: LHS =1= 1=1, RHS =1(2)/2=1= 1(2)/2 = 1=1(2)/2=1. ?

(Inductive step) Assume ∑i=1ki=k(k+1)2\sum_{i=1}^{k} i = \frac{k(k+1)}{2}∑i=1k​i=2k(k+1)​. Then: ∑i=1k+1i=(∑i=1ki)+(k+1)=k(k+1)2+(k+1)=k(k+1)+2(k+1)2=(k+1)(k+2)2\sum_{i=1}^{k+1} i = \left(\sum_{i=1}^{k} i\right) + (k+1) = \frac{k(k+1)}{2} + (k+1) = \frac{k(k+1) + 2(k+1)}{2} = \frac{(k+1)(k+2)}{2}∑i=1k+1​i=(∑i=1k​i)+(k+1)=2k(k+1)​+(k+1)=2k(k+1)+2(k+1)​=2(k+1)(k+2)​ Thus P(k)  ⟹  P(k+1)P(k) \implies P(k+1)P(k)⟹P(k+1). By induction, true for all n≥1n \geq 1n≥1. □\square□

Theorem 4.8 (Inequality). 2n≥n+12^n \geq n+12n≥n+1 for all n≥1n \geq 1n≥1.

Proof. Base n=1n=1n=1: 21=2≥22^1 = 2 \geq 221=2≥2. ?. Assume 2k≥k+12^k \geq k+12k≥k+1. Then 2k+1=2⋅2k≥2(k+1)=2k+2≥k+22^{k+1} = 2 \cdot 2^k \geq 2(k+1) = 2k+2 \geq k+22k+1=2⋅2k≥2(k+1)=2k+2≥k+2 for k≥1k \geq 1k≥1. So P(k)  ⟹  P(k+1)P(k) \implies P(k+1)P(k)⟹P(k+1). □\square□

// Verifying the sum formula by induction with TypeScript
function sumFormula(n: number): number {
  return (n * (n + 1)) / 2;
}

function verifySumByLoop(n: number): number {
  let sum = 0;
  for (let i = 1; i <= n; i++) sum += i;
  return sum;
}

// Test for first 100 numbers
for (let n = 1; n <= 100; n++) {
  if (sumFormula(n) !== verifySumByLoop(n)) {
    console.log(`Mismatch at n = ${n}`);
  }
}
console.log("All checks passed for n = 1 to 100");

One-Sentence Takeaway: Induction proves a statement for all natural numbers by showing it holds for the first one and that truth at kkk implies truth at k+1k+1k+1.

4.6 Strong Induction​

Principle of Strong Induction. If:

  1. Base case(s): P(n0),P(n0+1),…,P(m)P(n_0), P(n_0+1), \ldots, P(m)P(n0​),P(n0​+1),…,P(m) are true, and
  2. Strong inductive step: For all k≥mk \geq mk≥m, P(n0)∧⋯∧P(k)  ⟹  P(k+1)P(n_0) \land \cdots \land P(k) \implies P(k+1)P(n0​)∧⋯∧P(k)⟹P(k+1),

then P(n)P(n)P(n) is true for all n≥n0n \geq n_0n≥n0​.

Strong induction assumes all smaller instances, not just the immediate predecessor.

Theorem 4.9. Every integer n≥2n \geq 2n≥2 can be expressed as a product of primes.

Proof. (Base) n=2n = 2n=2 is prime. ?

(Strong inductive step) Assume every integer 2,3,…,k2, 3, \ldots, k2,3,…,k is a product of primes. Consider k+1k+1k+1. If k+1k+1k+1 is prime, we are done. If k+1k+1k+1 is composite, then k+1=abk+1 = abk+1=ab where 2≤a,b≤k2 \leq a, b \leq k2≤a,b≤k. By the inductive hypothesis, aaa and bbb are products of primes, so their product k+1k+1k+1 is also a product of primes. □\square□

Theorem 4.10 (Fibonacci inequality). The Fibonacci sequence F1=1F_1 = 1F1​=1, F2=1F_2 = 1F2​=1, Fn=Fn−1+Fn−2F_n = F_{n-1} + F_{n-2}Fn​=Fn−1​+Fn−2​ for n≥3n \geq 3n≥3 satisfies F_n &lt; 2^n for all n≥1n \geq 1n≥1.

Proof. Base: F_1 = 1 &lt; 2^1, F2=1<22F_2 = 1 < 2^2F2​=1<22. ?. Assume Fi<2iF_i < 2^iFi​<2i for all i≤ki \leq ki≤k. Then Fk+1=Fk+Fk−1<2k+2k−1<2k+2k=2k+1F_{k+1} = F_k + F_{k-1} < 2^k + 2^{k-1} < 2^k + 2^k = 2^{k+1}Fk+1​=Fk​+Fk−1​<2k+2k−1<2k+2k=2k+1. □\square□

One-Sentence Takeaway: Strong induction lets you assume the statement holds for all smaller numbers, not just the immediate predecessor ? essential when P(k+1)P(k+1)P(k+1) depends on P(k−1)P(k-1)P(k−1) or earlier.

4.7 Structural Induction​

Structural induction proves properties of recursively defined sets (e.g., trees, lists, formulas). For each constructor in the recursive definition, prove that if all sub-instances satisfy the property, then the constructed instance does as well.

Example (Full binary trees). Define: a single vertex is a full binary tree. If T1T_1T1​ and T2T_2T2​ are full binary trees, then (T1,r,T2)(T_1, r, T_2)(T1​,r,T2​) is a full binary tree with root rrr, left subtree T1T_1T1​, and right subtree T2T_2T2​.

Theorem 4.11. In any full binary tree, the number of vertices vvv and the number of edges eee satisfy v=e+1v = e + 1v=e+1.

Proof. By structural induction.

Base: A single vertex has v=1v = 1v=1, e=0e = 0e=0, so 1=0+11 = 0 + 11=0+1. ?

Inductive step: Let TTT be built from subtrees T1T_1T1​ and T2T_2T2​. Assume T1T_1T1​ satisfies v1=e1+1v_1 = e_1 + 1v1​=e1​+1 and T2T_2T2​ satisfies v2=e2+1v_2 = e_2 + 1v2​=e2​+1. Then TTT has v=v1+v2+1v = v_1 + v_2 + 1v=v1​+v2​+1 vertices and e=e1+e2+2e = e_1 + e_2 + 2e=e1​+e2​+2 edges (two new edges from root to each subtree). So v=v1+v2+1=(e1+1)+(e2+1)+1=e1+e2+3=(e1+e2+2)+1=e+1v = v_1 + v_2 + 1 = (e_1 + 1) + (e_2 + 1) + 1 = e_1 + e_2 + 3 = (e_1 + e_2 + 2) + 1 = e + 1v=v1​+v2​+1=(e1​+1)+(e2​+1)+1=e1​+e2​+3=(e1​+e2​+2)+1=e+1. □\square□

One-Sentence Takeaway: Structural induction mirrors the recursive definition of a data type ? prove the base constructors and prove that the property is preserved by each recursive constructor.

4.8 Proof by Cases​

Sometimes a statement can be proved by dividing the domain into exhaustive cases and proving each case separately.

Theorem 4.12. For any integer nnn, n2 mod 3n^2 \bmod 3n2mod3 is either 000 or 111 (never 222).

Proof. Every integer can be written as n=3kn = 3kn=3k, n=3k+1n = 3k+1n=3k+1, or n=3k+2n = 3k+2n=3k+2 (three cases by division algorithm).

  • Case 1: n=3k  ⟹  n2=9k2≡0(mod3)n = 3k \implies n^2 = 9k^2 \equiv 0 \pmod{3}n=3k⟹n2=9k2≡0(mod3).
  • Case 2: n=3k+1  ⟹  n2=9k2+6k+1≡1(mod3)n = 3k+1 \implies n^2 = 9k^2 + 6k + 1 \equiv 1 \pmod{3}n=3k+1⟹n2=9k2+6k+1≡1(mod3).
  • Case 3: n=3k+2  ⟹  n2=9k2+12k+4≡1(mod3)n = 3k+2 \implies n^2 = 9k^2 + 12k + 4 \equiv 1 \pmod{3}n=3k+2⟹n2=9k2+12k+4≡1(mod3).

In all cases, n2n^2n2 is 000 or 111 mod 333. □\square□

One-Sentence Takeaway: Case analysis divides the domain into exhaustive partitions; proving each partition separately establishes the whole claim.

4.9 Existence Proofs​

An existence proof demonstrates that ∃x  P(x)\exists x\; P(x)∃xP(x) is true. Constructive proofs exhibit an explicit ccc with P(c)P(c)P(c). Non-constructive proofs show existence without producing an example (e.g., by contradiction or pigeonhole principle).

Constructive example: Prove there exists a prime number between 10 and 20. Exhibit 111111 ? it is prime, and 10 &lt; 11 < 20.

Non-constructive example: Prove that for any 5 points in a unit square, some pair is at most 2/2\sqrt{2}/22​/2 apart. The pigeonhole principle shows existence but does not say which pair.

Pro Tip: Start with direct proof ? it is the most straightforward. If direct proof stalls, try the contrapositive. If that also fails, fall back to contradiction.

Pro Tip: For existence proofs, always try a constructive approach first. The explicit witness makes the proof more informative.

Warning: Induction can only prove statements about well-ordered sets (typically natural numbers). It does not apply to real numbers or arbitrary infinite sets.

Warning: When using proof by contradiction, be careful that the contradiction you derive actually follows from the assumption ? a "contradiction" that is merely unexpected is not a valid proof.

Example 4.3 (Direct proof). Prove that the sum of two odd integers is even.

Example 4.8 (Proof by contradiction ? no largest integer). Prove there is no largest integer.

Proof. Assume, to the contrary, that MMM is the largest integer. Then M+1M + 1M+1 is an integer greater than MMM, contradicting the maximality of MMM. Hence no largest integer exists. □\square□

Example 4.9 (Pigeonhole ? nonconstructive existence). In any set of 13 distinct integers, some pair has a difference divisible by 12.

Proof. Consider the residues of each integer modulo 12. There are 12 possible residues (000 through 111111). By the pigeonhole principle, with 13 integers, two must share the same residue. Their difference is divisible by 12. □\square□

Summary​

  • Direct proof: assume hypothesis, derive conclusion.
  • Contrapositive: prove ¬Q  ⟹  ¬P\neg Q \implies \neg P¬Q⟹¬P instead of P  ⟹  QP \implies QP⟹Q.
  • Contradiction: assume false, derive contradiction.
  • Induction: base case + P(k)  ⟹  P(k+1)P(k) \implies P(k+1)P(k)⟹P(k+1) over natural numbers.
  • Strong induction: base cases + P(all smaller)  ⟹  P(k+1)P(\text{all smaller}) \implies P(k+1)P(all smaller)⟹P(k+1).
  • Structural induction: proof by recursive constructor preservation.
  • Counterexample disproves universal claims.
  • Existence proofs can be constructive or non-constructive.

Practical Takeaways​

  1. Start direct ? most proofs are direct; only pivot to other methods when stuck.
  2. Try contrapositive ? if the conclusion's negation gives more leverage than the hypothesis.
  3. Use contradiction as fallback ? powerful but can produce less constructive proofs.
  4. Induction for natural numbers ? always identify the base case and the inductive step clearly.
  5. Strong induction when dependencies skip ? if P(k+1)P(k+1)P(k+1) needs P(k−1)P(k-1)P(k−1) or P(k−2)P(k-2)P(k−2), use strong induction.
  6. One counterexample suffices ? never try to prove a universal false; find a single exception.

  domain: number[],

  conclusion: (n: number) => boolean

  const contra = domain.every(n => conclusion(n) || !premise(n));

Theorem 4.4 (Principle of Mathematical Induction). Let P(n)P(n)P(n) be a statement about n∈Nn \in \mathbb{N}n∈N. If:

  1. P(1)P(1)P(1) is true (base case).
  2. ∀k≥1,P(k)  ⟹  P(k+1)\forall k \geq 1, P(k) \implies P(k+1)∀k≥1,P(k)⟹P(k+1) (inductive step).

}

4.10 Strong Induction​

Theorem 4.5 (Strong Induction). If P(1),…,P(m)P(1), \ldots, P(m)P(1),…,P(m) are true and P(1)∧⋯∧P(k)  ⟹  P(k+1)P(1) \land \cdots \land P(k) \implies P(k+1)P(1)∧⋯∧P(k)⟹P(k+1), then P(n)P(n)P(n) is true for all nnn.

function strongInduction(
  base: number,
  baseCases: number[],
  predicate: (n: number) => boolean,
  inductiveStep: (k: number, prev: boolean[]) => boolean,
  upTo: number
): boolean {
  const results: boolean[] = [false]; // 1-indexed
  for (let i = 0; i < baseCases.length; i++) {
    if (!predicate(base + i)) return false;
    results[base + i] = true;
  }
  for (let k = base + baseCases.length; k <= upTo; k++) {
    if (!inductiveStep(k - 1, results)) return false;
    results[k] = predicate(k);
  }
  return true;
}

4.11 Structural Induction​

Definition 4.5 (Structural Induction). Used for recursively defined structures (trees, lists, formulas):

  1. Show the property holds for all base elements.
  2. Show the property is preserved by each construction rule.
// Structural induction on arithmetic expressions
type Expr =
  | { type: "num"; value: number }
  | { type: "add"; left: Expr; right: Expr }
  | { type: "mul"; left: Expr; right: Expr };

function evalExpr(e: Expr): number {
  switch (e.type) {
    case "num": return e.value;
    case "add": return evalExpr(e.left) + evalExpr(e.right);
    case "mul": return evalExpr(e.left) * evalExpr(e.right);
  }
}

// Structural induction claim: Every expression built from integers,
// +, and ? evaluates to an integer.
function allResultsAreIntegers(e: Expr): boolean {
  const result = evalExpr(e);
  if (!Number.isInteger(result)) return false;
  // Verify recursively
  if (e.type === "num") return Number.isInteger(e.value);
  return allResultsAreIntegers(e.left) && allResultsAreIntegers(e.right);
}

Proof 4.10 (Pigeonhole principle proof). Among any n+1n+1n+1 integers, two have the same remainder when divided by nnn.

Proof. There are nnn possible remainders modulo nnn: {0,1,…,n−1}\{0, 1, \ldots, n-1\}{0,1,…,n−1}. By the pigeonhole principle, among n+1n+1n+1 integers, two must fall in the same remainder class. Their difference is divisible by nnn.

Example 4.8 (Combinatorial proof using double counting). In any group of people, the number of people who have shaken hands an odd number of times is even.

Proof. Each handshake contributes 2 to the total handshake count. Sum of all handshake counts = 2×(handshakes)2 \times \text{(handshakes)}2×(handshakes), which is even. An odd number of odd terms would sum to an odd total, impossible. Therefore the count of odd-degree vertices is even. □\square□
