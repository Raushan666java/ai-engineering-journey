### 1.2 The 6-Second Recruiter Scan

Recruiters and ATS (Applicant Tracking Systems) decide in 6 seconds:

| What They Check | Why |
|----------------|-----|
| **Name & Contact** | Can they reach you? (missing email = instant reject) |
| **Current College + Year** | Eligibility for the role |
| **CGPA** | Filter criterion (most set a cutoff, usually 6+ or 7+) |
| **Skills section** | Do you have the keywords they're searching for? |
| **Last project/internship** | Is it relevant to this role? |
| **Overall formatting** | Is it clean or a mess? |

**The 6-second rule in practice:**
- Top third of page must contain: Name, Skills, Education CGPA, and one strong project
- ATS parses before a human sees it â€” use standard section headers (no fancy icons)
- Font size: 10-12pt body, 14-16pt name. Margins: 0.5-0.75 inches

### 3.2 20 Solved Problems

#### Problem 1: Percentage â€” Successive Increase

> The salary of an employee is first increased by 20%, then decreased by 10%, and then increased by 25%. What is the net percentage change?

**Solution:**

Using successive percentage formula: `a + b + c + (ab + bc + ca)/100 + (abc)/10000`

First two changes: `20 - 10 + (20 Ã— (-10))/100 = 10 - 2 = 8%`
Now apply 25% on 108: `8 + 25 + (8 Ã— 25)/100 = 33 + 2 = 35%`

**Answer: 35% increase**

#### Problem 2: Time, Speed & Distance â€” Relative Speed

> Two trains, 140m and 160m long, run at 60 km/h and 40 km/h respectively in opposite directions on parallel tracks. How long do they take to cross each other completely?

**Solution:**

Relative speed = `60 + 40 = 100 km/h = 100 Ã— 5/18 = 250/9 m/s`
Total distance to cover = `140 + 160 = 300m`
Time = `Distance / Speed = 300 / (250/9) = 300 Ã— 9/250 = 2700/250 = 10.8 seconds`

**Answer: 10.8 seconds**

#### Problem 4: Averages â€” Weighted Average

> The average marks of 20 students in a class is 72. The average marks of 12 boys is 68. What is the average marks of the girls?

**Solution:**

Total marks of 20 students = `20 Ã— 72 = 1440`

#### Problem 5: Profit & Loss

> A shopkeeper marks an article 40% above cost price and offers a discount of 15%. What is his profit percentage?

**Solution:**

MP = 100 + 40 = 140
Discount = 15% of 140 = 21
SP = 140 - 21 = 119
Profit = 119 - 100 = 19%

**Answer: 19%**

### 3.3 Logical Reasoning Shortcuts

#### Syllogisms

**Rule of thumb for "All/Some/No" statements:**

| Statement | Venn Interpretation | Quick Check |
|-----------|-------------------|-------------|
| All A are B | A inside B | "Some A are B" is also true |
| Some A are B | A and B overlap | Cannot say "All A are B" |
| No A is B | Disjoint circles | "Some A are not B" is also true |
| Some A are not B | A partially outside B | Cannot say "No A is B" |

**Shortcut method (Ravish Sood's technique):**
- Combine two statements using the middle term
- Check if middle term is distributed at least once
- Elimination method: cross out options that contradict known true statements

#### Blood Relations

|----------|---------|

#### Arrangements (Linear & Circular)

**Linear arrangement shortcut:**
- Fix the first condition person's position
- Work left-to-right filling in what you know
- Use "not" conditions to eliminate
- Draw placeholders: ___ ___ ___ ___

**Circular arrangement shortcut:**

- Use relative positions ("to the left of", "opposite")

**Puzzle types:**

- Comparison puzzles: Use >, <, = notations in a chain
- Scheduling (days/months): Draw a calendar grid

## 8. ATS Optimization Strategy

Applicant Tracking Systems (ATS) filter resumes before they reach human recruiters. Understanding how ATS works is critical â€” especially for service-based and large product companies.

### 8.1 How ATS Parses Resumes

ATS software extracts the following fields from your resume:
- **Contact Info**: Name, email, phone, LinkedIn, GitHub
- **Work Experience**: Company, title, dates, description
- **Education**: Institution, degree, GPA, dates
- **Skills**: Keyword matching against job description
- **Certifications**: Extracted from dedicated section

### 8.2 ATS-Friendly Formatting Rules

| Rule | Why |
|------|-----|
| Use standard section headers (EXPERIENCE, EDUCATION, SKILLS) | ATS looks for these exact labels |
| Save as .docx or plain PDF (text-based, not scanned) | Scanned PDFs and images cannot be parsed |
| No tables, columns, or text boxes | ATS reads left-to-right, top-to-bottom |
| No headers/footers with critical info | Many ATS skip header/footer content |
| Standard fonts only (Arial, Calibri, Times New Roman) | Unusual fonts may not render in ATS preview |
| Bullet points using standard characters ( - * â€¢ ) | Custom bullet symbols may be skipped |
| Spell out acronyms at least once (e.g., "AWS (Amazon Web Services)") | ATS may match "AWS" or "Amazon Web Services" |
| Include a Keywords section or skill tags | Direct keyword matching is how ATS scores resumes |

### 8.3 Keyword Optimization Process

1. **Extract keywords** from the job description: Required skills, tools, methodologies, domain terms
2. **Map to your resume**: Ensure each keyword appears naturally in your experience or skills section
3. **Prioritize**: Required skills > nice-to-have > domain buzzwords
4. **Verify**: The job description contains 80%+ of the skills you list

**Example**: If the JD asks for "Java, Spring Boot, REST APIs, Microservices, Docker, Kubernetes, CI/CD, MySQL, Redis, Kafka":
- Your SKILLS section must list these exact terms
- Your EXPERIENCE bullets should use these terms contextually (e.g., "Built REST APIs using Spring Boot and deployed on Kubernetes")

### 8.4 ATS Score Improvement Checklist

- [ ] Resume is a single column layout
- [ ] No images, icons, or graphics
- [ ] All section headers are standard
- [ ] Keywords from target job description are included
- [ ] File name is `FirstName_LastName_Resume.pdf` or `FirstName_LastName_CompanyName.pdf`
- [ ] No special characters in file name
- [ ] PDF is text-selectable (not scanned)
- [ ] Contact info is in the top header area
- [ ] Education includes CGPA in standard format (e.g., 8.5/10 or 85%)
- [ ] Dates use consistent format (e.g., "Jun 2024 - Aug 2024")
- [ ] No password protection on the PDF
- [ ] Resume passes through an ATS simulator (try jobscan.co or resumeworded.com)
