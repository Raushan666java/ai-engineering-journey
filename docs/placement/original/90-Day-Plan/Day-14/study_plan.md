## 💡 Tips for Success

**Problem Solving:**
- Start with brute force, then optimize
- Draw diagrams for complex problems
- Test with edge cases before submitting
- Time yourself (interview simulation)

**Contest Strategy:**
- Don't get stuck—move on after 30 min
- Partial solution > no solution
- Read problem carefully (missed details = bugs)
- Keep calm, manage anxiety

**Learning:**
- Understand solutions, don't just copy
- Multiple approaches > single solution
- Focus on patterns, not memorization
- Review mistakes thoroughly
