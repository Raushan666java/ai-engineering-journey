Exam Overview​

The IBPS SO (Specialist Officer) IT Officer Scale 1 examination is conducted by the Institute of Banking Personnel Selection (IBPS) to recruit IT professionals for Public Sector Banks in India. The exam is held annually across three phases:

PhaseDescriptionMarksDuration
Phase IPreliminary Exam (Online Objective)125120 min
Phase IIMains Exam (Online Objective)200135 min
Phase IIIInterview100Varies

Preliminary Exam Structure​

The Preliminary Exam consists of three sections conducted in a single session:

SectionQuestionsMarksDuration

Note: The Prelims for SO are qualifying in nature. Marks obtained in Prelims are NOT counted for final merit — only Mains + Interview marks determine selection.

Mains Exam Structure (IT Officer)​

The Mains Exam consists of four sections, each with a separate timing:

SectionQuestionsMarksDuration

Quantitative Aptitude356045 min
English Language354040 min

Total175220190 min

Marking Scheme​

  • Correct Answer: +1 mark for Preliminary, +1 mark for English in Mains, variable for other sections
  • Incorrect Answer: -0.25 marks (negative marking applies to all objective sections)
  • Unanswered: No marks deducted
  • Professional Knowledge Section: +0.25 marks per question in some years, check official notification

Interview Process​

  • Total Marks: 100 (qualifying in nature)
  • Qualifying Marks: Minimum 40% (35% for SC/ST/OBC/PwBD)
  • Final Merit: 80% Mains + 20% Interview (ratios may vary by notification)

Subject-wise Deep Dive​

Database Management Systems (14-18 Questions)​

Core Topics:

  • ER Model: Entities, relationships, attributes, weak entities, specialization/generalization
  • Relational Model: Schemas, keys (candidate, primary, foreign, super), relational algebra operations
  • SQL: DDL, DML, DCL commands, joins, subqueries, aggregate functions, views, indexes
  • Normalization: 1NF, 2NF, 3NF, BCNF, 4NF, 5NF — dependency preservation and lossless decomposition
  • Transaction Management: ACID properties, states, serializability, conflict/view serializability
  • Concurrency Control: Lock-based protocols, timestamp ordering, deadlock detection/prevention
  • Indexing: B-tree, B+ tree, hash indexing, dense vs sparse
  • File Organization: Sequential, heap, hash, clustered, multi-table clustering

Sample SQL Query for Practice:

// TypeScript simulation of SQL query execution
interface Employee {
  id: number;
  name: string;
  departmentId: number;
  salary: number;
}

interface Department {
  id: number;
  name: string;
  location: string;
}

// SQL: SELECT d.name, AVG(e.salary) as avg_salary
//      FROM employees e
//      JOIN departments d ON e.departmentId = d.id
//      GROUP BY d.name
//      HAVING AVG(e.salary) > 50000;

function getDepartmentsAboveAvgSalary(
  employees: Employee[],
  departments: Department[]
): { name: string; avgSalary: number }[] {
  const deptMap = new Map(departments.map(d => [d.id, d]));

  // Group by department
  const grouped = new Map<number, number[]>();
  for (const emp of employees) {
    const list = grouped.get(emp.departmentId) || [];
    list.push(emp.salary);
    grouped.set(emp.departmentId, list);
  }

  const result: { name: string; avgSalary: number }[] = [];
  for (const [deptId, salaries] of grouped) {
    const avgSalary = salaries.reduce((a, b) => a + b, 0) / salaries.length;
    if (avgSalary > 50000) {
      result.push({ name: deptMap.get(deptId)?.name || "Unknown", avgSalary });
    }
  }
  return result;
}

Operating Systems (10-12 Questions)​

Core Topics:

  • Process Management: States (new, ready, running, wait, terminated), PCB, context switching
  • CPU Scheduling: FCFS, SJF, SRTF, Round Robin, Priority, Multilevel Queue/Feedback
  • Process Synchronization: Race conditions, critical section, mutex, semaphores, monitors
  • Deadlocks: Necessary conditions, RAG, deadlock prevention/avoidance (Banker's algorithm)
  • Memory Management: Contiguous allocation, paging, segmentation, virtual memory, page replacement
  • File Systems: Directory structure, allocation methods, free space management
  • Disk Scheduling: FCFS, SSTF, SCAN, C-SCAN, LOOK, C-LOOK

Scheduling Algorithm Simulation:

// Round Robin CPU Scheduling Simulation
interface Process {
  id: number;
  arrivalTime: number;
  burstTime: number;
  remainingTime: number;
  completionTime: number;
  turnaroundTime: number;
  waitingTime: number;
}

function roundRobinScheduling(processes: Process[], quantum: number): Process[] {
  const queue: Process[] = [...processes];
  let currentTime = 0;
  const completed: Process[] = [];

  while (queue.length > 0) {
    const process = queue.shift()!;
    const executeTime = Math.min(quantum, process.remainingTime);
    currentTime += executeTime;
    process.remainingTime -= executeTime;

    if (process.remainingTime === 0) {
      process.completionTime = currentTime;
      process.turnaroundTime = process.completionTime - process.arrivalTime;
      process.waitingTime = process.turnaroundTime - process.burstTime;
      completed.push(process);
    } else {
      // Check if any new process arrived during execution
      queue.push(process); // Re-add to end of queue
    }
  }
  return completed;
}

// Calculate average turnaround time
function avgTurnaroundTime(processes: Process[]): number {
  return processes.reduce((sum, p) => sum + p.turnaroundTime, 0) / processes.length;
}

Computer Networks (9-11 Questions)​

Core Topics:

  • OSI Model: 7 layers, functions, protocols at each layer
  • TCP/IP Model: Comparison with OSI, encapsulation
  • Network Topologies: Star, bus, ring, mesh, hybrid
  • MAC Protocols: CSMA/CD, CSMA/CA, token passing
  • IP Addressing: IPv4 classes, subnetting, CIDR, VLSM
  • Routing Protocols: RIP, OSPF, BGP, distance vector vs link state
  • Transport Layer: TCP (3-way handshake, flow control), UDP
  • Application Layer: HTTP/HTTPS, FTP, SMTP, DNS, DHCP
  • Network Security: Firewalls, VPNs, SSL/TLS, IDS/IPS

Subnet Calculator:

// Subnet Calculator in TypeScript
class IPv4Address {
  constructor(
    public octets: [number, number, number, number],
    public prefixLength: number
  ) {}

  getNetworkAddress(): string {
    const mask = this.getSubnetMask();
    return this.octets.map((octet, i) => octet & mask[i]).join(".");
  }

  getSubnetMask(): number[] {
    const mask: number[] = [0, 0, 0, 0];
    for (let i = 0; i < 4; i++) {
      const bits = Math.min(8, this.prefixLength - i * 8);
      if (bits > 0) {
        mask[i] = 256 - Math.pow(2, 8 - bits);
      }
    }
    return mask;
  }

  getBroadcastAddress(): string {
    const mask = this.getSubnetMask();
    return this.octets
      .map((octet, i) => octet | (255 - mask[i]))
      .join(".");
  }

  getTotalHosts(): number {
    return Math.pow(2, 32 - this.prefixLength) - 2;
  }
}

// Example: 192.168.1.0/24
const subnet = new IPv4Address([192, 168, 1, 0], 24);
console.log(subnet.getNetworkAddress());   // 192.168.1.0
console.log(subnet.getBroadcastAddress()); // 192.168.1.255
console.log(subnet.getTotalHosts());       // 254

Preparation Strategy​

Phase I: Preliminary Exam Strategy​

The Prelims is qualifying only — you need minimum sectional cutoffs plus overall cutoff.

SectionTarget ScoreStrategy
English20+/30Focus on Reading Comprehension (RC) speed, error spotting accuracy
Reasoning25+/35Solve puzzles daily, master syllogisms & inequalities
Quant20+/30DI sets + simplification + number series = 50% of paper

Prelims Golden Rules:

  1. Attempt all easy questions first (Simplification, Inequalities, Syllogisms)
  2. Spend max 8-10 minutes on any single puzzle
  3. In English, attempt RC first (highest marks per question)
  4. Leave the hardest 3-5 questions — don't let negative marking eat your score

Phase II: Mains Exam Strategy​

Section 1: Professional Knowledge (The Decider)​

This section makes or breaks your selection. With 60 questions and 45 minutes, you need speed AND depth.

Priority Order for Preparation:

  1. DBMS (highest weightage, most scoring)
  2. Operating Systems (conceptual, formula-based)
  3. Computer Networks (theory-heavy, memorize key points)
  4. Data Structures (algorithmic thinking)
  5. Software Engineering (process-oriented)
  6. OOP Concepts (language-agnostic principles)
  7. Web Technologies & Security (current trends)
// Study time allocation calculator
interface StudyAllocation {
  topic: string;
  weightage: number;     // out of 60
  difficulty: number;     // 1-5
  currentProficiency: number; // 1-10
}

function calculateHours(allocation: StudyAllocation[]): Map<string, number> {
  const totalHours = 90; // Total study days * hours per day
  const allocationMap = new Map<string, number>();

  let totalPriority = 0;
  const priorities = allocation.map(a => {
    const priority = a.weightage * (10 - a.currentProficiency) * a.difficulty;
    totalPriority += priority;
    return { topic: a.topic, priority };
  });

  for (const p of priorities) {
    allocationMap.set(p.topic, Math.round((p.priority / totalPriority) * totalHours));
  }
  return allocationMap;
}

Mock Test Strategy​

How to Take a Mock Test​

1. Simulate real exam conditions:
   - Sit at a desk with no distractions
   - Use a timer (do NOT pause)
   - Use on-screen calculator only (no physical one)

2. Section Order Strategy:
   Option A: Reasoning → Quant → English → Professional Knowledge
   Option B: Professional Knowledge → Reasoning → Quant → English
   Option C: English → Reasoning → Quant → Professional Knowledge

3. Time Management Template:
   - First 5 minutes: Scan all sections, identify easy questions
   - Professional Knowledge: 35-40 min (attempt all 60)
   - Reasoning: 35-40 min (puzzles first, then quick ones)
   - Quant: 25-30 min (DI sets, then arithmetic)
   - English: 20-25 min (RC first, then vocabulary)

Speed Drills for Quant & Reasoning​

Quant Speed Drills​

Drill 1: Simplification (Target: 10 questions in 5 minutes)

Practice using BODMAS/VBODMAS rules with squares, cubes, percentages, fractions.

// Generate random simplification questions
function generateSimplificationQuestion(): { question: string; answer: number } {
  const a = Math.floor(Math.random() * 100);
  const b = Math.floor(Math.random() * 50) + 1;
  const operations = ["+", "-", "×", "÷"];
  const op = operations[Math.floor(Math.random() * operations.length)];

  let answer: number;
  switch (op) {
    case "+": answer = a + b; break;
    case "-": answer = a - b; break;
    case "×": answer = a * b; break;
    case "÷": answer = Math.round((a / b) * 100) / 100; break;
    default: answer = 0;
  }

  return {
    question: `${a} ${op} ${b} = ?`,
    answer,
  };
}

Drill 2: Number Series (Target: 5 questions in 4 minutes)

Common patterns:

  • Difference-based: +2, +4, +6, +8, ...
  • Multiplication-based: ×2, ×3, ×4, ...
  • Mixed: ×2-1, ×3-2, ×4-3, ...
  • Square/Cube: 1², 2², 3², ... or 1³, 2³, 3³, ...
  • Fibonacci: 0, 1, 1, 2, 3, 5, 8, ...

Drill 3: Quadratic Equations (Target: 5 questions in 4 minutes)

Compare values of x and y from two equations using factorization or formula.

I. x² - 7x + 12 = 0 II. y² - 9y + 20 = 0 → x = 3, 4; y = 4, 5 → x ≤ y

Reasoning Speed Drills​

Drill 1: Syllogisms (Target: 5 questions in 3 minutes)

Use Venn diagrams to solve quickly. Memorize:

  • All A are B → A ⊆ B
  • Some A are B → A ∩ B ≠ ∅
  • No A is B → A ∩ B = ∅

Drill 2: Inequalities (Target: 5 questions in 3 minutes)

Use the chain rule: If A > B > C, then A > C. For coded inequalities, decode the symbols first.

Drill 3: Puzzles (Target: 1 complex puzzle in 6-8 minutes)

Practice these puzzle types daily:

  • Circular arrangement (facing center / facing out)
  • Linear arrangement (north / south)
  • Floor-based (with/without flats)
  • Scheduling (month/year/day based)
  • Comparison-based (height/age/weight)

Memory Techniques​

ACID properties: "Atomic Cats In Docks" — Atomicity, Consistency, Isolation, Durability

OSI 7 layers (Physical → Application): "Please Do Not Throw Sausage Pizza Away" or "Physical, Data Link, Network, Transport, Session, Presentation, Application"

TCP/IP 4 layers: "Network Interface → Internet → Transport → Application" (NITA)

Normal Forms:

  • 1NF: Atomic values (no repeating groups)
  • 2NF: 1NF + no partial dependency
  • 3NF: 2NF + no transitive dependency
  • BCNF: 3NF + every determinant is a candidate key

Common Mistakes to Avoid​

Mistake 1: Ignoring Professional Knowledge​

Many candidates with IT backgrounds assume they'll ace this section. Result: 35-40/60 instead of 50+. Treat this section as your differentiator.

Mistake 2: Spending too much time on one puzzle​

If a puzzle takes >10 minutes, leave it and come back. The opportunity cost is too high.

Mistake 3: Neglecting English​

English carries 40 marks in Mains. 22-25 marks here can make the difference between selection and rejection.

Mistake 4: Not practicing with a timer​

Without timing yourself, you won't build the speed needed for the actual exam.

Mistake 5: Over-relying on coaching material​

Standard coaching material often doesn't cover the depth needed for Professional Knowledge. Use standard textbooks:

  • DBMS: Korth, Navathe (or Elmasri)
  • OS: Galvin, Silberschatz
  • Networks: Tanenbaum, Kurose
  • DSA: Cormen (CLRS) or Horowitz

Mistake 6: Not analyzing mock tests​

Taking 20 mocks without analysis yields less improvement than 5 mocks with thorough analysis.

Mistake 7: Poor time management in the exam hall​

  • Don't spend >40 minutes on Professional Knowledge (you have 45 minutes)
  • Don't spend >45 minutes on Reasoning
  • Keep 5-10 minutes at the end for review

Final Preparation Checklist​

One Month Before Exam​

  • Complete all Professional Knowledge syllabus
  • Practice at least 10 full-length Mains mocks
  • Achieve 85%+ accuracy in easy topics
  • Identify and improve weak areas

One Week Before Exam​

  • Attempt one full mock every alternate day
  • Revise formulas and key concepts (2 hours daily)
  • Practice relaxation techniques
  • Prepare exam day kit (admit card, ID, photos)
  • Sleep 7-8 hours daily

Exam Day​

  • Reach center 1 hour early
  • Carry all documents
  • Read instructions carefully
  • Attempt easy questions first
  • Mark answers clearly (no stray marks)
  • Use rough sheets efficiently
  • Review marked questions if time permits

Post-Exam​

  • Note down questions you remember (for future analysis)
  • Start preparing for interview (if applicable)
  • Analyze performance for improvement areas

Remember: Consistent practice over 90 days beats sporadic intense study. Focus on understanding concepts deeply rather than rote memorization. The Professional Knowledge section is your strongest weapon — use it to secure your selection. Good luck!
