## 🧠 Week 2 Cheat Sheets

### Time Complexity Reference

**Array Operations:**
- Access: O(1)
- Search: O(n)
- Insert (end): O(1) amortized
- Delete: O(n)

**HashMap:**
- Insert/Search/Delete: O(1) average, O(n) worst

**LinkedList:**
- Access: O(n)
- Insert/Delete (with reference): O(1)

**BST (Balanced):**
- Search/Insert/Delete: O(log n)

**Heap:**
- Insert: O(log n)
- Extract Min/Max: O(log n)
- Peek: O(1)

### Common Patterns Cheat Sheet

**Two Pointer:** Arrays, Linked Lists  
**Sliding Window:** Substring problems  
**Fast & Slow:** Cycle detection  
**BFS:** Level order, shortest path  
**DFS:** All paths, tree problems  
**HashMap:** Frequency, Two Sum  
**Heap:** Top-K, Kth largest  
**BST:** Search in sorted data
