# System Design Syllabus
*Duration: 8-10 weeks*

## Phase 1: Low-Level Design (Week 1-4) 🟢

### Object-Oriented Design
- **SOLID Principles:** SRP, OCP, LSP, ISP, DIP
- **Design Patterns:** Singleton, Factory, Observer, Strategy, Decorator
- **UML Diagrams:** Class, sequence, activity diagrams

### Practice Problems
- **Week 1-2:** Parking Lot, Library Management
- **Week 3-4:** Chess Game, Elevator System, ATM

## Phase 2: High-Level Design Fundamentals (Week 5-6) 🟡

### Core Concepts
- **Scalability:** Horizontal vs Vertical scaling
- **Load Balancing:** Round robin, least connections, consistent hashing
- **Caching:** Browser, CDN, Application, Database caching
- **Database:** SQL vs NoSQL, sharding, replication

### System Components
- **Message Queues:** Kafka, RabbitMQ, SQS
- **Storage:** File systems, object storage (S3)
- **CDN:** CloudFlare, AWS CloudFront

## Phase 3: Advanced Systems (Week 7-10) 🔴

### Distributed Systems
- **CAP Theorem:** Consistency, Availability, Partition tolerance
- **Consistency Models:** Strong, eventual, weak consistency
- **Microservices:** Service discovery, API gateway
- **Monitoring:** Logging, metrics, distributed tracing

### System Design Problems
- **Week 7:** URL Shortener (bit.ly), Chat System (WhatsApp)
- **Week 8:** Social Media Feed (Instagram), Video Streaming (YouTube)
- **Week 9:** Ride Sharing (Uber), Search Engine (Google)
- **Week 10:** E-commerce (Amazon), Payment System (PayPal)

## Interview Preparation
- **Framework:** Requirements → Estimation → Design → Deep Dive → Scale
- **Practice:** 2-3 systems per week, mock interviews
- **Resources:** Grokking System Design, System Design Primer
