# 🔬 Module 1: Learning Science

## How Your Brain Learns

### Focused vs Diffuse Mode
**Focused Mode:**
- Concentrated attention
- Logical, sequential thinking
- Problem-solving with known patterns

**Diffuse Mode:**
- Relaxed attention
- Big-picture connections
- Creative insights

**Practice:** Alternate 25min focused work + 5min break

### Memory Formation
**3 Stages:**
1. **Encoding** - Information input
2. **Storage** - Long-term retention
3. **Retrieval** - Accessing information

**Key Insight:** Retrieval practice strengthens memory more than re-reading

### Learning Principles
1. **Active Learning** - Engage with material
2. **Spaced Practice** - Distribute learning over time
3. **Interleaving** - Mix different topics
4. **Testing Effect** - Quiz yourself frequently

## Practical Applications
- [ ] Use Pomodoro Technique (25min + 5min break)
- [ ] Take breaks to activate diffuse mode
- [ ] Test yourself instead of re-reading
- [ ] Space out review sessions

## Daily Practice
**Morning:** Learn new concept (focused mode)
**Afternoon:** Practice problems (focused mode)
**Evening:** Review/reflect (diffuse mode)
