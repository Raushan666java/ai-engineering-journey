# Week 1: System Design Basics

**Duration:** October 27 - November 2, 2026 | **Hours:** 35

---

## Key Concepts

| Concept | Purpose |
|---------|---------|
| Load Balancer | Distribute traffic |
| Caching (Redis) | Reduce DB load |
| CDN | Serve static assets fast |
| Database Sharding | Horizontal scaling |
| Message Queue | Async processing |
| Rate Limiting | Protect APIs |

## Design Problems

Practice these:

1. **Design URL Shortener** (bit.ly)
2. **Design WhatsApp Bot** for 100k users
3. **Design Twitter Feed**

### Framework

```text
1. Requirements (functional + non-functional)
2. High-level design (components)
3. Deep dive (each component)
4. Scale (how to handle growth)
5. Tradeoffs (what you'd do differently)
```
