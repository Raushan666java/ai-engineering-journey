## 📚 Topics Covered

### Morning Session (6:00 AM - 9:00 AM): Operators Deep Dive

1. **Arithmetic Operators** (1 hour)
   - Basic operators: +, -, *, /, %
   - Increment/Decrement: ++, --
   - Compound assignment: +=, -=, *=, /=, %=
   - Type promotion and casting

2. **Relational & Logical Operators** (1 hour)
   - Comparison: ==, !=, <, >, <=, >=
   - Logical: &&, ||, !
   - Short-circuit evaluation
   - Truth tables and boolean logic

3. **Bitwise & Other Operators** (1 hour)
   - Bitwise: &, |, ^, ~, <<, >>
   - Ternary: ? :
   - instanceof operator
   - Operator precedence chart

### Afternoon Session (2:00 PM - 5:00 PM): Control Flow Mastery

4. **if-else Statements** (1 hour)
   - Simple if statement
   - if-else ladder
   - Nested if-else
   - Common patterns and best practices

5. **switch Statements** (1 hour)
   - Basic switch syntax
   - Multiple cases and default
   - Switch with strings (Java 7+)
   - When to use switch vs if-else

6. **Practice Problems** (1 hour)
   - 10 problems combining operators and control flow
   - Grade calculator, number classification, menu systems
   - Debug and fix common errors

### Evening Session (7:00 PM - 10:00 PM): Project & Advanced Practice

7. **Decision Making Calculator** (1.5 hours)
   - Build a comprehensive calculator
   - Multiple operations with user choice
   - Input validation and error handling
   - Clean, maintainable code structure

8. **Advanced Practice & Review** (1.5 hours)
   - 5 bonus problems for mastery
   - Code review and optimization
   - Common interview questions
   - Prepare for Day 3
