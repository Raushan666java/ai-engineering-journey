## 🎯 Recursion Templates

### Basic Recursion Template
```java
returnType recursion(parameters) {
    // Base case
    if (baseCondition) {
        return baseValue;
    }
    
    // Recursive case
    // 1. Make problem smaller
    // 2. Recurse on smaller problem
    // 3. Combine results
    return combineResults(recursion(smallerProblem));
}
```

### Backtracking Template
```java
void backtrack(state, choices, result) {
    // Base case: solution found
    if (isValidSolution(state)) {
        result.add(state);
        return;
    }
    
    // Try each choice
    for (choice : choices) {
        // 1. Make choice
        makeChoice(choice);
        
        // 2. Recurse
        backtrack(newState, newChoices, result);
        
        // 3. Undo choice (BACKTRACK)
        undoChoice(choice);
    }
}
```

### Memoization Template
```java
int recursionWithMemo(int n, int[] memo) {
    // Base case
    if (n <= baseCase) return baseValue;
    
    // Check memo
    if (memo[n] != -1) return memo[n];
    
    // Compute and store
    memo[n] = computation(recursionWithMemo(n-1, memo));
    return memo[n];
}
```

## 📊 Complexity Analysis

### Common Time Complexities
- **Factorial:** O(n)
- **Fibonacci (naive):** O(2^n)
- **Fibonacci (memo):** O(n)
- **Binary search:** O(log n)
- **Permutations:** O(n!)
- **Subsets:** O(2^n)
- **N-Queens:** O(N!)
- **Sudoku:** O(9^m) where m = empty cells

### Space Complexity
- **Call stack depth:** O(depth)
- **With memoization:** O(n) for memo array
- **Backtracking:** O(depth) for recursion stack
