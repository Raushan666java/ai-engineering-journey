# Python Programming Syllabus

- Syntax and data structures: variables, lists, tuples, sets, dictionaries
- File handling: open, read, write, with statement, error handling
- Exceptions: try-except, custom exceptions
- Libraries: NumPy (arrays, operations), Pandas (DataFrames, data manipulation), Matplotlib (plotting)
- OOP in Python: classes, inheritance, polymorphism, encapsulation
- Scripting and automation: os, sys, subprocess, argparse, scheduling
- Python for DSA: recursion, sorting, searching, dynamic programming
- Python for ML: scikit-learn basics, model training, evaluation
- Best practices: code style (PEP8), documentation, virtual environments
