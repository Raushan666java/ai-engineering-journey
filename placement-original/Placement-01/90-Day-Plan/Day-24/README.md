# Day 24: Graphs - Part 2 (Flow, Bridges, Articulation, LCA)

## Overview
This day continues Graphs with advanced techniques:
- Max Flow algorithms (Edmonds-Karp, Dinic)
- Bridges and articulation points (Tarjan's algorithm)
- Lowest Common Ancestor (LCA) with binary lifting

## Goals
- Implement `GraphFlow` (Edmonds-Karp) for max flow
- Implement `GraphTarjan` to find bridges and articulation points
- Implement `GraphLCA` (binary lifting) for ancestor queries
- Add demos, visualizers, and integrate into the harness
