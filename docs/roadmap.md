# CS Curriculum Roadmap

A structured, semester-by-semester plan to master Computer Science.

---

## Semester 1 — Foundations

| Week | Topics | Courses |
|------|--------|---------|
| 1-4 | C Programming basics, control flow, arrays, strings | [C: 01-04](courses/c-programming/) |
| 5-8 | C — pointers, functions, structures, memory | [C: 05-10](courses/c-programming/) |
| 9-12 | Discrete Math — sets, logic, proofs, combinatorics | [Discrete: 01-06](courses/discrete-mathematics/) |
| 13-16 | Digital Logic — number systems, gates, combinational circuits | [Digital Logic: 01-06](courses/digital-logic/) |

## Semester 2 — Data & Programming

| Week | Topics | Courses |
|------|--------|---------|
| 1-4 | Data Structures — arrays, linked lists, stacks, queues | [DSA: 01-06](courses/data-structures/) |
| 5-8 | Trees, heaps, graphs, hash tables | [DSA: 07-12](courses/data-structures/) |
| 9-12 | OOP with C++ — classes, inheritance, polymorphism, STL | [OOP: 01-10](courses/oop-cpp/) |
| 13-16 | Algorithms — sorting, searching, recursion | [Algorithms: 01-06](courses/algorithms/) |
