# DBMS Course Assignment Schedule

## Week 1-2: Fundamentals
### Assignment 1: Database Concepts
- Compare file system vs database management
- Design ER diagram for library system
- Identify entities, attributes, relationships
**Due: End of Week 2**

## Week 3-4: SQL Basics
### Assignment 2: Basic SQL Operations
- Create student management database
- Write CRUD operations
- Implement basic queries with WHERE, ORDER BY
**Due: End of Week 4**

## Week 5-6: Advanced SQL
### Assignment 3: Complex Queries
- Multi-table joins
- Subqueries and CTEs
- Aggregate functions and GROUP BY
**Due: End of Week 6**

## Week 7-8: Database Design
### Assignment 4: Normalization Project
- Design unnormalized table
- Apply 1NF, 2NF, 3NF transformations
- Document functional dependencies
**Due: End of Week 8**

## Week 9-10: Performance & Administration
### Assignment 5: Optimization Challenge
- Analyze slow queries
- Create appropriate indexes
- Implement stored procedures
**Due: End of Week 10**

## Week 11-12: Final Project
### Capstone Project Options:
1. E-commerce Database System
2. Hospital Management System
3. Social Media Platform
4. Banking Transaction System

**Requirements:**
- Complete database design
- Implementation with sample data
- Performance optimization
- Documentation
**Due: End of Week 12**

## Grading Criteria
- Correctness: 40%
- Design Quality: 30%
- Performance: 20%
- Documentation: 10%
