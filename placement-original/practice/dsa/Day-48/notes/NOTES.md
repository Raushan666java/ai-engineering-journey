# Day 48 Notes: Bit Manipulation

## Overview
Day 48 covers bit-level operations, XOR properties, bit masks, and common bit-tricks used in competitive programming and interview problems.

## Key Concepts
- Bitwise operators: &, |, ^, ~, <<, >>, >>>
- Common tricks: isolate lowest set bit, Brian Kernighan's algorithm for counting bits
- Bitmasking for subset enumeration and DP
- Using binary trie for maximum XOR queries

## Test Strategy
- Verify common patterns (single number, missing number) using multiple approaches
- Edge cases: negative numbers in languages with signed right shift
- Stress tests for performance on 32-bit and 64-bit integers
