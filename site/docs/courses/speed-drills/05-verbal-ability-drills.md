   - (D) Ordinary

   - (A) Criticized
   - (B) Admired
   - (C) Avoided
   - (D) Punished

   - (A) Pleasant
   - (B) Favorable
   - (C) Inclement
   - (D) Beautiful

   - (A) Weak
   - (B) Flawed
   - (C) Irrefutable

   - (C) Meteoritic

<details>

3. **(C) Inclement** — Weather that forces cancellation of outdoor events would be bad/severe. Inclement = (of weather) unpleasant, severe.
4. **(C) Irrefutable** — "No one could refute it" means the argument was impossible to disprove. Irrefutable fits perfectly.
5. **(C) Meteoritic** — "Made it a market leader" suggests rapid growth. Meteoritic = very rapid (like a meteor).

## Error Spotting Drills

### Set 1: Grammar Errors | ⏱ Target: 2 min | 🎯 Accuracy Goal: 75%

Identify the part with an error (A, B, C, D). If no error, mark E.

1. (A) The group of students / (B) are going / (C) on a field trip / (D) to the museum. / (E) No error

2. (A) She doesn't / (B) have no / (C) money left / (D) in her account. / (E) No error

3. (A) Each of the employees / (B) were given / (C) a bonus / (D) for their hard work. / (E) No error

4. (A) The teacher / (B) told the students / (C) to complete their assignments / (D) before they leave. / (E) No error

5. (A) Neither the manager / (B) nor the employees / (C) was aware / (D) of the change. / (E) No error

<details>
<summary>Show Answers</summary>

1. **(B) are going** — Error: "group" is a collective noun, singular → should be "is going." "The group" (singular) → "is going."
2. **(B) have no** — Error: Double negative. "Doesn't" + "no" = incorrect. Should be "doesn't have any" or "has no."
3. **(B) were given** — Error: "Each" is singular → "was given." Correct: "Each of the employees was given."
4. **(E) No error** — The sentence is grammatically correct.
5. **(C) was aware** — Error: With "neither...nor," the verb agrees with the nearest subject. "Employees" (plural) → "were aware."

<details>
<summary>Show Answers</summary>

4. **(A) I could of** — Error: "Could of" is incorrect. Should be "could have" (or "could've").
5. **(C) less** — Error: "Less" is for uncountable nouns. "Employees" is countable → "fewer employees."

### Set 1: Basic Jumbles | ⏱ Target: 3 min | 🎯 Accuracy Goal: 70%

Arrange the sentences in logical order.

1. **A:** He decided to learn to swim.
   **B:** John watched his friends swimming in the pool.
   **C:** He signed up for swimming classes.
   **D:** Within a month, he could swim across the pool.
   - (A) B, A, C, D
   - (B) A, B, C, D
   - (C) B, C, A, D
   - (D) A, C, B, D

2. **A:** Therefore, he started eating more fruits and vegetables.
   **B:** His doctor advised him to improve his diet.
   **C:** Within weeks, he felt more energetic.
   **D:** Ramesh was feeling tired all the time.
   - (A) D, B, A, C
   - (B) B, A, D, C
   - (C) D, A, B, C
   - (D) A, B, C, D

3. **A:** These eggs eventually hatch into caterpillars.
   **B:** The butterfly lays eggs on a leaf.
   **C:** The caterpillar forms a chrysalis.
   **D:** Finally, a beautiful butterfly emerges.
   **E:** The caterpillar eats and grows.
