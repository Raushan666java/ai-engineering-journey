## 🎓 Week 7 Topics Summary

### Trie Data Structure (Day 45)
**Mastery Indicators:**
- ✅ Basic insert, search, delete operations
- ✅ Wildcard search with backtracking
- ✅ Prefix matching and autocomplete
- ✅ XOR optimization with binary trie
- ✅ Application to word problems

**Common Patterns:**
- TrieNode with children array/map
- End of word flag
- Backtracking for wildcard search
- Prefix counting for autocomplete

### Segment Tree & Fenwick Tree (Day 46)
**Mastery Indicators:**
- ✅ Range query and point update
- ✅ Lazy propagation for range updates
- ✅ 2D segment tree/Fenwick tree
- ✅ Choosing between segment tree vs Fenwick
- ✅ Coordinate compression

**Common Patterns:**
- Build: O(n), Query: O(log n), Update: O(log n)
- Fenwick: Simpler, less space, range sum only
- Segment: More flexible, min/max/gcd queries
- Lazy propagation for batch updates

### Binary Search Advanced (Day 47)
**Mastery Indicators:**
- ✅ First/last occurrence patterns
- ✅ Rotated array search
- ✅ Binary search on answer
- ✅ 2D matrix search
- ✅ Median of two sorted arrays

**Common Patterns:**
- Search space: [min, max]
- Feasibility function: can we achieve mid?
- Move left or right based on condition
- Overflow prevention: mid = left + (right-left)/2

### Bit Manipulation (Day 48)
**Mastery Indicators:**
- ✅ XOR properties (self-cancellation)
- ✅ Bit counting (Brian Kernighan)
- ✅ Power of 2 check
- ✅ Subset generation with bitmask
- ✅ Trie for XOR problems

**Common Patterns:**
- XOR: Find unique elements
- AND: Check common bits
- OR: Set bits
- Shift: Multiply/divide by powers of 2
- Mask: Extract/set specific bits

### Greedy Algorithms (Day 49)
**Mastery Indicators:**
- ✅ Greedy choice property
- ✅ Interval scheduling (sort by end)
- ✅ Two-pointer pairing
- ✅ Frequency-based strategies
- ✅ Proof of correctness

**Common Patterns:**
- Sort first (by end time, value/weight)
- Make local optimal choice
- Prove exchange argument
- Activity selection template
- Priority queue for frequency

### Backtracking (Day 50)
**Mastery Indicators:**
- ✅ Choose-Explore-Unchoose pattern
- ✅ Pruning invalid branches
- ✅ Subset and permutation generation
- ✅ Board problems (N-Queens)
- ✅ Constraint satisfaction

**Common Patterns:**
- Base case: goal reached
- Loop through choices
- Validate before recursion
- Make choice → recurse → undo choice
- Track state (visited, used)
