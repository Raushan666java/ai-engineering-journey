# 1. Introduction to JavaScript

## What is JavaScript?
JavaScript is a high-level, interpreted programming language that enables interactive web pages and is an essential part of web applications. Alongside HTML and CSS, it is one of the core technologies of the World Wide Web.

## History and Evolution
- Created by Brendan Eich in 1995 for Netscape Navigator.
- Originally named Mocha, then LiveScript, and finally JavaScript.
- Standardized as ECMAScript (ES) by ECMA International.
- Major updates: ES5 (2009), ES6/ES2015 (2015), and annual updates since.

## JavaScript Engines and Runtime Environments
- JavaScript code runs in engines such as V8 (Chrome, Node.js), SpiderMonkey (Firefox), and JavaScriptCore (Safari).
- Can run in browsers (client-side) and on servers (Node.js).

## ECMAScript Standards
- ECMAScript is the standard that defines JavaScript.
- ES6 (ECMAScript 2015) introduced major features: let/const, arrow functions, classes, modules, promises, etc.
