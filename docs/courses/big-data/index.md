# Big Data Engineering

## Course Overview

This course covers distributed data processing at scale. From Hadoop's HDFS and MapReduce through Apache Spark's RDDs, DataFrames, Structured Streaming, and MLlib — you will learn to build production data pipelines that process terabytes to petabytes.

**Target Audience:** Data engineers, ML engineers, backend developers moving into data-intensive roles.

**Prerequisites:** Python, SQL, basic Linux CLI.
