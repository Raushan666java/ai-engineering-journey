# JavaScript Core Concepts

## Introduction
JavaScript is the language of the web, essential for client-side interactivity and real-time features.

## Key Topics
- Variables, data types, operators
- Functions, objects, arrays
- DOM manipulation
- Events & event handling
- Promises, async/await
- Fetch API & AJAX
- ES6+ features
- WebSockets in JavaScript

---

## Details
- **Variables:** `let`, `const`, `var`
- **Functions:** Arrow functions, callbacks
- **DOM:** `document.querySelector`, event listeners
- **Async:** `fetch()`, `Promise`, `async/await`
- **WebSockets:** `const ws = new WebSocket(url);`
