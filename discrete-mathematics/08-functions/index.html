Theory​

8.1 Definition​

A function (or mapping) f:A→Bf: A \rightarrow Bf:A→B assigns to each a∈Aa \in Aa∈A exactly one b∈Bb \in Bb∈B. We write f(a)=bf(a) = bf(a)=b.

  • AAA is the domain, BBB is the codomain.
  • The image (or range) of fff is f(A)={f(a)∣a∈A}⊆Bf(A) = \{f(a) \mid a \in A\} \subseteq Bf(A)={f(a)∣a∈A}⊆B.
  • If f(a)=bf(a) = bf(a)=b, bbb is the image of aaa, and aaa is a preimage of bbb.

Two functions fff and ggg are equal if they have the same domain and f(a)=g(a)f(a) = g(a)f(a)=g(a) for all aaa in the domain.

One-Sentence Takeaway: A function assigns every element of the domain exactly one element of the codomain; the range (image) may be a proper subset of the codomain.

8.2 Injective, Surjective, Bijective​

Injective (one-to-one): f(a1)=f(a2)  ⟹  a1=a2f(a_1) = f(a_2) \implies a_1 = a_2f(a1​)=f(a2​)⟹a1​=a2​. Equivalently: distinct inputs map to distinct outputs. ∣f(A)∣=∣A∣|f(A)| = |A|∣f(A)∣=∣A∣.

Surjective (onto): For every b∈Bb \in Bb∈B, there exists a∈Aa \in Aa∈A with f(a)=bf(a) = bf(a)=b. Equivalently: f(A)=Bf(A) = Bf(A)=B. The codomain equals the range.

Bijective (one-to-one correspondence): Both injective and surjective.

Theorem 8.1. A function is bijective if and only if it has an inverse.

Theorem 8.2. If AAA and BBB are finite sets with ∣A∣=∣B∣|A| = |B|∣A∣=∣B∣, then f:A→Bf: A \rightarrow Bf:A→B is injective iff it is surjective iff it is bijective.

function isInjective<T, U>(domain: T[], f: (x: T) => U): boolean {
  const images = new Set<U>();
  for (const x of domain) {
    const y = f(x);
    if (images.has(y)) return false;
    images.add(y);
  }
  return true;
}

function isSurjective<T, U>(
  domain: T[],
  codomain: U[],
  f: (x: T) => U
): boolean {
  const images = new Set(domain.map(f));
  return codomain.every(y => images.has(y));
}

const domain = [1, 2, 3, 4];
console.log(isInjective(domain, x => x * 2)); // true
console.log(isInjective(domain, x => Math.floor(x / 2))); // false

One-Sentence Takeaway: Injective functions are one-to-one (distinct inputs map to distinct outputs); surjective functions hit every codomain element; bijective functions are both ? and only bijections have inverses.

8.3 Composition​

If f:A→Bf: A \rightarrow Bf:A→B and g:B→Cg: B \rightarrow Cg:B→C, then the composition g∘f:A→Cg \circ f: A \rightarrow Cg∘f:A→C is: (g∘f)(a)=g(f(a))(g \circ f)(a) = g(f(a))(g∘f)(a)=g(f(a))

Composition is associative: (h∘g)∘f=h∘(g∘f)(h \circ g) \circ f = h \circ (g \circ f)(h∘g)∘f=h∘(g∘f).

Theorem 8.3 (Composition and injectivity/surjectivity).

  • If fff and ggg are injective, then g∘fg \circ fg∘f is injective.
  • If fff and ggg are surjective, then g∘fg \circ fg∘f is surjective.
  • If g∘fg \circ fg∘f is injective, then fff is injective.
  • If g∘fg \circ fg∘f is surjective, then ggg is surjective.

One-Sentence Takeaway: Composition applies one function after another (g∘fg \circ fg∘f means "first fff, then ggg"); it is associative but not commutative.

8.4 Inverse Functions​

If f:A→Bf: A \rightarrow Bf:A→B is bijective, there exists an inverse f−1:B→Af^{-1}: B \rightarrow Af−1:B→A such that: f−1(b)=a  ⟺  f(a)=bf^{-1}(b) = a \iff f(a) = bf−1(b)=a⟺f(a)=b

Properties:

  • f−1∘f=idAf^{-1} \circ f = \text{id}_Af−1∘f=idA​ (identity on AAA)
  • f∘f−1=idBf \circ f^{-1} = \text{id}_Bf∘f−1=idB​ (identity on BBB)
  • (g∘f)−1=f−1∘g−1(g \circ f)^{-1} = f^{-1} \circ g^{-1}(g∘f)−1=f−1∘g−1

One-Sentence Takeaway: Only bijective functions have inverses; the inverse reverses the mapping and satisfies f−1(f(x))=xf^{-1}(f(x)) = xf−1(f(x))=x.

8.5 Special Functions​

Floor function: ⌊x⌋\lfloor x \rfloor⌊x⌋ = the greatest integer ≤x\leq x≤x.

Ceiling function: ⌈x⌉\lceil x \rceil⌈x⌉ = the least integer ≥x\geq x≥x.

Properties of floor and ceiling:

  • \lfloor x \rfloor \leq x &lt; \lfloor x \rfloor + 1
  • \lceil x \rceil - 1 &lt; x \leq \lceil x \rceil
  • ⌊−x⌋=−⌈x⌉\lfloor -x \rfloor = -\lceil x \rceil⌊−x⌋=−⌈x⌉
  • ⌊x⌋=n\lfloor x \rfloor = n⌊x⌋=n iff n \leq x &lt; n+1
  • ⌈x⌉=n\lceil x \rceil = n⌈x⌉=n iff n-1 &lt; x \leq n
  • x - 1 &lt; \lfloor x \rfloor \leq x \leq \lceil x \rceil < x + 1

Factorial: n!=n⋅(n−1)⋯2⋅1n! = n \cdot (n-1) \cdots 2 \cdot 1n!=n⋅(n−1)⋯2⋅1, with 0!=10! = 10!=1.

Mod function: a mod ma \bmod mamodm = the remainder when aaa is divided by mmm (integer rrr with 0 \leq r &lt; m and a=qm+ra = qm + ra=qm+r).

Stirling's approximation: n!∼2πn (n/e)nn! \sim \sqrt{2\pi n}\,(n/e)^nn!∼2πn​(n/e)n.

One-Sentence Takeaway: Floor rounds down toward −∞-\infty−∞, ceiling rounds up toward +∞+\infty+∞; factorial grows faster than any exponential.

function isQuadraticGrowth(f: (n: number) => number): boolean {

8.7 Partial Functions​

A partial function f:A⇀Bf: A \rightharpoonup Bf:A⇀B is a function defined on a subset of AAA. If fff is defined for all a∈Aa \in Aa∈A, it is a total function.

Example: f(x)=1/xf(x) = 1/xf(x)=1/x is a partial function from R\mathbb{R}R to R\mathbb{R}R (undefined at x=0x = 0x=0).

One-Sentence Takeaway: A partial function may be undefined for some domain elements; a total function is a partial function that is defined everywhere.

8.8 Recursive Functions​

Some functions are defined recursively (in terms of themselves):

  • f(0)=1f(0) = 1f(0)=1, f(n)=n⋅f(n−1)f(n) = n \cdot f(n-1)f(n)=n⋅f(n−1) for n>0n > 0n>0 (factorial)
  • F1=1F_1 = 1F1​=1, F2=1F_2 = 1F2​=1, Fn=Fn−1+Fn−2F_n = F_{n-1} + F_{n-2}Fn​=Fn−1​+Fn−2​ (Fibonacci)

Recursive definitions require base case(s) and a recursive rule that eventually reaches the base.

Example 8.10 (Big-O in TypeScript ? verifying growth). Show that f(n)=100n+5f(n) = 100n + 5f(n)=100n+5 is O(n)O(n)O(n).

function verifyLinearGrowth(f: (n: number) => number, nMax: number): boolean {
  // Check if f(n) / n converges to a constant
  const ratios: number[] = [];
  for (let n = 1; n <= nMax; n++) {
    ratios.push(f(n) / n);
  }
  // Variance should be small for large n
  const mean = ratios.reduce((a, b) => a + b, 0) / ratios.length;
  const variance = ratios.reduce((sum, r) => sum + (r - mean) ** 2, 0) / ratios.length;
  return variance < 1; // heuristic
}

console.log(verifyLinearGrowth(n => 100 * n + 5, 1000)); // true

TypeScript: Function Properties Checker​

type Func<T, U> = Map<T, U>;

function isInjective<T, U>(f: Func<T, U>): boolean {
  const seen = new Set<U>();
  for (const v of f.values()) { if (seen.has(v)) return false; seen.add(v); }
  return true;
}

function isSurjective<T, U>(f: Func<T, U>, codomain: Set<U>): boolean {
  const images = new Set(f.values());
  for (const v of codomain) if (!images.has(v)) return false;
  return true;
}

function isBijective<T, U>(f: Func<T, U>, codomain: Set<U>): boolean {
  return isInjective(f) && isSurjective(f, codomain);
}

function inverseFunction(f: (x: number) => number, domain: number[], codomain: number[]): Map<number, number> | null {
  const mapping = new Map<number, number>();

    if (mapping.has(y)) return null; // not injective

  return mapping;

Summary​

  • Functions map each input to exactly one output.
  • Injective: one-to-one. Surjective: onto. Bijective: both.
  • Bijective functions have inverses; composition is associative but not commutative.
  • Floor/ceiling round to integers; growth rates are classified by big-O/Ω\OmegaΩ/Θ\ThetaΘ.
  • Common hierarchy: constant ≺\prec≺ logarithmic ≺\prec≺ linear ≺\prec≺ polynomial ≺\prec≺ exponential.

Practical Takeaways​

  2. Surjectivity depends on codomain ? changing the codomain can make a non-surjective function surjective.
  3. Inverse only for bijections ? only bijections have true inverses.
  4. Big-O ignores constants ? 1000n1000n1000n is O(n)O(n)O(n) just as much as 2n2n2n is.
  5. Dominant term wins ? in a sum, only the fastest-growing term matters asymptotically.

function isInjective<T, U>(f: (x: T) => U, domain: T[]): boolean {
  const seen = new Set<U>();

function inverse<T extends string | number>(
  f: (x: T) => T,
  domain: T[]
): ((y: T) => T) | null {
  const pairs = new Map(domain.map(x => [f(x), x] as [T, T]));
  if (pairs.size !== domain.length) return null; // not bijective

    const x = pairs.get(y);
    if (x === undefined) throw new Error("Not in range");
    return x;
  };

function growthClass(n: number, f: (n: number) => number): string {
  const logN = Math.log2(n);
  const nLogN = n * logN;
  const nSq = n * n;
  const nCb = n * n * n;
  const twoN = Math.pow(2, n);
  const fn = f(n);

  if (fn <= n) return "O(n) or less";
  if (fn <= nLogN) return "T(n log n)";
  if (fn <= nSq) return "T(n?)";
  if (fn <= nCb) return "T(n?)";
  if (fn <= twoN) return "O(2^n)";
  return "super-exponential";
}
