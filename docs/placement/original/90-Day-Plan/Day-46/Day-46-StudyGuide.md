# Day 46 — Advanced DP: Bitmask DP & Convex Hull Trick

## Learning Objectives
- Apply bitmask DP to solve small-state TSP problems (DP over subsets).
- Understand Convex Hull Trick (CHT) as an optimization technique for DP recurrences of the form dp[i] = min_j (m_j * x_i + b_j).

## Topics
- Bitmask DP: TSP, subset dynamic programming patterns
- CHT (add lines; query mins/maximums) and requirements for monotonic slopes/queries
- Li Chao tree, monotone deque methods, dynamic trick for more advanced cases

## Practice Problems
- BOI / Codeforces problems on state-space DP and bitmask optimizations
- DP optimization from DP on convex hull trick examples (slopes monotonic)
