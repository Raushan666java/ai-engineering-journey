# 📱 Learning Apps Installation - 15 Minutes

## 🎯 Essential Learning Stack

### Core Apps (Free)
```
□ Anki - Spaced repetition flashcards
  Download: ankiweb.net
  
□ Obsidian - Connected note-taking
  Download: obsidian.md
  
□ Forest - Focus timer with gamification
  Download: App Store/Google Play ($3)
  
□ Toggl - Time tracking
  Download: toggl.com (free tier)
```

### Quick Setup Commands

#### Anki Setup (5 minutes)
1. Download and install Anki
2. Create AnkiWeb account for sync
3. Import shared deck: "Data Structures & Algorithms"
4. Set daily review limit: 50 cards

#### Obsidian Setup (5 minutes)
1. Download and install Obsidian
2. Create new vault: "Learning_Vault"
3. Install plugins: Calendar, Daily Notes, Graph View
4. Create folders: Concepts, Practice, Progress

#### Forest Setup (2 minutes)
1. Download Forest app
2. Set default session: 25 minutes (Pomodoro)
3. Enable focus mode notifications
4. Connect with friends for accountability

#### Toggl Setup (3 minutes)
1. Create Toggl account
2. Create projects: Study, Practice, Review
3. Install browser extension
4. Set up mobile app for tracking

## ✅ Setup Verification

### Test Each App (5 minutes)
```

□ Obsidian: Create first learning note
□ Forest: Complete 25-minute focus session
□ Toggl: Track 10 minutes of study time
```

```
Daily Routine:

3. Anki: Create flashcards from notes
4. Toggl: Track time automatically
5. Review progress in each app
```
