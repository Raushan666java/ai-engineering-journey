# Applied AI Engineering

## Course Overview

This course bridges the gap between ML theory and production AI systems. It covers the three most in-demand applied skills: LLM orchestration with LangChain, computer vision with OpenCV, and generative AI (GANs, VAEs, diffusion models). Every chapter ships complete, runnable code.

**Target Audience:** ML engineers, AI application developers, data scientists moving into production.

**Prerequisites:** Python, basic deep learning concepts (neural networks, loss functions, backpropagation).
