Theory​

11.1 Binary Operations​

A binary operation on a set SSS is a function ∗:S×S→S* : S \times S \rightarrow S∗:S×S→S. For a,b∈Sa, b \in Sa,b∈S, a∗ba * ba∗b denotes the result.

Properties:

  • Closure: a∗b∈Sa * b \in Sa∗b∈S for all a,b∈Sa, b \in Sa,b∈S.
  • Associativity: (a∗b)∗c=a∗(b∗c)(a * b) * c = a * (b * c)(a∗b)∗c=a∗(b∗c) for all a,b,c∈Sa, b, c \in Sa,b,c∈S.
  • Commutativity: a∗b=b∗aa * b = b * aa∗b=b∗a for all a,b∈Sa, b \in Sa,b∈S.
  • Identity: There exists e∈Se \in Se∈S such that a∗e=e∗a=aa * e = e * a = aa∗e=e∗a=a for all a∈Sa \in Sa∈S.
  • Inverse: For each a∈Sa \in Sa∈S, there exists b∈Sb \in Sb∈S such that a∗b=b∗a=ea * b = b * a = ea∗b=b∗a=e.

One-Sentence Takeaway: A binary operation combines two elements; the properties it satisfies define the type of algebraic structure.

11.2 Semigroups and Monoids​

Semigroup: A set SSS with an associative binary operation ∗*∗.

  • Example: (Z+,+)(\mathbb{Z}^+, +)(Z+,+) is a semigroup.
  • Example: Strings under concatenation form a semigroup.

Monoid: A semigroup with an identity element.

  • Example: Strings under concatenation with the empty string ϵ\epsilonϵ as identity.
  • Example: (Z,+)(\mathbb{Z}, +)(Z,+) with identity 0.
  • Example: (Z,×)(\mathbb{Z}, \times)(Z,×) with identity 1.

One-Sentence Takeaway: A semigroup requires associativity; a monoid adds an identity element.

11.3 Groups​

A group (G,∗)(G, *)(G,∗) is a set GGG with a binary operation ∗*∗ satisfying:

  1. Closure: a∗b∈Ga * b \in Ga∗b∈G for all a,ba, ba,b.
  2. Associativity: (a∗b)∗c=a∗(b∗c)(a * b) * c = a * (b * c)(a∗b)∗c=a∗(b∗c).
  3. Identity: There exists e∈Ge \in Ge∈G with a∗e=e∗a=aa * e = e * a = aa∗e=e∗a=a.
  4. Inverse: For each aaa, there exists a−1a^{-1}a−1 with a∗a−1=a−1∗a=ea * a^{-1} = a^{-1} * a = ea∗a−1=a−1∗a=e.

Theorem 11.1 (Uniqueness). The identity element is unique. Each element has a unique inverse.

Theorem 11.2 (Cancellation laws). In any group:

  • If a∗b=a∗ca * b = a * ca∗b=a∗c, then b=cb = cb=c (left cancellation).
  • If b∗a=c∗ab * a = c * ab∗a=c∗a, then b=cb = cb=c (right cancellation).

Abelian group: A group where ∗*∗ is commutative.

Order of a group: ∣G∣|G|∣G∣, the number of elements.

Order of an element: The smallest positive integer nnn such that an=ea^n = ean=e (where ana^nan means a∗a∗⋯∗aa * a * \cdots * aa∗a∗⋯∗a, nnn times).

Theorem 11.3 (Subgroup criterion). A non-empty subset H⊆GH \subseteq GH⊆G is a subgroup (H≤GH \leq GH≤G) if and only if a,b∈H  ⟹  a∗b−1∈Ha, b \in H \implies a * b^{-1} \in Ha,b∈H⟹a∗b−1∈H.

One-Sentence Takeaway: A group is a set with an associative operation that has an identity and inverses; groups are the central objects of algebraic study.

11.4 Examples of Groups​

(Z,+)(\mathbb{Z}, +)(Z,+): Integers under addition. Identity 0. Inverse of nnn is −n-n−n. Infinite abelian group.

(Zn,+)(\mathbb{Z}_n, +)(Zn​,+): Integers modulo nnn under addition modulo nnn. Identity 0. Order nnn.

(Zn×,⋅)(\mathbb{Z}_n^\times, \cdot)(Zn×​,⋅): Units modulo nnn under multiplication. Elements coprime to nnn. Order ϕ(n)\phi(n)ϕ(n) (Euler's totient). Example: Z7×={1,2,3,4,5,6}\mathbb{Z}_7^\times = \{1,2,3,4,5,6\}Z7×​={1,2,3,4,5,6}.

Symmetric group SnS_nSn​: Permutations of nnn elements under composition. Order n!n!n!. Not abelian for n≥3n \geq 3n≥3.

Dihedral group DnD_nDn​: Symmetries of a regular nnn-gon (rotations and reflections). Order 2n2n2n.

11.5 Cyclic Groups​

A group GGG is cyclic if there exists an element g∈Gg \in Gg∈G (a generator) such that every element of GGG equals gkg^kgk for some integer kkk. In additive notation: every element equals k⋅gk \cdot gk⋅g.

Theorem 11.4 (Structure of cyclic groups).

  • Every cyclic group is abelian.
  • Every subgroup of a cyclic group is cyclic.
  • A finite cyclic group of order nnn is isomorphic to (Zn,+)(\mathbb{Z}_n, +)(Zn​,+).
  • An infinite cyclic group is isomorphic to (Z,+)(\mathbb{Z}, +)(Z,+).

Theorem 11.5 (Generators of Zn\mathbb{Z}_nZn​). An element k∈Znk \in \mathbb{Z}_nk∈Zn​ generates Zn\mathbb{Z}_nZn​ under addition if and only if gcd⁡(k,n)=1\gcd(k, n) = 1gcd(k,n)=1.

Theorem 11.6 (Subgroups of Zn\mathbb{Z}_nZn​). For each positive divisor ddd of nnn, there is exactly one subgroup of Zn\mathbb{Z}_nZn​ of order ddd, generated by n/dn/dn/d.

One-Sentence Takeaway: A cyclic group is generated by a single element; all cyclic groups of order nnn are isomorphic to Zn\mathbb{Z}_nZn​, and Zn\mathbb{Z}_nZn​ has one subgroup per divisor of nnn.

11.6 Permutation Groups​

A permutation of a set XXX is a bijection f:X→Xf: X \rightarrow Xf:X→X. The set of all permutations of XXX forms the symmetric group SXS_XSX​.

Cycle notation: (a1  a2  …  ak)(a_1\;a_2\;\dots\;a_k)(a1​a2​…ak​) means a1→a2→⋯→ak→a1a_1 \rightarrow a_2 \rightarrow \dots \rightarrow a_k \rightarrow a_1a1​→a2​→⋯→ak​→a1​.

Transposition: A 2-cycle (a  b)(a\;b)(ab).

Theorem 11.7 (Cycle decomposition). Every permutation can be written uniquely as a product of disjoint cycles (up to order of cycles).

Theorem 11.8 (Parity). Every permutation is either even (product of an even number of transpositions) or odd. The alternating group AnA_nAn​ consists of all even permutations in SnS_nSn​, ∣An∣=n!/2|A_n| = n!/2∣An​∣=n!/2.

One-Sentence Takeaway: Permutations are bijections on a set; every permutation decomposes into disjoint cycles, and the parity (even/odd) is well-defined.

11.7 Rings and Fields​

Ring (R,+,⋅)(R, +, \cdot)(R,+,⋅): A set with two operations such that:

  1. (R,+)(R, +)(R,+) is an abelian group.
  2. (R,⋅)(R, \cdot)(R,⋅) is a semigroup (associative, not necessarily commutative).
  3. Distributive: a(b+c)=ab+aca(b+c) = ab + aca(b+c)=ab+ac and (a+b)c=ac+bc(a+b)c = ac + bc(a+b)c=ac+bc.

Examples of rings: Z\mathbb{Z}Z (the integers), Zn\mathbb{Z}_nZn​ (integers mod nnn), Mn(R)M_n(\mathbb{R})Mn​(R) (n×nn \times nn×n matrices).

Commutative ring: Multiplication is commutative.

Integral domain: A commutative ring where ab=0ab = 0ab=0 implies a=0a = 0a=0 or b=0b = 0b=0 (no zero divisors).

Field: A commutative ring where every non-zero element has a multiplicative inverse.

  • Examples: Q\mathbb{Q}Q, R\mathbb{R}R, C\mathbb{C}C, Zp\mathbb{Z}_pZp​ (for prime ppp).

Theorem 11.9 (Finite fields). A finite field exists for every prime power pnp^npn. All finite fields of the same order are isomorphic. Zp\mathbb{Z}_pZp​ is a field if and only if ppp is prime.

// Modular arithmetic in Z_p (a field for prime p)
class Zp {
  constructor(public readonly p: number) {
    if (!isPrime(p)) throw new Error("p must be prime for Z_p to be a field");
  }

  add(a: number, b: number): number { return (a + b) % this.p; }
  multiply(a: number, b: number): number { return (a * b) % this.p; }

  inverse(a: number): number {
    // Using extended Euclidean algorithm
    let t = 0, newt = 1, r = this.p, newr = a;
    while (newr !== 0) {
      const q = Math.floor(r / newr);
      [t, newt] = [newt, t - q * newt];
      [r, newr] = [newr, r - q * newr];
    }
    return ((t % this.p) + this.p) % this.p;
  }
}

function isPrime(n: number): boolean {
  if (n < 2) return false;
  for (let i = 2; i * i <= n; i++) if (n % i === 0) return false;
  return true;
}

One-Sentence Takeaway: A ring has addition and multiplication; a field adds multiplicative inverses (making division possible); finite fields exist exactly for prime power orders.

11.8 Homomorphisms and Isomorphisms​

Group homomorphism: ϕ:G→H\phi: G \rightarrow Hϕ:G→H such that ϕ(a∗b)=ϕ(a)⋅ϕ(b)\phi(a * b) = \phi(a) \cdot \phi(b)ϕ(a∗b)=ϕ(a)⋅ϕ(b) for all a,b∈Ga, b \in Ga,b∈G.

Kernel: ker⁡(ϕ)={g∈G∣ϕ(g)=eH}\ker(\phi) = \{g \in G \mid \phi(g) = e_H\}ker(ϕ)={g∈G∣ϕ(g)=eH​}.

Image: im(ϕ)={h∈H∣∃g∈G,ϕ(g)=h}\text{im}(\phi) = \{h \in H \mid \exists g \in G, \phi(g) = h\}im(ϕ)={h∈H∣∃g∈G,ϕ(g)=h}.

Theorem 11.10 (Properties of homomorphisms). For any homomorphism ϕ\phiϕ:

  • ϕ(eG)=eH\phi(e_G) = e_Hϕ(eG​)=eH​.
  • ϕ(a−1)=ϕ(a)−1\phi(a^{-1}) = \phi(a)^{-1}ϕ(a−1)=ϕ(a)−1.
  • ker⁡(ϕ)\ker(\phi)ker(ϕ) is a subgroup of GGG.
  • im(ϕ)\text{im}(\phi)im(ϕ) is a subgroup of HHH.
  • ϕ\phiϕ is injective iff ker⁡(ϕ)={eG}\ker(\phi) = \{e_G\}ker(ϕ)={eG​}.

Isomorphism: A bijective homomorphism. G≅HG \cong HG≅H means GGG and HHH are isomorphic (structurally identical).

Theorem 11.11 (Cayley's theorem). Every group is isomorphic to a subgroup of a symmetric group SnS_nSn​ for some nnn.

11.9 Direct Sums and Product Groups​

The direct product of groups GGG and HHH is G×H={(g,h)∣g∈G,h∈H}G \times H = \{(g,h) \mid g \in G, h \in H\}G×H={(g,h)∣g∈G,h∈H} with componentwise operation: (g1,h1)∗(g2,h2)=(g1∗g2,h1∗h2)(g_1, h_1) * (g_2, h_2) = (g_1 * g_2, h_1 * h_2)(g1​,h1​)∗(g2​,h2​)=(g1​∗g2​,h1​∗h2​).

Theorem 11.12 (Order of direct product). ∣G×H∣=∣G∣⋅∣H∣|G \times H| = |G| \cdot |H|∣G×H∣=∣G∣⋅∣H∣.

Theorem 11.13 (Chinese Remainder Theorem for Groups). If gcd⁡(m,n)=1\gcd(m,n) = 1gcd(m,n)=1, then Zmn≅Zm×Zn\mathbb{Z}_{mn} \cong \mathbb{Z}_m \times \mathbb{Z}_nZmn​≅Zm​×Zn​. This is the algebraic version of the CRT from number theory.

11.10 The Classification of Finite Fields​

Theorem 11.14 (Existence and uniqueness of finite fields). For every prime ppp and positive integer nnn, there exists a finite field of order pnp^npn (denoted GF(pn)\text{GF}(p^n)GF(pn) or Fpn\mathbb{F}_{p^n}Fpn​). All finite fields of the same order are isomorphic.

Theorem 11.15 (Subfield criterion). Fpm\mathbb{F}_{p^m}Fpm​ is a subfield of Fpn\mathbb{F}_{p^n}Fpn​ if and only if m∣nm \mid nm∣n.

Finite fields are widely used in cryptography (AES uses GF(28)\text{GF}(2^8)GF(28)), coding theory (Reed-Solomon codes), and computer algebra.

// --- Closure, Associativity, Identity, Inverses Checker ---
function isGroup(set: number[], op: (a: number, b: number) => number): boolean {
  // Closure and associativity are checked on the operation
  for (const a of set) for (const b of set) if (!set.includes(op(a, b))) return false;
  // Identity
  let identity = -1;
  for (const e of set) if (set.every(x => op(x, e) === x && op(e, x) === x)) { identity = e; break; }
  if (identity === -1) return false;
  // Inverses
  for (const a of set) if (!set.some(b => op(a, b) === identity && op(b, a) === identity)) return false;
  return true;
}

// --- Cyclic Group Checker & Generator Finder ---
function findGenerators(set: number[], op: (a: number, b: number) => number): number[] {
  const n = set.length;
  return set.filter(g => {
    const generated = new Set<number>();
    let current = g;
    for (let i = 0; i < n; i++) {
      generated.add(current);
      current = op(current, g);
    }
    return generated.size === n;
  });
}

  const identity = findIdentity(groupTable);
  if (!subset.includes(identity)) return false;
  for (const a of subset) {
    const inv = findInverse(groupTable, a);
    if (!subset.includes(inv)) return false;
    for (const b of subset)
      if (!subset.includes(groupTable[a][b])) return false;
  }
  return true;
}

// --- Ring Property Checker ---
function isRing(addTable: number[][], mulTable: number[][], set: number[]): boolean {
  const addAssoc = set.every(a => set.every(b => set.every(c =>
    addTable[addTable[a][b]][c] === addTable[a][addTable[b][c]])));
  const addComm = set.every(a => set.every(b => addTable[a][b] === addTable[b][a]));
  const identity = addTable.some((r, i) => set.every(a => addTable[a][i] === a));
  const mulAssoc = set.every(a => set.every(b => set.every(c =>
    mulTable[mulTable[a][b]][c] === mulTable[a][mulTable[b][c]])));
  const distrib = set.every(a => set.every(b => set.every(c =>
    mulTable[a][addTable[b][c]] === addTable[mulTable[a][b]][mulTable[a][c]])));
  return addAssoc && addComm && identity !== false && mulAssoc && distrib;
}

// --- Field Checker ---
function isField(addTable: number[][], mulTable: number[][], set: number[]): boolean {
  if (!isRing(addTable, mulTable, set)) return false;
  const zero = addTable.findIndex((r, i) => set.every(a => addTable[a][i] === a));
  const nonzero = set.filter(x => x !== zero);
  const mulInv = nonzero.every(a => nonzero.some(b => mulTable[a][b] === set[nonzero[0]]));
  return mulInv;
}

Summary​

  • Binary operations combine two elements; properties define the algebraic structure.
  • Semigroup: associative. Monoid: semigroup + identity. Group: monoid + inverses.
  • Important groups: Zn\mathbb{Z}_nZn​, Zn×\mathbb{Z}_n^\timesZn×​, SnS_nSn​, DnD_nDn​.
  • Cyclic groups are generated by one element; every cyclic group is isomorphic to Zn\mathbb{Z}_nZn​.
  • Rings have two operations; fields add multiplicative inverses beyond rings.
  • Homomorphisms preserve structure; isomorphisms indicate structural identity.

Practical Takeaways​

  1. Group = symmetries ? whenever you think about rotations, permutations, or reversible transformations, you are working in a group.
  2. Fields enable division ? the difference between a ring and a field is that fields let you divide.
  3. Zp\mathbb{Z}_pZp​ is a field when ppp is prime ? this is the foundation of modern cryptography.
  4. Cyclic = one generator ? finding a generator enables efficient computation in the group.
  5. Homomorphism preserves the operation ? always check ϕ(a∗b)=ϕ(a)⋅ϕ(b)\phi(a*b) = \phi(a) \cdot \phi(b)ϕ(a∗b)=ϕ(a)⋅ϕ(b).

A group action is a formal way for a group to act on a set. A group GGG acts on a set XXX if there is a map ⋅:G×X→X\cdot : G \times X \to X⋅:G×X→X satisfying:

  1. e⋅x=xe \cdot x = xe⋅x=x for all x∈Xx \in Xx∈X (identity).
  2. (g1g2)⋅x=g1⋅(g2⋅x)(g_1 g_2) \cdot x = g_1 \cdot (g_2 \cdot x)(g1​g2​)⋅x=g1​⋅(g2​⋅x) for all g1,g2∈Gg_1, g_2 \in Gg1​,g2​∈G, x∈Xx \in Xx∈X (compatibility).

11.7 Rings and Fields in Depth​

Definition 11.11 (Ring). A set RRR with two binary operations +++ and ⋅\cdot⋅ such that:

  • (R,+)(R, +)(R,+) is an abelian group.
  • (R,⋅)(R, \cdot)(R,⋅) is a semigroup.
  • Multiplication distributes over addition: a(b+c)=ab+aca(b+c) = ab + aca(b+c)=ab+ac and (b+c)a=ba+ca(b+c)a = ba + ca(b+c)a=ba+ca.

Definition 11.12 (Integral Domain). A commutative ring with 1≠01 \neq 01=0 and no zero divisors (ab=0  ⟹  a=0ab = 0 \implies a = 0ab=0⟹a=0 or b=0b = 0b=0).

Definition 11.13 (Field). A commutative ring where every nonzero element has a multiplicative inverse.

interface Ring<T> {
  add: (a: T, b: T) => T;
  mul: (a: T, b: T) => T;
  zero: T;
  one: T;
  neg: (a: T) => T;
  equals: (a: T, b: T) => boolean;
}

function isIntegralDomain<T>(R: Ring<T>, elements: T[]): boolean {
  for (const a of elements) {
    for (const b of elements) {
      if (R.equals(R.mul(a, b), R.zero)) {
        if (!R.equals(a, R.zero) && !R.equals(b, R.zero)) return false;
      }
    }
  }
  return true;
}

function isField<T>(R: Ring<T>, elements: T[]): boolean {
  if (!isIntegralDomain(R, elements)) return false;
  for (const a of elements) {
    if (R.equals(a, R.zero)) continue;
    let hasInverse = false;
    for (const b of elements) {
      if (R.equals(R.mul(a, b), R.one)) { hasInverse = true; break; }
    }
    if (!hasInverse) return false;
  }
  return true;
}

11.8 Group Homomorphisms and Isomorphism Theorems​

Theorem 11.4 (First Isomorphism Theorem). If ϕ:G→H\phi: G \to Hϕ:G→H is a homomorphism, then G/ker⁡(ϕ)≅Im(ϕ)G / \ker(\phi) \cong \text{Im}(\phi)G/ker(ϕ)≅Im(ϕ).

function isHomomorphism<T, U>(
  G: T[],
  opG: (a: T, b: T) => T,
  H: U[],
  opH: (a: U, b: U) => U,
  phi: (x: T) => U
): boolean {
  for (const a of G) {
    for (const b of G) {
      const lhs = phi(opG(a, b));
      const rhs = opH(phi(a), phi(b));
      if (lhs !== rhs) return false;
    }
  }
  return true;
}

11.9 Algebraic Structures in Cryptography​

Diffie-Hellman key exchange relies on the cyclic group Zp×\mathbb{Z}_p^\timesZp×​:

  • Public: prime ppp, generator ggg.
  • Alice: picks aaa, sends ga mod pg^a \bmod pgamodp.
  • Bob: picks bbb, sends gb mod pg^b \bmod pgbmodp.
  • Shared secret: gab mod pg^{ab} \bmod pgabmodp.
function diffieHellman(p: number, g: number, a: number, b: number) {
  const A = Math.pow(g, a) % p;
  const B = Math.pow(g, b) % p;
  const secretA = Math.pow(B, a) % p;
  const secretB = Math.pow(A, b) % p;
  return { A, B, secretA, secretB, match: secretA === secretB };
}
console.log(diffieHellman(23, 5, 6, 15)); // shared secret = 2

RSA encryption uses the ring Zn\mathbb{Z}_nZn​ where n=pqn = pqn=pq:

  • Public key: (n,e)(n, e)(n,e), private key: ddd.
  • Encrypt: c=me mod nc = m^e \bmod nc=memodn.
  • Decrypt: m=cd mod nm = c^d \bmod nm=cdmodn.
function rsaEncrypt(m: number, e: number, n: number): number {
  return Math.pow(m, e) % n;
}

function rsaDecrypt(c: number, d: number, n: number): number {
  return Math.pow(c, d) % n;
}

function cayleyTable(elements: number[], op: (a: number, b: number) => number): number[][] {
  const n = elements.length;
  const table: number[][] = [];
  for (let i = 0; i < n; i++) {
    table[i] = [];
    for (let j = 0; j < n; j++) {
      table[i][j] = op(elements[i], elements[j]);
    }
  }
  return table;
}
