# Data Structures & Algorithms (DSA) Syllabus
*Total Duration: 12-16 weeks*

## 1. Fundamentals (Week 1-2) 🟢
**Time & Space Complexity**
- Big-O, Big-Ω, Big-Θ notation
- Best/Average/Worst case analysis
- Space-time tradeoffs

**Arrays & Strings**
- 1D/2D arrays, operations (O(1) access)
- String manipulation, pattern matching
- **Problems:** Two Sum, Maximum Subarray, Valid Anagram

## 2. Linear Data Structures (Week 3-4) 🟡
**Linked Lists**
- Singly/Doubly/Circular implementation
- Insertion, deletion, traversal
- **Problems:** Reverse List, Cycle Detection, Merge Lists

**Stacks & Queues**
- LIFO/FIFO operations, applications
- Implementation using arrays/linked lists
- **Problems:** Valid Parentheses, Next Greater Element

## 3. Non-Linear Structures (Week 5-7) 🟠
**Trees**
- Binary Tree: traversals (in/pre/post-order)
- BST: search, insert, delete
- AVL, Segment Trees
- **Problems:** Level Order, Validate BST, LCA

**Heaps**
- Min/Max heap, heapify operations
- Priority Queue implementation
- **Problems:** Kth Largest, Merge K Lists

## 4. Advanced Structures (Week 8-9) 🔴
**Graphs**
- Adjacency matrix/list representation
- BFS, DFS traversals
- Shortest path: Dijkstra, Floyd-Warshall
- MST: Kruskal, Prim
- **Problems:** Clone Graph, Course Schedule

**Hashing**
- Hash functions, collision resolution
- HashMap/HashSet operations
- **Problems:** Group Anagrams, LRU Cache

## 5. Problem-Solving Techniques (Week 10-12) 🔴
**Dynamic Programming**
- Memoization vs Tabulation
- 1D/2D DP patterns
- **Problems:** Fibonacci, Coin Change, LIS

**Sliding Window & Two Pointers**
- Fixed/Variable window techniques
- **Problems:** Longest Substring, Container With Water

**Backtracking**
- Decision tree approach
- **Problems:** N-Queens, Sudoku Solver

## 6. Specialized Topics (Week 13-16) 🔴
**Greedy Algorithms**
- Activity Selection, Huffman Coding

**Bit Manipulation**
- Bitwise operators, bit masking
- **Problems:** Single Number, Power of Two

**Advanced Algorithms**
- Union-Find, Trie, KMP

## Practice Strategy
- **Daily:** 2-3 problems (mix of easy/medium)
- **Weekly:** 1 hard problem, topic revision
- **Platforms:** LeetCode (primary), GeeksforGeeks, HackerRank
- **Target:** 300+ problems before interviews
