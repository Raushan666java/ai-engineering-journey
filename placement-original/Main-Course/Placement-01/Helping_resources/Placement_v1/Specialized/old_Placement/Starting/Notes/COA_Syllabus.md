# SECTION 1: Core CS Subjects

## 5. Computer Organization and Architecture (COA)

### A. Number Systems & Arithmetic

- Binary, octal, decimal, hexadecimal
- Binary arithmetic: addition, subtraction, multiplication, division
- Complements: 1's, 2's

### B. Digital Circuits

- Combinational: adders, subtractors, multiplexers, encoders, decoders
- Sequential: flip-flops, registers, counters, memory

### C. CPU & Memory

- ALU, registers, instruction cycle, fetch-decode-execute
- Memory hierarchy: cache, RAM, ROM, virtual memory
- Addressing modes: immediate, direct, indirect, indexed, base

### D. Pipelining & Hazards

- Pipeline stages, hazards (structural, data, control), solutions
- Instruction-level parallelism

### E. Instruction Set Architecture

- RISC vs CISC, instruction formats, addressing
- Microprogramming basics

### F. I/O & Peripherals

- I/O methods: programmed, interrupt-driven, DMA
- Peripheral devices: keyboard, display, disk
