# AJAX Interview Questions & Revision Notes

## Revision Notes
- AJAX (Asynchronous JavaScript and XML) enables asynchronous web requests without reloading the page.
- Uses `XMLHttpRequest` or `fetch()` for requests; jQuery provides `$.ajax()`, `$.get()`, `$.post()`.
- Common data formats: JSON, XML.
- AJAX workflow: send request, handle response, update DOM.
- Handle errors and loading states for good UX.
- Cross-origin requests require CORS headers.
- Best practices: use promises, handle errors, sanitize data, avoid blocking UI.
