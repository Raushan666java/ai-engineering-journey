# 🤖 AI Prompts Library - Ready-to-Use Templates

## 🎯 Quick Access Prompts

### Learning Fundamentals
```
Concept Mastery:
"Explain [CONCEPT] like I'm 12 with analogies and 3 practice questions"

Problem Generation:
"Generate 5 [DIFFICULTY] problems for [TOPIC] with solutions"

Memory Aid:
"Create memory palace story for [LIST] using [LOCATION]"

Study Planning:
"Create study plan for [GOAL] in [TIMELINE] with daily schedule"
```

### AI Learning Coach Setup
```
"You are my AI Learning Coach for [SUBJECT].

Your role:
- Explain concepts simply with analogies
- Generate practice problems at my level
- Test my understanding regularly
- Track my progress and adapt
- Provide motivation and encouragement

My profile:
- Current level: [BEGINNER/INTERMEDIATE/ADVANCED]
- Goal: [SPECIFIC OBJECTIVE]
- Timeline: [WEEKS AVAILABLE]
- Learning style: [VISUAL/AUDITORY/KINESTHETIC]

Start by assessing my knowledge of [TOPIC]."
```

### Subject-Specific Templates

#### DSA Practice
```
"Act as my DSA interview coach.

For [ALGORITHM/DATA STRUCTURE]:
1. Explain with simple analogy
2. Show implementation pattern
3. Generate 3 practice problems
4. Test my understanding
5. Provide optimization tips

My level: [ASSESSMENT]
Focus: [WEAK AREAS]
Target: [COMPANY] interviews"
```

#### System Design
```
"Help me design [SYSTEM] step-by-step.

Process:
1. Gather requirements
2. Estimate capacity
3. Design high-level architecture
4. Detail key components
5. Address scalability
6. Discuss trade-offs

My experience: [LEVEL]
Time limit: [MINUTES]"
```

#### Interview Prep
```
"Conduct mock [INTERVIEW TYPE] for [ROLE].

Format:
1. Ask realistic questions
2. Evaluate my responses
3. Provide specific feedback
4. Suggest improvements
5. Rate readiness (1-10)

Company focus: [TARGET COMPANIES]"
```

### Progress Tracking
```
Daily Analysis:
"Analyze my learning session:
- Time: [MINUTES]
- Topics: [LIST]
- Problems solved: [COUNT]
- Difficulty: [RATING]
- Energy: [1-10]

Provide insights and tomorrow's plan."

Weekly Review:
"Review my week's data: [PASTE DATA]
Calculate learning velocity and suggest optimizations."
```

### Debugging & Problem Solving
```
Code Debug:
"Debug this code step-by-step:
[PASTE CODE]
Error: [DESCRIPTION]
Guide me to the solution."

Concept Clarification:
"I'm confused about [CONCEPT].
My understanding: [EXPLANATION]
Identify gaps and help me improve."
```

## 🔧 Prompt Optimization Templates

### Quality Control
```
"Before responding, verify:
1. Technical accuracy (fact-check)
2. Appropriate difficulty level
3. Clear explanations
4. Practical examples
5. Actionable next steps

Rate confidence (1-10) for each area."
```

### Iterative Improvement
```
"Your previous response scored [X]/10.
Improve by:
- [SPECIFIC ISSUE 1]
- [SPECIFIC ISSUE 2]
- [SPECIFIC ISSUE 3]

Revise while keeping good aspects: [LIST]"
```

## 📊 Usage Guidelines

### Customization Tips
- Replace [BRACKETS] with your specific information
- Adjust difficulty level to match your needs
- Combine prompts for comprehensive assistance
- Test and refine based on results

### Best Practices
- Be specific about your context
- Provide relevant background
- Ask for explanations of reasoning
- Request multiple approaches
- Use follow-up questions
