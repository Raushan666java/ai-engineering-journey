# Laravel Reverb

## Introduction
Reverb is Laravel's first-party WebSocket server for real-time broadcasting.

## Key Topics
- Installation & configuration
- Running the Reverb server
- Broadcasting with Reverb
- Authentication & security
- Scaling & deployment

---

## Details
- **Install:** `composer require laravel/reverb`
- **Run:** `php artisan reverb:start`
- **Broadcast:** Use Reverb as your broadcast driver.
- **Security:** Use channel authorization and HTTPS.
