## 📚 Course Structure

### **Week 1-2: Security Fundamentals**
- CIA Triad (Confidentiality, Integrity, Availability)
- Security Principles & Best Practices
- Threat Modeling
- Risk Assessment
- Security Frameworks (NIST, ISO 27001)

### **Week 3-4: Network Security**
- TCP/IP Security
- Firewalls & IDS/IPS
- VPN & Secure Tunneling
- Network Attacks (DDoS, MITM, Spoofing)
- Network Monitoring & Analysis

### **Week 5-6: Web Application Security**
- OWASP Top 10 Vulnerabilities
- SQL Injection
- XSS (Cross-Site Scripting)
- CSRF (Cross-Site Request Forgery)
- Authentication & Session Management
- Secure API Design

### **Week 7-8: Cryptography**
- Symmetric vs Asymmetric Encryption
- Hashing Algorithms
- Digital Signatures
- SSL/TLS
- PKI (Public Key Infrastructure)
- Cryptographic Attacks

### **Week 9-10: Penetration Testing**
- Reconnaissance & Information Gathering
- Vulnerability Scanning
- Exploitation Techniques
- Post-Exploitation
- Reporting & Documentation
- Tools: Metasploit, Burp Suite, Nmap

### **Week 11: Cloud & DevSecOps**
- AWS/Azure Security
- Container Security (Docker, Kubernetes)
- CI/CD Security
- Infrastructure as Code Security
- Secrets Management

### **Week 12: Incident Response & Compliance**
- Incident Response Process
- Forensics Basics
- Compliance (GDPR, PCI-DSS, HIPAA)
- Security Auditing
- Career Preparation
