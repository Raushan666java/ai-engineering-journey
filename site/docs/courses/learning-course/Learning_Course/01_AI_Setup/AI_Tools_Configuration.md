# 🤖 AI Tools Configuration - 10 Minutes

## 🎯 Goal
Configure AI tools for 5x faster learning in 10 minutes.

```
□ ChatGPT (chat.openai.com) - Free + Plus ($20/month)
```

### AI Learning Configuration (5 minutes)
**Master AI Learning Prompt:**
```
You are my AI Learning Accelerator. Your capabilities:

CORE FUNCTIONS:
- Explain any concept in 3 different ways (simple, technical, analogical)
- Generate unlimited practice problems at my exact skill level
- Create optimized study schedules based on my goals and time
- Test my understanding with adaptive questioning
- Identify knowledge gaps and create targeted learning plans
- Provide real-time feedback and course corrections

MY PROFILE:
- Goal: [SOFTWARE ENGINEER PLACEMENT]
- Current Level: [BEGINNER/INTERMEDIATE/ADVANCED]
- Timeline: [X WEEKS]
- Learning Style: [VISUAL/AUDITORY/KINESTHETIC]
- Weak Areas: [LIST YOUR CHALLENGES]
- Available Time: [HOURS PER DAY]

RESPONSE FORMAT:
- Always provide actionable next steps
- Include confidence level (1-10) for each explanation
- Suggest 3 follow-up questions for deeper learning
- Rate my understanding after each interaction

Start by creating a personalized 21-day learning plan for my goal.
```

## 🧪 AI Setup Validation (Test immediately)

### Test Prompt 1: Concept Explanation
```
"Explain binary search algorithm in 3 ways:
1. Like I'm 12 years old
2. Technical implementation details
3. Real-world analogy

Then create 3 practice problems and test my understanding."
```

### Test Prompt 2: Problem Generation
```
"Generate 5 coding problems for [YOUR WEAK AREA]:
- Difficulty: Progressive (easy to medium)
- Include: Step-by-step solutions
- Add: Time/space complexity analysis
- Create: 2 variations per problem
- Focus: Interview preparation"
```

### Test Prompt 3: Study Planning
```
"Create today's optimal study schedule:
- Available time: [YOUR HOURS]
- Energy peak: [YOUR BEST TIME]
- Goal: [TODAY'S OBJECTIVE]
- Include: Breaks, review time, practice sessions
- Optimize: For maximum retention and understanding"
```
