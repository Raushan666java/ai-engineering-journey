# Day 47 Notes: Binary Search Advanced

## Overview
Day 47 focuses on advanced binary search patterns, search-on-answer, and variants like exponential and ternary search.

## Key Techniques
- Boundary search for first/last occurrence
- Search over the answer (e.g., minimum time to complete tasks)
- Partition-based binary searches for Kth problems
- Ternary search for unimodal function optimization

## Test Strategy

- Long arrays with repeated numbers to validate boundary conditions
- Search on answer: validate with feasibility function and binary search wrapper
