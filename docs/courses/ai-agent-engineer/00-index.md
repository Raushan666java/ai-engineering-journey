# Laravel Backend Developer → AI Agent Engineer

A 12-week, 6-phase transition curriculum. Builds on your existing production experience (multi-tenant ERPs, WhatsApp AI, n8n automation) and fills the gaps — Python async, RAG theory, LangGraph orchestration, MCP, and production hardening.

## Prerequisites

- Production Laravel/PHP experience (multi-tenant systems, payments, APIs)
- Working knowledge of Docker, Linux VPS, Git, Redis
- Python basics (you can read/write it, even if not daily)
- A Hetzner VPS with Docker and Cloudflare Tunnel running

## What you'll build

| Phase | Project | What it proves |
|-------|---------|----------------|
| 1 | Real estate booking module ported to FastAPI | You can ship business logic in Python, not just Laravel |
| 2 | Public RAG Memory API | You understand vector search, chunking, retrieval end-to-end |
| 3 | LangGraph Purvanchal orchestration | You can build agent state machines, not just use visual builders |
| 4 | Production hardening on both | You deploy with CI, logging, cost controls, and metrics |
| 5 | Portfolio + applications | You package everything into something a recruiter understands in 60 seconds |

## Time commitment

| Phase | Weeks | Hours | Type |
|-------|-------|-------|------|
| 0 — Backend gap-fill | 1 | 14-18 | Concepts, no project code |
| 1 — Python/FastAPI/Async | 2 | 32-34 | Project: booking module port |
| 2 — LLM + RAG | 2 | 28-32 | Project: RAG demo API |
| 3 — Agents/LangGraph/MCP | 3 | 35-40 | Project: Purvanchal rebuild |
| 4 — Production hardening | 2 | 24-26 | Both projects retrofitted |
| 5 — Portfolio + positioning | 2 + ongoing | 16-20 + applications | Profile rewrite + outreach |

**Total: ~150-170 hours, 12 weeks with buffer. Plus ongoing job search (see [playbook](08-job-search-playbook.md)).**
