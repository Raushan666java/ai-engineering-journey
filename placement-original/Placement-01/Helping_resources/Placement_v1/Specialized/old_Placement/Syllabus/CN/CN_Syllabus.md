# Computer Networks (CN) Detailed Syllabus

## A. Network Models

- OSI (7 layers): functions, protocols
- TCP/IP (4 layers): mapping, protocols

## B. Physical & Data Link Layer

- Transmission media, encoding
- Framing, error detection/correction
- MAC protocols, Ethernet

## C. Network Layer

- IP addressing: IPv4/IPv6, subnetting, CIDR
- Routing: static/dynamic, algorithms (RIP, OSPF, BGP)
- ARP, ICMP, NAT, firewalls

## D. Transport Layer

- TCP: features, segment format, handshakes, flow/congestion control
- UDP: features, datagram format, comparison
- Applications: DNS, DHCP, streaming

## E. Application Layer

- Protocols: HTTP/HTTPS, FTP, SMTP, POP3/IMAP, DNS, DHCP
- Web technologies: URL/URI, cookies, caching, REST APIs

## F. Network Devices & Security

- Devices: switch, router, hub, gateway, modem
- Security: firewalls, VPN, encryption, SSL/TLS, IPSec
