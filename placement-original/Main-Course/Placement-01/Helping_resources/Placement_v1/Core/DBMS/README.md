## Study Plan

Follow this 4-week study plan to master DBMS concepts:

### Week 1: Fundamentals
- Introduction to DBMS
- ER Model and Database Design
- SQL Basics (DDL, DML commands)
- Practice: 10 basic SQL queries daily

### Week 2: Relational Model & Normalization
- Relational Model and Algebra
- Normalization (1NF to BCNF)
- SQL Joins and Subqueries
- Practice: 10 intermediate SQL queries daily

### Week 3: Transaction Management
- ACID Properties
- Concurrency Control
- Recovery Systems
- Practice: Complex SQL queries and transaction examples

### Week 4: Advanced Topics & Interview Prep
- Indexing and Query Optimization
- Advanced SQL (Stored Procedures, Triggers)
- NoSQL Databases
- Practice: Interview questions and SQL problem solving

## Key Focus Areas for Interviews

1. **Normalization**: Be able to identify normal forms and normalize tables
2. **SQL Queries**: Practice complex joins, subqueries, and aggregations
3. **Transaction Management**: Understand ACID properties and isolation levels
4. **Indexing**: Know when and how to use different types of indexes
5. **ER Modeling**: Practice converting requirements to ER diagrams and schemas

## Interview Success Tips

1. **Understand the fundamentals** rather than memorizing syntax
2. **Practice writing SQL queries** without IDE assistance
3. **Draw ER diagrams** to explain database design concepts
4. **Explain trade-offs** in database design decisions
5. **Be familiar with real-world applications** of DBMS concepts
