# 🏃 Daily Learning Exercises

## Week 1: Foundation Building

### Day 1: Learning Science
**Morning (30 min):**
- [ ] Read Module 1
- [ ] Try Pomodoro technique

**Evening (15 min):**
- [ ] Reflect on learning session

### Day 2: Memory Techniques
**Morning (45 min):**
- [ ] Create 10 flashcards
- [ ] Practice active recall
- [ ] Try memory palace for one topic

**Evening (15 min):**
- [ ] Review flashcards
- [ ] Update spaced repetition schedule

### Day 3: Study Methods
**Morning (60 min):**
- [ ] Use Feynman technique on complex topic

- [ ] Create mind map

**Evening (20 min):**
- [ ] Review notes using active recall
- [ ] Identify knowledge gaps

### Day 4: Time Management
**Morning (30 min):**
- [ ] Plan day using time blocking
- [ ] Use Eisenhower matrix
- [ ] Set up GTD system

**Throughout day:**
- [ ] Track time spent on activities
- [ ] Use Pomodoro for focused work

### Day 5: Mindset
**Morning (20 min):**
- [ ] Write growth mindset affirmations
- [ ] Identify fixed mindset thoughts
- [ ] Set learning goals

**Evening (15 min):**
- [ ] Celebrate day's progress
- [ ] Plan next week's learning
