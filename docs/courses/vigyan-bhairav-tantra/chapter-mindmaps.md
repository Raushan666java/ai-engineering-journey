## अध्याय 01: परिचय — ओशो का दृष्टिकोण

`mermaid
mindmap

      व्याख्याता

      व्यावहारिक मार्ग
`

### मुख्य बिंदु (Key Takeaways)

1. **तंत्र एक धर्म नहीं, एक विज्ञान है** — ओशो तंत्र को एक प्रयोगात्मक विज्ञान के रूप में प्रस्तुत करते हैं।
2. **विज्ञान भैरव तंत्र का महत्व** — सबसे प्राचीन ध्यान शास्त्र, 112 ध्यान विधियाँ।
3. **ओशो का आधुनिक संदर्भ** — प्राचीन विधियों को आधुनिक संदर्भ में पुनः व्याख्यायित।
4. **कोई पूर्वापेक्षा नहीं** — किसी दीक्षा या विश्वास की आवश्यकता नहीं।
5. **ध्यान = अनुभव** — करने और अनुभव करने की चीज़ है।
6. **प्रत्येक व्यक्ति अलग** — अपनी प्रकृति के अनुसार विधि चुनें।
7. **प्रयोगशाला के रूप में जीवन** — स्वयं पर प्रयोग करें।
8. **शास्त्र से अधिक अनुभव** — स्वयं अनुभव किया हुआ ही सत्य है।

### संस्कृत शब्दावली

|------|-----------------|

| **भैरव** | चेतना की वह अवस्था जो भय से परे है |
| **तंत्र** | स्वीकार करने की कला, विस्तार |
| **साक्षी** | मन की अवस्था जहाँ बिना निर्णय के देखते हैं |

## अध्याय 02: ओशो की तंत्र दृष्टि

`mermaid
flowchart TD
    A["तंत्र दृष्टि"] --> B["स्वीकार का मार्ग"]
    A --> C["ऊर्जा का रूपांतरण"]
    A --> D["साक्षी चेतना"]
    B --> B1["जीवन को नकारो मत"]
    B --> B2["सब कुछ पवित्र है"]
    B --> B3["कोई पाप नहीं"]
    C --> C1["काम से समाधि"]
    C --> C2["क्रोध से करुणा"]
    C --> C3["भय से स्वतंत्रता"]
    D --> D1["करने वाला नहीं"]
    D --> D2["देखने वाला बनो"]
    D --> D3["गवाह बनो"]
`

### मुख्य बिंदु

1. **तंत्र = स्वीकार** — जीवन को वैसे स्वीकार करना जैसा वह है।
2. **त्याग नहीं, उपयोग** — हर चीज़ का उपयोग करो, ऊर्जा का रूपांतरण करो।
3. **कोई पाप नहीं** — केवल अज्ञान और ज्ञान है।
4. **काम और समाधि** — यौन ऊर्जा को आध्यात्मिक ऊर्जा में रूपांतरित करना।
5. **नैतिकता vs. तंत्र** — नैतिकता बाहर से लादी जाती है, तंत्र भीतर से जागता है।
6. **यहीं और अभी** — इसी क्षण में मुक्त होना सिखाता है।
7. **पूर्ण जागरूकता** — हर क्रिया को पूर्ण जागरूकता से करना।

### संस्कृत शब्दावली

| शब्द | ओशो की परिभाषा |
|------|-----------------|
| **तंत्र** | विस्तार — चेतना का विस्तार |
| **समाधि** | जहाँ ध्यान करने वाला और ध्यान एक हो जाते हैं |
| **शिव** | चेतना का शुद्ध रूप, कोई देवता नहीं |
| **शक्ति** | ब्रह्मांड की मूल ऊर्जा |

### मुख्य बिंदु

1. **पाँच मुख्य श्रेणियाँ** — श्वास, शारीरिक, दृश्य, ध्वनि, भाव/साक्षी।
2. **श्वास विधियाँ (20)** — श्वास पर ध्यान, प्राणायाम, श्वास-विचार संबंध।
3. **शारीरिक विधियाँ (22)** — शरीर गतिविधियाँ, संवेदनाएँ।
4. **दृश्य विधियाँ (18)** — प्रकाश, रंग, आकाश, दृश्य प्रतिमाएँ।
5. **ध्वनि विधियाँ (16)** — मंत्र, नाद, मौन।
6. **भाव और साक्षी (36)** — भावनाएँ, रस, शुद्ध साक्षी भाव।
7. **प्रगतिशील क्रम** — पहले श्वास-शरीर, फिर दृश्य-ध्वनि, अंत में साक्षी।
8. **उपाय का सिद्धांत** — प्रत्येक साधक अपनी प्रकृति अनुसार चुन सकता है।

| **प्राणायाम** | प्राण का विस्तार, न कि श्वास नियंत्रण |
| **मंत्र** | ध्वनि उपकरण, कोई पवित्र शब्द नहीं |
| **दृष्टि** | चेतना से देखना, आँखों से नहीं |

## अध्याय 04: श्वास-प्रज्ञा

`mermaid
flowchart TB
    subgraph Breath["श्वास-प्रज्ञा प्रवाह"]
        direction TB
        A["चरण 1: श्वास देखना"] --> B["चरण 2: श्वास लय"]
        B --> C["चरण 3: श्वास और विचार"]
        C --> D["चरण 4: श्वास और ऊर्जा"]
        D --> E["चरण 5: श्वास और चेतना"]
    end
    A --> A1["बस देखो, कोई बदलाव नहीं"]
    B --> B1["श्वास लेना-छोड़ना-अंतराल"]
    C --> C1["विचार और श्वास का संबंध"]
    D --> D1["प्राण ऊर्जा का अनुभव"]
    E --> E1["श्वास = चेतना, द्वैत का अंत"]
`

### मुख्य बिंदु

1. **श्वास = पुल** — शरीर और मन के बीच का पुल है।
2. **चार श्वास विधियाँ** — देखना, रोकना, लंबाई बदलना, अंतराल में झाँकना।
3. **श्वास और विचार** — जब विचार बदलता है, श्वास बदलती है।
4. **श्वास के चार चरण** — लेना, भीतर रोकना, छोड़ना, बाहर रोकना।
5. **अंतराल में समाधि** — कुंभक वह द्वार है जहाँ से समाधि में प्रवेश होता है।
6. **बिना प्रयास के** — श्वास को बदलना नहीं, बस जागरूकता से देखना।
7. **प्राण और चेतना** — श्वास से प्राण, प्राण से चेतना को समझना।

### संस्कृत शब्दावली

| शब्द | ओशो की परिभाषा |
|------|-----------------|
| **प्राण** | जीवन ऊर्जा, श्वास को संचालित करने वाली ऊर्जा |
| **कुंभक** | श्वास अंतराल, अनंत का द्वार |
| **प्रज्ञा** | जागरूकता, तर्क नहीं प्रत्यक्ष अनुभव |
| **रेचक** | श्वास छोड़ना, तनाव और विचार छोड़ना |

## अध्याय 05: शरीर चेतना

`mermaid
flowchart LR
    subgraph Body["शरीर चेतना का सफर"]
        A["शरीर = मंदिर"] --> B["संवेदना देखो"]
        B --> C["ऊर्जा प्रवाह"]
        C --> D["स्थिरता ध्यान"]
        D --> E["शरीर से परे"]
    end
    A --> A1["शरीर को जानो, दोस्ती करो"]
    B --> B1["गर्मी-सर्दी, स्पर्श-दबाव"]
    C --> C1["प्राण प्रवाह, चक्र ऊर्जा"]
    D --> D1["निश्चल बैठना, शवासन"]
    E --> E1["देहातीत, चेतना विस्तार"]
`

### मुख्य बिंदु

1. **शरीर = मंदिर** — शरीर कोई बाधा नहीं, चेतना का निवास है।
2. **शरीर से दोस्ती** — पहला कदम शरीर से दोस्ती करना है।
3. **संवेदना ध्यान** — एक संवेदना पर ध्यान केंद्रित करना।
4. **निश्चलता की शक्ति** — पूरी तरह स्थिर रखकर ध्यान करना।
5. **शवासन ध्यान** — लेटकर पूरी तरह ढीला छोड़ना।
6. **शरीर से परे** — शरीर की चेतना पूर्ण होने पर शरीर से बाहर।
7. **चक्र जागरण** — ऊर्जा केंद्रों पर ध्यान।

### संस्कृत शब्दावली

| शब्द | ओशो की परिभाषा |
|------|-----------------|
| **देह** | चेतना का रूप, चेतना का निवास |
| **चक्र** | मनो-शारीरिक ऊर्जा केंद्र |
| **शवासन** | पूर्ण समर्पण, कोई प्रयास नहीं |
| **आसन** | पूर्ण सहज और स्थिर स्थिति |

### मुख्य बिंदु

2. **त्राटक विधि** — बिना पलक झपकाए घूरना, आँखों की ऊर्जा भीतर मुड़ती है।
3. **दीपक ध्यान** — मोमबत्ती की लौ देखना, फिर भीतर प्रतिबिंब।
4. **अंधकार ध्यान** — अंधकार को देखना, गहन शांति का द्वार।
5. **आकाश ध्यान** — असीम आकाश में खो जाना।
6. **नीला प्रकाश** — तीसरी आँख जगाने में सहायक।
7. **बिंदु ध्यान** — भौंहों के बीच बिंदु पर ध्यान केंद्रित करना।

## TypeScript: Chapter Revision Card Randomizer

This TypeScript utility generates random revision cards from all 18 chapters for quick review.

`	ypescript
interface RevisionCard {
  chapterNumber: number;
  chapterTitle: string;
  category: 'keyPoint' | 'sanskritTerm';
  content: string;
  detail: string;
}

interface ChapterData {
  number: number;
  title: string;
  keyPoints: { point: string; detail: string }[];
  sanskritTerms: { term: string; definition: string }[];
}

class RevisionCardGenerator {
  private cards: RevisionCard[] = [];
  private drawnCards: RevisionCard[] = [];
  private history: string[] = [];

  constructor() {
    this.initializeCards();
  }

  private initializeCards(): void {
    const chapters: ChapterData[] = [
      {
        number: 1,
        title: 'परिचय: ओशो का दृष्टिकोण',
        keyPoints: [
          { point: 'तंत्र एक प्रयोगात्मक विज्ञान है', detail: 'अंध-विश्वास नहीं, प्रयोग करके देखें' },

        ],

          { term: 'शक्ति', definition: 'ब्रह्मांड की मूल ऊर्जा' },

    this.drawnCards = [];
    this.history = [];

    if (this.cards.length === 0) return null;
    const index = Math.floor(Math.random() * this.cards.length);
    const card = this.cards[index];
    this.drawnCards.push(card);
    this.history.push('[Ch' + card.chapterNumber + '] ' + card.content);
    return card;

    const chapterCards = this.cards.filter(c => c.chapterNumber === chapterNumber);
    if (chapterCards.length === 0) return null;
    const index = Math.floor(Math.random() * chapterCards.length);
    const card = chapterCards[index];
    this.drawnCards.push(card);
    this.history.push('[Ch' + card.chapterNumber + '] ' + card.content);
    return card;
  }

  drawByCategory(category: 'keyPoint' | 'sanskritTerm'): RevisionCard | null {
    const filtered = this.cards.filter(c => c.category === category);
    if (filtered.length === 0) return null;
    const index = Math.floor(Math.random() * filtered.length);
    const card = filtered[index];
    this.drawnCards.push(card);
    return card;
  }

  getTotalCards(): number { return this.cards.length; }
  getDrawnCount(): number { return this.drawnCards.length; }
  getHistory(): string[] { return [...this.history]; }

  getChapterStats(): { chapterNumber: number; chapterTitle: string; cardCount: number }[] {
    const stats = new Map<number, { title: string; count: number }>();
    for (const card of this.cards) {
      if (!stats.has(card.chapterNumber)) {
        stats.set(card.chapterNumber, { title: card.chapterTitle, count: 0 });
      }
      stats.get(card.chapterNumber)!.count++;
    }
    return Array.from(stats.entries()).map(([num, data]) => ({
      chapterNumber: num,
      chapterTitle: data.title,
      cardCount: data.count,
    }));
  }

  getDailySet(): RevisionCard[] {
    const used = new Set<number>();
    const set: RevisionCard[] = [];
    const shuffled = [...this.cards].sort(() => Math.random() - 0.5);
    for (const card of shuffled) {
      if (set.length >= 5) break;
      if (!used.has(card.chapterNumber)) {
        used.add(card.chapterNumber);
        set.push(card);
      }
    }
    return set;
  }
}

export { RevisionCardGenerator, RevisionCard, ChapterData };

## Osho के 7 सुनहरे नियम (7 Golden Rules)

1. **स्वीकार करो** — जीवन को वैसे स्वीकार करो जैसा वह है।
2. **प्रयोग करो** — किसी भी बात को अंध-विश्वास से मत मानो।
3. **साक्षी बनो** — कर्ता मत बनो, द्रष्टा बनो।
4. **निर्णय मत दो** — अनुभव को अच्छा या बुरा मत कहो।
5. **नियमित रहो** — एक बार में बहुत नहीं, बल्कि नियमित करो।
6. **धैर्य रखो** — ध्यान कोई व्यवसाय नहीं, धीरे-धीरे फल देता है।
7. **हँसते रहो** — ध्यान को गंभीर मत बनाओ, इसे आनंद बनाओ।
