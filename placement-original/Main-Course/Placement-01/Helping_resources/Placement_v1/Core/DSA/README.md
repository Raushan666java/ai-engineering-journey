# 🧮 Data Structures & Algorithms

## Learning Path

### [Basics](Basics/) (4 weeks)
**Week 1: Arrays & Strings**
- Array operations, 2D arrays
- String manipulation, pattern matching
- **Problems:** Two Sum, Maximum Subarray, Valid Anagram
- **Target:** 30 problems

**Week 2: Linked Lists**
- Singly, doubly, circular implementation
- Insertion, deletion, reversal, cycle detection
- **Problems:** Reverse List, Merge Lists, Cycle Detection
- **Target:** 25 problems

**Week 3: Stacks & Queues**
- Implementation using arrays/linked lists
- Applications: expression evaluation, BFS
- **Problems:** Valid Parentheses, Next Greater Element
- **Target:** 20 problems

**Week 4: Basic Trees**
- Binary tree traversals (in/pre/post/level order)
- BST operations (search, insert, delete)
- **Problems:** Tree Traversals, Validate BST, LCA
- **Target:** 25 problems

### [Advanced](Advanced/) (5 weeks)
**Week 5: Advanced Trees**
- Heaps (min/max), priority queues
- Tries, segment trees
- **Problems:** Kth Largest, Merge K Lists, Word Search
- **Target:** 30 problems

**Week 6-7: Graphs**
- Representation (adjacency matrix/list)
- Traversals (BFS, DFS), shortest path algorithms
- **Problems:** Clone Graph, Course Schedule, Network Delay
- **Target:** 35 problems

**Week 8-9: Dynamic Programming**
- 1D DP: Fibonacci, climbing stairs, house robber
- 2D DP: LCS, edit distance, knapsack
- **Problems:** Coin Change, LIS, Maximum Product Subarray
- **Target:** 40 problems

### [Practice](Practice/) (Ongoing)
**Daily Routine:**
- 2 Easy problems (if beginner)
- 1 Medium + 1 Easy (if intermediate)
- 1 Hard + 1 Medium (if advanced)

**Problem Categories:**
- Arrays & Strings: 50 problems
- Trees & Graphs: 50 problems
- Dynamic Programming: 40 problems
- Greedy & Backtracking: 30 problems
