## 🔄 Code Patterns Learned

### Pattern 1: Input Validation
```java
while (true) {
    try {
        // Get input
        if (valid) break;
        else System.out.println("Invalid input!");
    } catch (Exception e) {
        System.out.println("Error occurred!");
    }
}
```

### Pattern 2: Menu-Driven Program
```java
do {
    displayMenu();
    choice = getChoice();
    switch (choice) {
        case 1: operation1(); break;
        case 2: operation2(); break;
        // ... more cases
        case 0: System.out.println("Exit"); break;
        default: System.out.println("Invalid!");
    }
} while (choice != 0);
```

### Pattern 3: Multiple Condition Check
```java
if (condition1 && condition2) {
    // Both conditions true
} else if (condition1 || condition2) {
    // At least one true
} else {
    // Neither true
}
```

## 💡 Key Takeaways

### Best Practices Learned
1. **Always validate user input** before processing
2. **Use meaningful variable names** for clarity
3. **Handle edge cases** (division by zero, negative numbers)
4. **Comment complex logic** for future reference
5. **Keep methods small and focused** (single responsibility)
6. **Use constants** for magic numbers
7. **Provide clear error messages** to users

### Common Pitfalls Avoided
1. ❌ Confusing `=` (assignment) with `==` (comparison)
2. ❌ Forgetting `break` in switch cases
3. ❌ Not handling division by zero
4. ❌ Using `==` to compare strings (should use `.equals()`)
5. ❌ Ignoring operator precedence
6. ❌ Writing deeply nested conditions (hard to read)
