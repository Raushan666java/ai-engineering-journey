Q1: Perfunctory means carried out with minimal effort or reflection, i.e., superficial or half-hearted. The opposite would be thorough, but the question asks for the most similar meaning, so superficial is correct.

Q2: Let numbers be x and y. x + y = 26, xy = 144. (x − y)² = (x+y)² − 4xy = 676 − 576 = 100. So x − y = 10.

Q3: When "neither...nor" connects two subjects, the verb agrees with the closer subject. "friends" is plural, so "are" is correct. Option C uses past tense "were" but the present tense context calls for "are coming."

Summary​

Mock Test 7 focuses on discrete mathematics, automata theory, and compiler construction. Key takeaways:

  • Discrete Mathematics: Counting (stars and bars), onto functions (inclusion-exclusion), one-to-one functions, chromatic numbers, and Catalan numbers are essential.
  • Theory of Computation: Recursive enumerability, undecidability (halting problem complement), and closure properties of RE languages require theoretical clarity.
  • Compiler Construction: Grammar derivations, parse trees, left recursion elimination, and FIRST/FOLLOW sets are fundamental for the compiler design syllabus.
  • Data Structures: Heap operations, binary search tree traversals, and graph adjacency representations appear in both 1-mark and 2-mark questions.

Master counting functions with inclusion-exclusion and practice grammar derivations systematically. Catalan numbers are a recurring theme in GATE.

TypeScript Implementations​

The \MockTestSimulator\ class picks random questions from a question bank, tracks timing, and provides real-time feedback.

\\ ypescript /**

  • MockTestSimulator — Picks random questions from a
  • question bank, enforces time limits, and scores responses. */ interface Question { id: number; text: string; subject: string; difficulty: 1 | 2 | 3; marks: number; negativeMark: number; correctAnswer: string; }

interface SimResult { answered: number; correct: number; wrong: number; rawScore: number; timeTaken: number; accuracy: number; }

class MockTestSimulator { private questions: Question[] = []; private selected: Question[] = []; private answers: Map<number, string> = new Map(); private startTime: number = 0; private isRunning: boolean = false;

/** Load question bank. */ loadBank(questions: Question[]): void { this.questions = questions; }

/** Select N random questions, optionally filtered by subject. */ selectRandom(count: number, subject?: string): Question[] { let pool = this.questions; if (subject) pool = pool.filter((q) => q.subject === subject); this.selected = []; const shuffled = [...pool].sort(() => Math.random() - 0.5); for (let i = 0; i < Math.min(count, shuffled.length); i++) { this.selected.push(shuffled[i]); } return this.selected; }

/** Start the mock test timer. */ start(): void { this.startTime = Date.now(); this.isRunning = true; this.answers.clear(); }

/** Submit an answer for a question. */ answerQuestion(qId: number, answer: string): void { if (!this.isRunning) throw new Error('Test not started'); this.answers.set(qId, answer); }

/** End the test and compute results. */ endTest(): SimResult { if (!this.isRunning) throw new Error('Test not started'); const timeTaken = Math.round((Date.now() - this.startTime) / 1000); this.isRunning = false;

let correct = 0, wrong = 0;
for (const q of this.selected) {
  const ans = this.answers.get(q.id);
  if (!ans) continue; // unattempted
  if (ans === q.correctAnswer) correct++;
  else wrong++;
}

let rawScore = 0;
for (const q of this.selected) {
  const ans = this.answers.get(q.id);
  if (ans === q.correctAnswer) rawScore += q.marks;
  else if (ans !== undefined) rawScore -= q.negativeMark;
}

return {
  answered: this.answers.size,
  correct,
  wrong,
  rawScore: Math.round(rawScore * 100) / 100,
  timeTaken,
  accuracy: this.answers.size > 0
    ? Math.round((correct / this.answers.size) * 10000) / 100
    : 0,
};

}

/** Generate a performance summary. */ summary(result: SimResult): string { return [ \Questions: \ | Answered: \, \Correct: \ | Wrong: \, \Raw Score: \, \Accuracy: %, \Time: \m \s, ].join(' | '); } }

// Example usage const sim = new MockTestSimulator(); sim.loadBank([ { id: 1, text: 'P ? Q = ?', subject: 'Math', difficulty: 1, marks: 1, negativeMark: 0.25, correctAnswer: '¬P ? Q' }, { id: 2, text: 'Which is a DCFL?', subject: 'TOC', difficulty: 2, marks: 2, negativeMark: 0.66, correctAnswer: 'L = {anbn}' }, ]); sim.selectRandom(2); sim.start(); sim.answerQuestion(1, '¬P ? Q'); const res = sim.endTest(); console.log(sim.summary(res)); \\

Exercises​

  1. Timed Mock Test: Use \MockTestSimulator\ to select 10 random questions from a bank of 50. Start the timer, answer 8 questions, and compute the result summary. Ensure the simulation enforces a 10-minute time limit.

  2. Subject-Filtered Test: Select 5 questions each from 4 subjects (20 total) and run a timed simulation. Generate a per-subject accuracy breakdown.

  3. Time Limit Enforcer: Add a time limit feature to \MockTestSimulator\ that auto-submits unanswered questions when time expires. Test with a 5-minute limit.

  4. Difficulty Analyzer: After running 3 simulations, analyze accuracy per difficulty level (1, 2, 3). Determine if harder questions (level 3) have disproportionately lower accuracy.

  5. Simulation Benchmarking: Run 100 simulations of 10 random questions each. Compute average raw score, average accuracy, and the standard deviation across simulations to measure expected performance variance.
