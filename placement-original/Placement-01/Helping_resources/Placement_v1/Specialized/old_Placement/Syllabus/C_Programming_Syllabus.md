# C Programming Syllabus

## Detailed Breakdown

### 0. Basic Programming Skills

#### A. Operators

- Arithmetic operators: +, -, \*, /, %
- Relational operators: ==, !=, >, <, >=, <=
- Logical operators: &&, ||, !
- Assignment operators: =, +=, -=, \*=, /=
- Increment/decrement: ++, --
- Conditional (ternary) operator: ? :

#### B. Control Flow Statements

- if, if-else, else-if ladder
- switch-case
- goto statement (usage and pitfalls)

#### C. Loops

- for loop: syntax, use cases
- while loop: syntax, use cases
- do-while loop: syntax, use cases
- Nested loops
- Loop control: break, continue

### 1. Pointers

- Declaration and initialization
- Pointer arithmetic (increment, decrement, difference)
- Pointers to arrays, functions, structures
- NULL pointers, wild pointers
- Double pointers, pointer to pointer
- Passing pointers to functions
- Common pointer errors and debugging

### 2. Memory Management

- Dynamic memory allocation: malloc, calloc, realloc
- Freeing memory: free
- Memory leaks: detection and prevention
- Dangling pointers
- Use of memory management functions in real programs

### 3. Functions

- Declaration, definition, prototypes
- Recursion: base case, recursive case, stack usage
- Passing by value vs passing by reference (using pointers)
- Inline functions (C99)
- Scope and lifetime of variables

### 4. Structures and Unions

- Defining and using structures
- Nested structures
- Bit fields in structures
- Unions: memory sharing, use cases
- Array of structures
- Pointers to structures
- Structure padding and alignment

### 5. File Handling

- File operations: fopen, fclose, fread, fwrite, fprintf, fscanf
- File pointers and modes (r, w, a, rb, wb, ab)
- Error handling in file operations
- Reading/writing binary vs text files
- File positioning: fseek, ftell, rewind

### 6. Bitwise Operators

- AND, OR, XOR, NOT
- Left/right shift operators
- Bit masking, setting/clearing/toggling bits
- Applications: flags, permissions, compression

### 7. Compilation Process

- Preprocessing: macros, #include, #define, conditional compilation
- Compilation: syntax checking, object file generation
- Linking: static vs dynamic linking
- Executable generation
- Makefiles and build automation

### 8. Error Handling and Debugging

- Common runtime errors: segmentation fault, buffer overflow
- Debugging tools: gdb, valgrind
- Setting breakpoints, watchpoints
- Memory analysis and profiling

### 9. Best Practices

- Code organization: header/source files, modularity
- Use of comments and documentation
- Defensive programming: input validation, error checking
- Naming conventions
- Writing portable and maintainable code
