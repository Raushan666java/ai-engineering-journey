# 13. Advanced PHP

- File inclusion: `include`, `require`.
- Regular expressions: `preg_match()`, `preg_replace()`.
- Date/time: `date()`, `strtotime()`.
- Sending emails: `mail()`.
- JSON: `json_encode()`, `json_decode()`.
- cURL: `curl_init()`, `curl_exec()`.

## Example
```php
$date = date('Y-m-d H:i:s');
echo $date;
```

## Best Learning Methods
- Practice with file inclusion, regex, and APIs.
- Reference: https://www.php.net/manual/en/refs.basic.text.php
