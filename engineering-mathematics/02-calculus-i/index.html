2.3 Applications of Derivatives​

Critical Points: ccc is a critical point if f′(c)=0f'(c) = 0f′(c)=0 or f′(c)f'(c)f′(c) does not exist.

First Derivative Test:

  • If f′f'f′ changes from +++ to −-− at ccc, then f(c)f(c)f(c) is a local maximum
  • If f′f'f′ changes from −-− to +++ at ccc, then f(c)f(c)f(c) is a local minimum
