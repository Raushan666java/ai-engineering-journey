# ⏰ Module 4: Time Management

## Core Techniques

### 1. Pomodoro Technique
**Structure:**
- 25 minutes focused work
- 5 minutes break
- Repeat 4 cycles
- 15-30 minutes long break

**Benefits:** Maintains focus, prevents burnout

### 2. Time Blocking
**Method:**
- Assign specific times to activities
- Include buffer time
- Batch similar tasks
- Protect deep work blocks

### 3. Eisenhower Matrix
**Quadrants:**
- **Urgent + Important:** Do first
- **Important + Not Urgent:** Schedule
- **Urgent + Not Important:** Delegate
- **Neither:** Eliminate

### 4. Getting Things Done (GTD)
**Steps:**
1. **Capture:** Write everything down
2. **Clarify:** What does it mean?
3. **Organize:** Put in right place
4. **Reflect:** Review regularly
5. **Engage:** Take action

## Productivity Systems

### For Deep Work
- **Environment:** Quiet, distraction-free
- **Duration:** 2-4 hour blocks
- **Focus:** Single complex task
- **Recovery:** Adequate breaks

### For Learning
- **Interleaving:** Mix different subjects
- **Spacing:** Distribute practice over time
- **Testing:** Regular self-assessment
- **Reflection:** Connect new to existing knowledge
