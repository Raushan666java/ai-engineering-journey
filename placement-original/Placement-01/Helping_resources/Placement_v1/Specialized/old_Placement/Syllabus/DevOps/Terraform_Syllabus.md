# Terraform for DevOps Syllabus

- Introduction to Infrastructure as Code (IaC)
- Terraform installation and setup
- Providers: AWS, Azure, GCP, others
- Resources: definition, configuration
- Variables, outputs, data sources
- State management: local, remote, locking
- Modules: reusable infrastructure components
- Workspaces: environment management
- Provisioners: executing scripts
- Lifecycle rules: create_before_destroy, prevent_destroy
- Dependency management
- Remote backends: S3, Azure Blob, Google Cloud Storage
- Security: secrets management, sensitive variables
- Integrating Terraform with CI/CD pipelines
- Best practices: code organization, versioning, documentation
- Real-world scenarios: multi-cloud deployments, DR, scaling
