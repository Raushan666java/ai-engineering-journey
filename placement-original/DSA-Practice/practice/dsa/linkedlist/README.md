# 🔗 Linked List Problems

### Easy Level
- [ ] `Easy_LL_ReverseList.java` - Reverse a linked list
- [ ] `Easy_LL_MiddleElement.java` - Find middle of linked list
- [ ] `Easy_LL_DetectCycle.java` - Detect cycle in linked list
- [ ] `Easy_LL_MergeSorted.java` - Merge two sorted lists
- [ ] `Easy_LL_RemoveDuplicates.java` - Remove duplicates from sorted list
- [ ] `Easy_LL_PalindromeList.java` - Check if linked list is palindrome
- [ ] `Easy_LL_IntersectionPoint.java` - Find intersection point
- [ ] `Easy_LL_DeleteNode.java` - Delete a node (given node only)
- [ ] `Easy_LL_NthFromEnd.java` - Find nth node from end

### Hard Level
- [ ] `Hard_LL_MergeKLists.java` - Merge k sorted linked lists
- [ ] `Hard_LL_ReverseNodesInKGroup.java` - Reverse nodes in k-group

## Common Patterns
- **Fast & Slow Pointers:** Cycle Detection, Middle Element
- **Two Pointers:** Merge Lists, Intersection Point
- **Recursion:** Reverse List, Palindrome Check
- **Dummy Node:** Merge, Partition, Sort
