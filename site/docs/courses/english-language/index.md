> **Exam Weightage:** 25 Questions in IBPS SO Prelims, 25 Qs in SBI/SO, Descriptive in Mains
>
> **Difficulty:** Moderate (Class 10-12 English level)
>
> **Focus Areas:** Reading Comprehension, Grammar, Vocabulary, Verbal Ability

## 🎯 Strategy

1. **Daily reading** — The Hindu editorial, one RC passage daily
2. **Vocabulary** — 20 new words/day with usage in sentences
3. **Grammar drills** — Spotting errors, fillers, sentence improvement
4. **Mock test analysis** — Review every incorrect answer
