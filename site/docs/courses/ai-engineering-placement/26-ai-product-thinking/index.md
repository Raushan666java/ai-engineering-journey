# 26 — AI Product Thinking

## Overview

Bridge the gap between AI engineering and product strategy. Learn how to identify AI opportunities, design user-centric AI experiences, run experiments, define KPIs, and build product roadmaps that deliver real business value.

## Learning Path

1. Read sub-chapters in order
2. For each: read theory → run code → review Q&A → take quiz → do exercises
3. Mark complete when all sub-chapters done
