# 📚 Module 3: Study Methods

## Active Learning Techniques

### 1. Feynman Technique
**Steps:**
1. Choose concept
2. Explain in simple terms
3. Identify gaps
4. Review and simplify

**Practice:** Teach concepts to others

### 2. SQ3R Method
- **Survey:** Skim material
- **Question:** Create questions
- **Read:** Active reading
- **Recite:** Summarize aloud
- **Review:** Test understanding

### 3. Cornell Note-Taking
**Format:**
```
Notes Section    | Cue Section
-----------------|------------
Main content     | Keywords
Details          | Questions
Examples         | Summary
```

### 4. Mind Mapping
**Structure:**
- Central topic in middle
- Main branches for subtopics
- Sub-branches for details
- Use colors and images

## Study Session Structure

### Before Studying
- [ ] Set specific goals
- [ ] Remove distractions
- [ ] Prepare materials
- [ ] Set timer

### During Study
- [ ] Use active techniques
- [ ] Take regular breaks
- [ ] Switch between topics
- [ ] Test understanding

### After Study
- [ ] Review what learned
- [ ] Plan next session
- [ ] Update progress
- [ ] Reflect on effectiveness

## Problem-Solving Approach
1. **Understand:** Read problem carefully
2. **Plan:** Choose strategy
3. **Execute:** Implement solution
4. **Review:** Check and optimize
