06 — Docker, Kubernetes & Cloud

Overview​

Master containerization with Docker, orchestration with Kubernetes, and cloud deployment on AWS, Azure, and GCP. Covers CI/CD pipelines and best practices for deploying scalable AI services.

Learning Path​

  1. Read sub-chapters in order
  2. For each: read theory → run code → review Q&A → take quiz → do exercises
  3. Mark complete when all sub-chapters done

Prerequisites​

FastAPI & Backend Engineering. Basic Linux command knowledge is expected.
