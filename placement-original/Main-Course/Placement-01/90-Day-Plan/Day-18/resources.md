## 🔍 Tips
- Start with memoization; if you can convert to bottom-up, do so for performance
- Verify base cases and initialization
- Use rolling arrays (1D) to reduce memory when possible
- Explain state & transitions clearly in interviews

**Practice Tip:** Try to do at least 10 DP problems each week to build pattern recognition.
