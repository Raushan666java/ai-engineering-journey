# DBMS Syllabus for Placement

## 1. Introduction to DBMS
- Database concepts and architecture
- Data models (Hierarchical, Network, Relational, Object-oriented)
- Three-schema architecture
- Data independence (Logical, Physical)
- Database languages (DDL, DML, DCL, TCL)

## 2. Entity-Relationship Model
- ER diagrams
- Entity, Attributes, Relationships
- Constraints (Key, Domain, Referential integrity)
- Generalization, Specialization, Aggregation
- Converting ER diagrams to tables

## 3. Relational Model
- Relational data structure
- Relational algebra operations
- Tuple relational calculus
- Domain relational calculus
- SQL basics and advanced concepts

## 4. Normalization
- Functional dependencies
- Normal forms (1NF, 2NF, 3NF)
- BCNF (Boyce-Codd Normal Form)
- 4NF, 5NF
- Denormalization

## 5. Transaction Management
- ACID properties
- Transaction states
- Concurrency control
- Serializability
- Deadlock handling

## 6. Concurrency Control
- Lock-based protocols
- Timestamp-based protocols
- Validation-based protocols
- Multiple granularity
- Multiversion schemes

## 7. Recovery System
- Failure classification
- Storage structure
- Recovery and atomicity
- Log-based recovery
- Shadow paging

## 8. File Organization & Indexing
- File organization techniques
- Indexing methods
- B and B+ trees
- Hash-based indexing
- Bitmap indices

## 9. Query Processing & Optimization
- Query processing steps
- Query optimization techniques
- Join strategies
- Cost estimation
- Heuristic optimization

## 10. Advanced Topics
- Distributed databases
- Object-oriented databases
- NoSQL databases
- Data warehousing
- Big data and analytics

## Weekly Study Plan
- Week 1: Introduction & ER Model
- Week 2: Relational Model & SQL
- Week 3: Normalization
- Week 4: Transaction Management & Concurrency
- Week 5: Recovery, File Organization & Indexing
- Week 6: Query Processing & Advanced Topics
