# JavaScript Interview Questions & Revision Notes

## Revision Notes
- JavaScript is a high-level, interpreted scripting language for web development.
- Supports functional, object-oriented, and event-driven programming.
- Key concepts: variables, data types, functions, scope, closures, prototypes, async programming.
- ES6+ features: let/const, arrow functions, classes, template literals, destructuring, promises, async/await.
- DOM manipulation, event handling, and AJAX are core browser-side uses.
- Best practices: use strict mode, modular code, avoid global variables, handle errors gracefully.
