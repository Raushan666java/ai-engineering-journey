# 17. Practice and Projects

## Mini-project ideas

- Todo CRUD app with authentication and tests
- REST API for notes with pagination and filters
- Image gallery with upload, resize, and CDN integration
- Payment demo using Stripe sandbox

## Project template

- `README.md` (goal, setup)
- `composer.json` and `.env.example`
- `src/` or `app/` with clear structure
- Tests with PHPUnit or Pest
- CI pipeline (GitHub Actions) to run tests and linting

## Testing

- Unit tests for services and helpers
- Feature tests for controllers and endpoints
- Use factories and seeders for test data

## Deployment

- Dockerize application
- Set up CI/CD to run tests and deploy to staging
- Use migrations and backups for DB

---

**Practice:** Complete one mini-project end-to-end, add tests, and write a public blog post describing the architecture and lessons learned.
