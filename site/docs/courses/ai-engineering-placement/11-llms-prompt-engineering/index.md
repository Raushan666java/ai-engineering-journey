# 11 — LLMs & Prompt Engineering

## Overview

Learn to effectively use large language models through prompt engineering, structured output, context management, and cost optimization. Covers zero-shot, few-shot, chain-of-thought, and LLM evaluation.

| 08 | [Cost & Latency Optimization](08-cost-and-latency-optimization.md) | caching, batching, model routing, prompt compression | 10 |

1. Read sub-chapters in order
2. For each: read theory → run code → review Q&A → take quiz → do exercises
3. Mark complete when all sub-chapters done
