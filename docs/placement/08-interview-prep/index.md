From `Placement/Placement-01/08-Interview-Prep/Interview-Complete.md`:

```
2. EXPLORE — Manual examples, patterns
3. BRAINSTORM — Brute force → optimize (time/space)
4. IMPLEMENT — Clean code, meaningful names
5. TEST — Edge cases, complexity analysis
```

## Behavioral Interviews

### STAR Method

```
S — Situation: Context kya tha
T — Task: Tera role/responsibility
A — Action: Tune kya kiya
R — Result: Kya outcome aaya
```

### Common Questions

From `Placement/Placement-01/08-Interview-Prep/Interview-Complete.md`:

1. Tell me about yourself (30 sec pitch tayar rakho)
2. Biggest challenge faced (STAR se batao)
3. Team conflict kaise handle kiya
4. Why do you want to join our company
5. Where do you see yourself in 5 years

### Leadership Stories

Prepare 3-4 stories:
- **Technical challenge**: Production bug you fixed
- **Leadership**: Mentored someone / led a project
- **Failure**: Something that went wrong, lessons learned
- **Impact**: Project that made business impact
