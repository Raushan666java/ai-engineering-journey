Computer Networks — Complete Course Textbook

Course Code: CN-401
Level: Undergraduate / Graduate
Prerequisites: Basic operating systems, data structures, discrete mathematics

Course Description​

This course provides a comprehensive study of computer networking from the physical layer through the application layer. Students examine protocol architectures, network algorithms, performance analysis, and the engineering principles that govern modern network infrastructure. The course balances theoretical foundations with practical implementation through socket programming, packet analysis, and network configuration exercises.

Learning Outcomes​

Upon completion, students will be able to:

  1. Explain the layered architecture of computer networks and the function of each layer in the OSI and TCP/IP reference models.
  2. Analyze the principles of data transmission, multiplexing, and switching at the physical and data link layers.
  3. Design and evaluate medium access control protocols for shared and switched networks.
  4. Configure IP addressing schemes using subnetting, CIDR, and NAT.
  5. Compare and contrast routing algorithms including distance vector, link state, and path vector protocols.
  6. Explain TCP connection management, flow control, and congestion control mechanisms.
  7. Develop network applications using the socket API in C and Python.
  8. Analyze network traffic using packet capture and diagnostic tools.
  9. Describe the fundamental principles of network security including encryption, authentication, and firewall architectures.
  10. Evaluate modern networking paradigms including SDN, cloud networking, and emerging transport protocols.
