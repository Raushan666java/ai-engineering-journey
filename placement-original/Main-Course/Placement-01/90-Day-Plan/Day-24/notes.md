# Day 24 Notes: Graphs Part 2

## Concepts Covered
- Edmonds-Karp algorithm (BFS-based max flow)
- Dinic algorithm (optional improvement for faster performance)
- Tarjan's low-link algorithm for bridges and articulation points
- Lowest Common Ancestor (LCA) via Binary Lifting

## Common Pitfalls
- Flow implementations need careful residual edge updates; avoid integer overflow in capacities
- Tarjan's recursion needs visited/time arrays carefully to avoid infinite loops
- LCA requires precomputation up to log2(N) levels; match sizes and array offsets
