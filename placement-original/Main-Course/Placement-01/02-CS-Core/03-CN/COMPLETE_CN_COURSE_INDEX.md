## 🗂️ Complete Course Structure

### **Module 1: Network Fundamentals (Week 1)**
- Introduction to Computer Networks
- Network Types (LAN, WAN, MAN, PAN)
- Network Topologies
- Network Components
- **Practice**: 50 Questions + 3 Labs

### **Module 2: Physical Layer (Week 2)**
- Transmission Media
- Signal Encoding
- Multiplexing Techniques
- Error Detection Methods
- **Practice**: 60 Questions + 4 Labs

### **Module 3: Data Link Layer (Week 3-4)**
- Framing Techniques
- Error Detection & Correction
- Flow Control Protocols
- MAC Protocols
- Ethernet & WiFi
- **Practice**: 80 Questions + 5 Labs

### **Module 4: Network Layer (Week 5-6)**
- IP Addressing & Subnetting
- Routing Algorithms
- Internet Protocol (IPv4/IPv6)
- ICMP, ARP, DHCP
- **Practice**: 100 Questions + 6 Labs

### **Module 5: Transport Layer (Week 7)**
- TCP vs UDP
- Port Numbers
- Connection Management
- Flow & Congestion Control
- **Practice**: 70 Questions + 4 Labs

### **Module 6: Application Layer (Week 8)**
- HTTP/HTTPS, FTP, SMTP
- DNS, DHCP
- Web Technologies
- Socket Programming
- **Practice**: 80 Questions + 3 Labs

### **Module 7: Network Security (Week 9)**
- Cryptography Basics
- SSL/TLS, VPN
- Firewalls, IDS/IPS
- Network Attacks & Defense
- **Practice**: 60 Questions + 2 Labs
