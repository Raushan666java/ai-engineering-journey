# Day 51 System Design: Assessment Reporting & Analytics

## Overview
Design a reporting system to analyze assessment results across candidates and time.

## Components
- Ingestion: Collect assessment submissions and results
- Aggregation: Compute candidate-wise and problem-wise metrics
- Storage: Time-series DB for performance over time and relational DB for metadata
- Dashboard: Visualize grade distributions, weak topics, and trends

## Metrics
- Average score per topic
- Time per problem statistics
- Pass rate and grade distribution
- Correlation between practice hours and assessment performance

## Follow-ups
- Auto-generate study plan based on weak topics
- Recommend problems for focused practice
- Notify mentors with candidate progress reports
