- **Email Phishing:** Malicious emails requesting sensitive information
- **Spear Phishing:** Targeted attacks using personal information
- **Whaling:** High-level executive targeted phishing
- **Vishing:** Voice-based phishing attacks
- **Smishing:** SMS-based phishing attacks
- **Pharming:** DNS-based phishing attacks
