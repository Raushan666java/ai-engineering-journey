# 🚀 Computer Networks Course - Quick Start Guide

## ⚡ 5-Minute Setup

### Step 1: Install Required Software
```bash
# Cisco Packet Tracer (Network Simulation)
Download: https://www.netacad.com/courses/packet-tracer

# Wireshark (Protocol Analysis)
Download: https://www.wireshark.org/download.html

# GNS3 (Advanced Simulation) - Optional
Download: https://www.gns3.com/software/download
```

### Step 2: Verify Network Tools
```cmd
# Windows - Test basic commands
ping 8.8.8.8
ipconfig /all
tracert google.com

# Check if tools work
wireshark --version
```

### Step 3: Create First Network
**Packet Tracer Lab:**
1. Add 2 PCs and 1 Switch
2. Connect with straight-through cables
3. Configure IP addresses:
   - PC1: 192.168.1.10/24
   - PC2: 192.168.1.20/24
4. Test with ping command

## 🛠️ Essential Tools Setup

### Packet Tracer Basics
```
1. Create new project
2. Add devices from device panel
3. Use connection tools to cable devices
4. Configure devices via CLI or GUI
5. Use simulation mode to see packet flow
```

### Wireshark Basics
```
1. Select network interface
2. Start packet capture
3. Apply display filters
4. Analyze protocol details
5. Save capture files for analysis
```

### Command Line Tools
```cmd
# Essential Windows commands
ping, tracert, ipconfig, netstat, nslookup, arp

# Essential Linux commands  
ping, traceroute, ifconfig, netstat, dig, arp
```
