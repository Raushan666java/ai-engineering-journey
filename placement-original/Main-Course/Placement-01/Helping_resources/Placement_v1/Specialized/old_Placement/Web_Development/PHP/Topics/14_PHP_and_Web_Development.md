# 14. PHP and Web Development

- Embed PHP in HTML using `<?php ... ?>`.
- Separate logic and presentation.
- MVC basics: Model, View, Controller.
- Composer for dependency management: `composer.json`.

## Example
```php
// index.php
<html>
<body>
<?php echo "Hello, World!"; ?>
</body>
</html>
```

## Best Learning Methods
- Build simple web apps with PHP and HTML.
