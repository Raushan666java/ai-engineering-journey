# Arrays - Theory & Patterns

Arrays are the foundation of DSA. Mastering array problems builds the base for all advanced topics.

## Key Patterns
- Two Pointers
- Sliding Window
- Prefix Sum
- Sorting & Partitioning
- Hashing

## Common Approaches
- Brute Force: Try all possibilities
- Optimal: Use extra space, two pointers, or mathematical properties

## When to Use Arrays
- When you need fast random access (O(1))
- When order matters
- When you need to process elements in sequence

## Example Problems
- Reverse an array
- Find the maximum subarray sum (Kadane's Algorithm)
- Sort 0s, 1s, and 2s (Dutch National Flag)
- Find missing/duplicate elements

## Tips
- Always check for out-of-bounds
- Use extra space only if needed
- Practice edge cases: empty, single element, all same, sorted, reverse sorted
