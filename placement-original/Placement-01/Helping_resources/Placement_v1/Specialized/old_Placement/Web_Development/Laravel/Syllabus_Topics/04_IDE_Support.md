# 4. IDE Support

## Recommended IDEs and Editors

### Visual Studio Code
- Free, open-source code editor by Microsoft
- Lightweight yet powerful
- Extensive extension ecosystem
- Cross-platform (Windows, macOS, Linux)
- Integrated terminal and Git support

### PhpStorm
- Premium IDE by JetBrains specifically for PHP development
- Built-in Laravel support
- Advanced code completion and navigation
- Database tools and REST client
- Refactoring tools and code quality analysis

### Cursor
- AI-powered code editor
- Built on VS Code foundation
- Intelligent code suggestions
- Integrated AI assistance

### Sublime Text
- Fast, lightweight text editor
- Highly customizable
- Package ecosystem for Laravel support

## Essential Extensions and Plugins

### VS Code Extensions
- **Laravel Extension Pack**
  - Blade syntax highlighting
  - Laravel snippets
  - Laravel Artisan commands
  - Laravel Intellisense
- **PHP Intelephense**
  - Advanced PHP code intelligence
  - Code navigation and completion
- **Laravel Blade Snippets**
  - Blade template snippets
  - Syntax highlighting
- **Laravel Blade Formatter**
  - Format Blade templates
- **PHP Debug**
  - Xdebug integration

### PhpStorm Plugins
- **Laravel Idea**
  - Enhanced Laravel support
  - Route, config, and view navigation
  - Blade template support
  - Artisan command integration
- **Laravel Plugin**
  - Official Laravel plugin
  - Basic Laravel support
- **PHP Annotations**
  - DocBlock support
- **Symfony Support**
  - Support for Symfony components used in Laravel

## IDE Configuration

### PHP Language Server
- Configure PHP Intelephense or PHP Language Server
- Set up include paths for better code navigation
- Configure composer autoload for proper class resolution

### Debugging Setup
- Xdebug configuration
- Launch configurations for debugging
- Browser debugging extensions

### Code Style and Formatting
- PSR-12 code style configuration
- EditorConfig setup
- Prettier/PHP CS Fixer integration

## Productivity Features

### Code Navigation
- Go to definition
- Find all references
- Navigate between controllers, models, and views
- Jump to routes and configurations

### Autocompletion
- Class and method autocompletion
- Blade directive completion
- Route and config key completion
- DocBlock generation

### Refactoring Tools
- Rename symbols across files
- Extract methods and variables
- Move classes between namespaces

### Integrated Terminal
- Run Artisan commands
- Manage npm/composer dependencies
- Git operations

## Cloud-based Development

### GitHub Codespaces
- Cloud-based development environment
- Pre-configured Laravel setup
- VS Code in browser

### GitPod
- Browser-based development environment
- Automated setup from repository

### Firebase Studio
- Cloud-based IDE
- Collaborative development
- Integrated deployment

## Best Learning Methods
- Install and configure Laravel extensions/plugins
- Learn keyboard shortcuts for common operations
- Set up proper debugging environment
- Practice code navigation between related files
- Use integrated terminal for Artisan commands
- Configure code snippets for repetitive code patterns
