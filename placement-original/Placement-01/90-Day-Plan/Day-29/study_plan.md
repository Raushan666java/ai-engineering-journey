# Day 29 Study Plan

## Overview
This is the study plan for Day 29 of your 90-day placement preparation journey.

## Daily Schedule (9 hours total)

### Morning Session (3 hours)
- **Topic**: Mock Interview & Algorithm Practice
- **Activities**:
  - Read problem patterns & solve 3 medium coding questions focused on arrays, linked lists and intervals
  - Write tests and code for each solution
  - Review time/space complexity and common pitfalls

### Afternoon Session (3 hours)
- **Topic**: Coding Patterns & Mock Interview
- **Activities**:
  - Behavioral mock interview (role-play), practice explaining solutions and trade-offs
  - Implement a timed mock interview using the `Day29MockTest` harness
  - Review mistakes and optimize solutions

### Evening Session (3 hours)
- **Topic**: Review & Deep Dives
- **Activities**:
  - Revisit any failed cases and write extra tests
  - Pair review of solutions or code walkthrough
  - Log takeaways and next steps for improvement

## Learning Objectives
- Strengthen confidence with common interview patterns (two pointers, sliding window, sorting intervals)
- Practice explaining solutions verbally and writing tests
- Improve time management for live coding interviews

## Resources Required
- Problem lists (LeetCode/LC), example solutions, a timer, a mock interviewer (or recording tool)
- Local harness to test deterministic CI mode (Day29MockTest.java)

## Expected Outcomes
- Completed 3 problems in the day across data structure topics
- Recorded answers and recognized optimization opportunities
- CI pass of all mock test functions and consistent implementation

## Notes
- Remember to take regular breaks
- Stay hydrated and maintain good posture
- Review previous day's work for 15 minutes
