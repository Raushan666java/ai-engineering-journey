# 16. PHP Frameworks (Overview)

- Frameworks provide structure, rapid development, and security for PHP projects.
- Popular frameworks:
  - **Laravel:** MVC, Eloquent ORM, Blade templates, routing, authentication.
  - **CodeIgniter:** Lightweight, easy setup, good for small apps.
  - **Symfony:** Reusable components, scalable, enterprise-level.
- Why use frameworks: code organization, built-in security, faster development, community support.

## Best Learning Methods
- Explore official documentation and tutorials for each framework.
- Build a simple CRUD app in Laravel or CodeIgniter.
- Reference: https://laravel.com/, https://codeigniter.com/, https://symfony.com/
