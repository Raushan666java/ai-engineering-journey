# Day 33 Study Plan

## Overview
This is the study plan for Day 33 of your 90-day placement preparation journey — Topic: Heaps & Priority Queues.

## Daily Schedule (9 hours total)

### Morning Session (3 hours)
- **Topic**: Heaps & PriorityQueue basics
- **Activities**:
  - Understand Java's PriorityQueue implementation and Comparator usage
  - Implement heap-based solutions: heap sort, top-K elements
  - Write tests and reason about time/space complexity

### Afternoon Session (3 hours)
- **Topic**: Heap algorithms & applications
- **Activities**:
  - Merge k sorted arrays using heap
  - Sliding window top K (optional), median maintenance (two-heaps)
  - Compare against other algorithmic approaches (sorting, selection algorithms)

### Evening Session (3 hours)
- **Topic**: Practice & optimizations
- **Activities**:
  - Solve 3 heap problems (LeetCode) and ensure deterministic check harness
  - Expand `HeapsBasics` demos and add case tests
  - Document learnings & common issues

## Learning Objectives
- Understand Java PriorityQueue, max vs min heaps using comparators
- Implement heap algorithms: heap sort, top-K, merge k sorted arrays
- Reason about algorithmic complexities and apply for practical problems

## Resources Required
- Java PriorityQueue docs
- LeetCode topic sections: Heap / priority queue problems

## Expected Outcomes
- Correct heap usage in Java, with deterministic CI checks
- Working implementation for top-K and merge-k problems
- A test harness and run script
