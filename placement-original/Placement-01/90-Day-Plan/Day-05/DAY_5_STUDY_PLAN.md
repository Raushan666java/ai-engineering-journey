## 💡 STUDY TIPS

1. **Active Learning:**
   - Don't just read - type every example
   - Run code and observe output
   - Modify examples to test understanding

2. **Draw Diagrams:**
   - Draw call stack for recursion
   - Visualize method calls
   - Trace execution step-by-step

3. **Practice First Principles:**
   - Try solving before looking at solution
   - If stuck, check hints only
   - Implement solution from scratch

4. **Track Progress:**
   - Use checkbox lists above
   - Note difficult concepts
   - Review mistakes

5. **Take Breaks:**
   - 5-10 min break every hour
   - Stretch and hydrate
   - Review notes during breaks
