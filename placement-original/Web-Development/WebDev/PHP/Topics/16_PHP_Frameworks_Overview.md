# 16. PHP Frameworks Overview

## Laravel (Most popular)

- Expressive syntax, Eloquent ORM, Blade templating
- Starter: `composer create-project laravel/laravel my-app`
- Strengths: Ecosystem (Horizon, Sanctum, Passport), great docs, rapid development

## Symfony

- Component-based, robust for large applications
- Strengths: Flexibility, mature architecture, used in enterprise

## CodeIgniter

- Lightweight and simple to learn
- Strengths: Small footprint, easy hosting requirements

## Yii / Zend / Phalcon

- Each has different trade-offs (performance, architecture)

## When to choose a framework

- Laravel: fast development and full-featured apps
- Symfony: complex, long-lived enterprise apps
- CodeIgniter: simple dashboards or legacy support

---

**Practice:** Scaffold a small project in Laravel and Symfony to compare dev experience.
