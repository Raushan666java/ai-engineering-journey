# Searching - Complete Guide

## Overview
Searching algorithms are fundamental techniques for finding elements in data structures. They vary in efficiency, applicability, and use cases depending on the data structure and search requirements.

## Key Concepts

### Search Algorithm Types
- **Linear Search**: Sequential search through elements
- **Binary Search**: Divide and conquer on sorted data
- **Interpolation Search**: Improved binary search with estimation
- **Exponential Search**: Find range then binary search

### Time Complexity
- **Linear Search**: O(n)
- **Binary Search**: O(log n)
- **Interpolation Search**: O(log log n) average
- **Exponential Search**: O(log n)

## Common Patterns
1. **Binary Search on Answer**: Search for optimal value
2. **Two Pointer Technique**: Search with two moving pointers
3. **Sliding Window**: Search within moving windows
4. **DFS/BFS**: Graph/tree searching algorithms

## Interview Tips
- Understand when to use each search algorithm
- Know binary search variants and edge cases
- Practice search on different data structures
- Consider time/space trade-offs
- Handle boundary conditions carefully
