## 🚀 Quick Start Guide

### 1. Environment Setup

```bash
# Clone repository
git clone <repo-url>
cd AI-ML-Course

# Create virtual environment
python -m venv ml_env

# Activate (Windows)
ml_env\Scripts\activate

# Activate (Linux/Mac)
source ml_env/bin/activate

# Install dependencies
pip install -r Tools-Setup/requirements.txt
```

### 2. Choose Your Track

**Option A: 20-Week Part-Time**
- 2-3 hours/day
- Best for working professionals
- Complete all materials

**Option B: 90-Day Intensive**
- 4-6 hours/day
- Best for students/career switchers
- Fast-track to placement

**Option C: Self-Paced**
- Your schedule
- Flexible learning
- Complete at your pace

### 3. Start Learning

1. Go to `Phase-1-Foundations/Week-01-Python-Basics/`
2. Read `README.md`
3. Follow lectures in order
4. Complete labs & assignments
5. Build weekly projects
