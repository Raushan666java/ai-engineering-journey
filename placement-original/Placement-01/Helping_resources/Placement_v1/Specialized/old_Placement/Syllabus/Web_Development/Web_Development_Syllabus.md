# Web Development Syllabus (Laravel, MySQL, JavaScript)

## A. Frontend

- HTML5: structure, forms, semantic tags
- CSS3: selectors, box model, flexbox, grid, responsive design, media queries
- JavaScript: syntax, DOM manipulation, events, ES6+, AJAX, fetch API
- Frontend frameworks: basics of React.js, Tailwind CSS (optional)
- Validation: client-side form validation
- Tooling: npm, webpack, browser dev tools

## B. Backend (Laravel)

- Laravel basics: installation, directory structure, MVC architecture
- Routing: web.php, API routes
- Controllers, models, views (Blade templating)
- Eloquent ORM: relationships, querying, scopes
- Middleware: authentication, authorization, custom middleware
- Request lifecycle, service providers
- Validation: request validation, custom rules
- File upload, storage, image manipulation
- REST APIs: resource controllers, API resources, response formatting
- Authentication: Laravel Breeze, Sanctum, JWT
- Error handling, logging
- Testing: PHPUnit, feature/unit tests
- Task scheduling: cron jobs, Laravel scheduler
- Queues: jobs, workers, event broadcasting
- Security: CSRF, XSS, SQL injection prevention

## C. Database (MySQL)

- MySQL basics: installation, configuration
- Database design: tables, relationships, normalization
- SQL: SELECT, INSERT, UPDATE, DELETE, JOIN, subqueries, indexes
- Migrations: creating/modifying tables via Laravel
- Seeding and factories
- Query optimization, transactions
- Backup and restore

## D. Integration & Deployment

- API integration: consuming external APIs, HTTP clients
- Environment configuration: .env files, config caching
- Deployment: shared hosting, VPS, cloud (AWS, DigitalOcean)
- CI/CD basics: GitHub Actions, Envoyer
- Monitoring: error tracking, performance monitoring
- Version control: Git, GitHub workflows

## E. Real-World Projects

- Portfolio website
- Notes app with cloud sync
- Real-time chat app (Laravel Echo, Pusher)
- Task manager system
- RESTful API for mobile/web clients
