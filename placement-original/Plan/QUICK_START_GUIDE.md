## 💡 PROBLEM-SOLVING APPROACH

### Step-by-Step Method

#### 1. Understand (5 minutes)
- Read problem carefully
- Identify inputs & outputs
- Note constraints
- Ask clarifying questions

#### 2. Plan (10 minutes)
- Think of brute force solution
- Optimize approach
- Consider edge cases
- Estimate time/space complexity

#### 3. Code (20 minutes)
- Write clean, readable code
- Use meaningful variable names
- Add comments for complex logic
- Handle edge cases

#### 4. Test (10 minutes)
- Test with sample inputs
- Test edge cases
- Test large inputs
- Verify time/space complexity

#### 5. Optimize (10 minutes)
- Can you do better?
- Different data structure?
- Mathematical approach?
- Trade-offs?

#### 6. Review (5 minutes)
- Read solution discussions
- Learn alternative approaches
- Note patterns & techniques
- Add to personal notes

**Total Time per Problem**: 60 minutes (average)

## 💪 MOTIVATION BOOSTERS

### When Feeling Stuck:
1. Take a 10-minute break
2. Explain problem to rubber duck
3. Draw diagrams
4. Look at similar problems
5. Ask for hints (not solution)

3. Focus on today only
