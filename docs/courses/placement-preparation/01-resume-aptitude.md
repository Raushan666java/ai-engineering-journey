## 1. Resume Building (200+ Lines)

Your resume is your 6-second pitch. Recruiters at service-based companies, product startups, and FAANG all scan differently, but the fundamentals are universal.

### 1.1 Standard Resume Structure

A strong campus placement resume follows a strict single-page (or max 2-page for experienced hires) format with these sections in order:

```
1. CONTACT INFORMATION
   Name | Phone | Email | LinkedIn URL | GitHub/Portfolio URL

2. PROFESSIONAL SUMMARY / OBJECTIVE
   2-3 lines summarizing your profile, target role, and key differentiator

3. EDUCATION
   Degree | Institution | CGPA/Percentage | Year
   (Reverse chronological — highest degree first)

4. TECHNICAL SKILLS
   Languages | Frameworks | Databases | Tools | Platforms
   (Grouped by category, not just a comma-separated blob)

5. PROJECTS (2-4 projects)
   Project Name | Tech Stack | Timeline
   Bullet points describing what you did, how you did it, and the impact

6. EXPERIENCE / INTERNSHIPS (if any)
   Company | Role | Duration
   Bullet points with quantified achievements

7. POSITIONS OF RESPONSIBILITY / LEADERSHIP
   Club/Committee | Role | Impact

8. ACHIEVEMENTS & CERTIFICATIONS
   Competitive programming ranks, hackathon wins, scholarships, certifications
```

### 1.2 The 6-Second Recruiter Scan

Recruiters and ATS (Applicant Tracking Systems) decide in 6 seconds:

| What They Check | Why |
|----------------|-----|
| **Name & Contact** | Can they reach you? (missing email = instant reject) |
| **Current College + Year** | Eligibility for the role |
| **CGPA** | Filter criterion (most set a cutoff, usually 6+ or 7+) |
| **Skills section** | Do you have the keywords they're searching for? |
| **Last project/internship** | Is it relevant to this role? |
| **Overall formatting** | Is it clean or a mess? |

**The 6-second rule in practice:**
- Top third of page must contain: Name, Skills, Education CGPA, and one strong project
- ATS parses before a human sees it — use standard section headers (no fancy icons)
- Font size: 10-12pt body, 14-16pt name. Margins: 0.5-0.75 inches

### 1.3 Quantifying Achievements (Before → After)

Recruiters don't read responsibilities; they read impact. Every bullet should follow:

> **Action Verb + What You Did + Measurable Outcome**

| Before (Weak) | After (Strong) |
|--------------|----------------|
| Built a chatbot for the college website | Built an NLP-powered FAQ chatbot serving 2,000+ students, reducing admin queries by 65% |
| Worked on a movie recommendation system | Designed a collaborative filtering engine achieving 92% precision on MovieLens-100k dataset, outperforming baseline by 18% |
| Participated in hackathons | Won 3/8 national hackathons, building full-stack prototypes under 36-hour sprints |
| Optimized database queries | Reduced API response time from 2.3s to 310ms by implementing Redis caching and indexing MongoDB collections |
| Created a REST API | Architected a RESTful API handling 5,000+ RPM with JWT auth, rate limiting, and 99.5% uptime |

**Quantification templates:**

- *Reduced [X] by [Y]% by implementing [Z]*
- *Served [N] users with [latency/throughput improvement]*
- *Improved [metric] from [A] to [B] via [approach]*
- *Processed [N] records/requests in [timeframe]*
- *Achieved [accuracy/speed/reduction] of [X]% using [technique]*

### 1.5 Common Mistakes (And How to Fix Them)

| Mistake | Why It Hurts | Fix |
|---------|-------------|-----|
| Spelling/grammar errors | Looks careless — instant reject | Read aloud, use Grammarly, get 2 friends to proofread |
| Including photo, age, gender | Biases hiring decisions, wastes space | Remove completely |
| "Responsible for" bullets | Passive, boring, vague | Start with action verbs, quantify |
| CGPA < 7.0 with no explanation | Red flag | Omit or explain (e.g., "major GPA: 8.2") |
| Too many technologies | Looks like keyword stuffing | List 8-12 that you can actually answer questions on |
| Using templates with columns/tables | ATS cannot parse them | Single-column, standard headers |
| PDF with password/permissions | ATS cannot read it | Save as standard PDF without restrictions |
| Including irrelevant high school data | Filler | Remove unless exceptional achievement |
| Font inconsistencies | Looks unprofessional | Use one font throughout (Calibri, Roboto, Garamond) |
| Exaggerating or lying | Caught in interview → blacklisted | Always honest; frame modest achievements well |

## 2. LinkedIn Profile Optimization (100+ Lines)

Your LinkedIn profile is your always-on resume. Recruiters search LinkedIn before formal applications. An optimized profile gets 3x more recruiter messages.

### 2.1 Headline

Your headline appears everywhere — search results, comments, messages. Don't just write "Student at ABC College".

**Formula:** `[Current Role] | [Key Skill 1] + [Key Skill 2] | [Target Role] | [What You Build]`

| Weak | Strong |
|------|--------|
| Student at XYZ University | CS @ IIT Bombay | Full-Stack Developer | React + Spring Boot | Building scalable web apps |
| Software Engineer | SDE @ Razorpay | Go + Distributed Systems | Payments Infrastructure |
| Looking for SDE roles | Final-year CS @ NIT Surathkal | Java | System Design | Open for SDE-1 2025 |

**Optimization tips:**
- Use all 220 characters LinkedIn allows
- Include terms recruiters search for: your tech stack, role, and level
- Add "Open to Work" frame if actively job-hunting
- Avoid generic words: "enthusiast", "passionate", "aspiring"

### 2.2 About Section (Your Story)

Three paragraphs max, written in first person. Structure:

```
PARA 1: Who you are + what you do + key differentiator
PARA 2: Notable achievements quantified (projects, internships, impact)
PARA 3: What you're looking for + call to action
```

**Example (Product SDE):**

> I'm a final-year CS student at NIT Surathkal building distributed systems and full-stack applications. I specialize in Go, Java, and TypeScript with a focus on high-throughput, low-latency backend services.
>
> During my internship at Razorpay, I engineered a payment dispute resolution service handling 500+ daily cases across 3 gateways, reducing manual intervention by 60%. At Flipkart Grid 4.0, I built a real-time price dashboard processing 5M+ events/day via Kafka — winning 2nd place nationally.
>
> I'm seeking SDE-1 roles in product engineering teams working on scalable infrastructure or developer tooling. Open to Bangalore, Hyderabad, and remote opportunities. Feel free to connect or DM for referrals!

**Example (Service-Based):**

> Computer Science graduate passionate about building reliable software. Proficient in Java, SQL, and Spring Boot with hands-on experience in full-stack development and database design.
>
> Completed 3 industry projects and an internship at TechCorp building REST APIs and automating reporting pipelines. Strong foundation in OOP, data structures, and SDLC practices.
>
> Actively looking for software developer roles. Open to relocation. Connect with me for opportunities or collaboration!

### 2.3 Experience & Projects Section

- **Write 2-3 bullets per entry** (not the full resume, but enough to interest)
- **Include media** (screenshots, demo links, GitHub repos, articles)

### 2.6 Networking for Referrals

A referral multiplies your resume visibility by 10x at most companies.

**How to ask for a referral:**

```
Step 1: Find the person
  → LinkedIn search: "SDE [Company]" → filter by 1st/2nd degree
  → Target: alumni from your college or mutual connections

Step 2: Connection request (no referral ask yet)
  → "Hi [Name] — I'm a [year] student at [College] also pursuing SDE roles.
     Would love to connect and learn about your experience at [Company]."

Step 3: After they accept (wait 2-3 days)
  → "Hi [Name], thanks for connecting! I'm preparing for SDE interviews and
     noticed you're at [Company]. Would you have 10 minutes this week for a
     quick chat about your team and interview process?"

Step 4: After the chat (within 24 hours)
  → Thank them. Then (if they offered): "Based on our conversation, I'm
     excited about [Team/Role]. Would you be comfortable referring me?"

Step 5: Send them your resume + job ID + 2-line pitch
  → Make it as easy as possible for them to forward
```

**Golden rules:**
- Never ask for a referral in the first message — build a tiny relationship first
- Always research the person's role and team before messaging
- Apply to the job *before* asking for referral (check the portal)
- Have your resume ready in the format they ask for

## 3. Aptitude Crash Course (200+ Lines)

This is a **quick reference** for campus placement aptitude tests. For the GATE-level deep dive, see the dedicated GATE Aptitude chapter.

### 3.1 Quick Formula Reference

#### Percentages

| Concept | Formula |
|---------|---------|
| Percentage change | `((New - Old) / Old) × 100` |
| Successive increase | `a + b + (ab/100)` — two increments of a% and b% |
| Discount | `MP × (100 - D%) / 100 = SP` |
| Profit % | `(Profit / CP) × 100` |
| Population after n years | `P × (1 + r/100)^n` |
| Depreciation after n years | `P × (1 - r/100)^n` |

#### Time, Speed & Distance

| Concept | Formula |
|---------|---------|
| Speed | `Distance / Time` |
| Relative speed (same direction) | `|S1 - S2|` |
| Relative speed (opposite) | `S1 + S2` |
| Average speed (equal distances) | `(2ab) / (a + b)` — harmonic mean |
| Time to meet (two bodies) | `Distance / (S1 + S2)` — opposite |
| Train crossing pole | `Length / Speed` |
| Train crossing platform | `(Train Length + Platform Length) / Speed` |
| Boat upstream | `Speed(b) - Speed(r)` |
| Boat downstream | `Speed(b) + Speed(r)` |

#### Ratios & Proportions

- If `A : B = x : y` and `B : C = p : q`, then `A : B : C = xp : yp : yq`
- If `A : B = p : q` and `B : C = r : s`, then `A : C = pr : qs`
- If `A = kB` (A directly proportional to B) → `A1/B1 = A2/B2`
- If `A = k/B` (A inversely proportional to B) → `A1 × B1 = A2 × B2`

#### Averages

| Concept | Formula |
|---------|---------|
| Average | `Sum / Count` |
| Weighted average | `(w1×a1 + w2×a2 + ...) / (w1 + w2 + ...)` |
| Combined average (two groups) | `(n1×a1 + n2×a2) / (n1 + n2)` |
| Age average (after n years) | Each person's age increases by n |

#### Profit, Loss & Discount

| Concept | Formula |
|---------|---------|
| Profit | `SP - CP` (when SP > CP) |
| Loss | `CP - SP` (when CP > SP) |
| Profit % | `(Profit / CP) × 100` |
| Loss % | `(Loss / CP) × 100` |
| Discount | `MP - SP` |
| Discount % | `(Discount / MP) × 100` |
| Successive discount | `a + b - (ab/100)` for two discounts a% and b% |

#### Simple & Compound Interest

| Concept | Formula |
|---------|---------|
| Simple Interest | `SI = (P × R × T) / 100` |
| Amount (SI) | `P + SI` |
| Compound Interest | `CI = P × (1 + R/100)^T - P` |
| Amount (CI) | `P × (1 + R/100)^T` |
| Half-yearly CI | `P × (1 + R/200)^(2T)` |
| Quarterly CI | `P × (1 + R/400)^(4T)` |

#### Permutations & Combinations

| Concept | Formula |
|---------|---------|
| nPr | `n! / (n-r)!` |
| nCr | `n! / (r! × (n-r)!)` |
| Circular permutation (n distinct) | `(n-1)!` |
| Arrangements with repetition | `n^k` |

#### Probability

| Concept | Formula |
|---------|---------|
| Probability of event | `Favorable Outcomes / Total Outcomes` |
| P(Not E) | `1 - P(E)` |
| P(A or B) | `P(A) + P(B) - P(A∩B)` |
| P(A and B) independent | `P(A) × P(B)` |

#### Number System Quick Facts

- Divisibility by 3: Sum of digits divisible by 3
- Divisibility by 4: Last two digits divisible by 4
- Divisibility by 6: Divisible by both 2 and 3
- Divisibility by 8: Last three digits divisible by 8
- Divisibility by 9: Sum of digits divisible by 9
- Divisibility by 11: Difference of (sum of odd-placed digits) and (sum of even-placed digits) = 0 or multiple of 11
- HCF × LCM = Product of numbers
- HCF of fractions = `HCF of numerators / LCM of denominators`
- LCM of fractions = `LCM of numerators / HCF of denominators`

### 3.2 20 Solved Problems

#### Problem 1: Percentage — Successive Increase

> The salary of an employee is first increased by 20%, then decreased by 10%, and then increased by 25%. What is the net percentage change?

**Solution:**

Using successive percentage formula: `a + b + c + (ab + bc + ca)/100 + (abc)/10000`

First two changes: `20 - 10 + (20 × (-10))/100 = 10 - 2 = 8%`
Now apply 25% on 108: `8 + 25 + (8 × 25)/100 = 33 + 2 = 35%`

**Answer: 35% increase**

---

#### Problem 2: Time, Speed & Distance — Relative Speed

> Two trains, 140m and 160m long, run at 60 km/h and 40 km/h respectively in opposite directions on parallel tracks. How long do they take to cross each other completely?

**Solution:**

Relative speed = `60 + 40 = 100 km/h = 100 × 5/18 = 250/9 m/s`
Total distance to cover = `140 + 160 = 300m`
Time = `Distance / Speed = 300 / (250/9) = 300 × 9/250 = 2700/250 = 10.8 seconds`

**Answer: 10.8 seconds**

---

#### Problem 3: Ratio & Proportion

> If A : B = 2 : 3 and B : C = 5 : 7, find A : B : C.

**Solution:**

```
A : B = 2 : 3
B : C = 5 : 7
Make B equal: LCM of 3 and 5 = 15
A : B = 2×5 : 3×5 = 10 : 15
B : C = 5×3 : 7×3 = 15 : 21
A : B : C = 10 : 15 : 21
```

**Answer: 10 : 15 : 21**

---

#### Problem 4: Averages — Weighted Average

> The average marks of 20 students in a class is 72. The average marks of 12 boys is 68. What is the average marks of the girls?

**Solution:**

Total marks of 20 students = `20 × 72 = 1440`
Total marks of 12 boys = `12 × 68 = 816`
Total marks of 8 girls = `1440 - 816 = 624`
Average of girls = `624 / 8 = 78`

**Answer: 78**

---

#### Problem 5: Profit & Loss

> A shopkeeper marks an article 40% above cost price and offers a discount of 15%. What is his profit percentage?

**Solution:**

Let CP = 100
MP = 100 + 40 = 140
Discount = 15% of 140 = 21
SP = 140 - 21 = 119
Profit = 119 - 100 = 19%

**Answer: 19%**

---

#### Problem 6: Compound Interest

> Find the compound interest on Rs. 10,000 at 10% per annum for 2 years compounded half-yearly.

**Solution:**

`CI = P × (1 + R/200)^(2T) - P`
`CI = 10,000 × (1 + 10/200)^(4) - 10,000`
`CI = 10,000 × (1.05)^4 - 10,000`
`CI = 10,000 × 1.21550625 - 10,000`
`CI = 12,155.06 - 10,000 = 2,155.06`

**Answer: Rs. 2,155.06**

#### Problem 7: Permutation — Arrangements

> How many distinct 4-letter words can be formed from the letters of the word "MATHEMATICS"?

**Solution:**

Letters: M(2), A(2), T(2), H(1), E(1), I(1), C(1), S(1)

This requires casework by letter usage patterns:

**Case 1:** All 4 letters distinct
Choose 4 from 8 distinct letters: `C(8,4) = 70` ways
Arrange each: 4! = 24
Total = `70 × 24 = 1680`

**Case 2:** 1 letter repeated twice, 2 distinct
Repeated can be M, A, or T (3 options)
Choose 2 distinct from remaining 7: `C(7,2) = 21`
Arrange: 4!/2! = 12
Total = `3 × 21 × 12 = 756`

**Case 3:** 2 letters repeated twice
Choose 2 from {M, A, T}: `C(3,2) = 3`
Arrange: 4!/(2!×2!) = 6
Total = `3 × 6 = 18`

**Case 4:** 1 letter repeated 3 times — not possible (max frequency = 2)

Total = `1680 + 756 + 18 = 2454`

**Answer: 2,454**

#### Problem 8: Probability — Card Selection

> Two cards are drawn from a well-shuffled deck of 52 cards. Find the probability that both are kings.

**Solution:**

Total outcomes = `C(52,2) = 1326`
Favorable outcomes = `C(4,2) = 6`
Probability = `6 / 1326 = 1 / 221`

**Answer: 1/221**

#### Problem 9: Time & Work

> A can do a piece of work in 12 days, B in 15 days, and C in 20 days. They work together for 3 days, then A leaves. How many more days will B and C take to finish the work?

**Solution:**

Work done per day: A = 1/12, B = 1/15, C = 1/20
Combined (A+B+C) = `1/12 + 1/15 + 1/20 = (5+4+3)/60 = 12/60 = 1/5`
Work done in 3 days = `3 × 1/5 = 3/5`
Remaining work = `1 - 3/5 = 2/5`
B + C per day = `1/15 + 1/20 = (4+3)/60 = 7/60`
Days needed = `(2/5) / (7/60) = (2/5) × (60/7) = 120/35 = 24/7 = 3 3/7`

**Answer: 3 3/7 days**

#### Problem 10: Mixtures & Alligation

> In what ratio must water be mixed with milk costing Rs. 30/liter to obtain a mixture worth Rs. 24/liter?

**Solution:**

Using alligation:

| Cost of milk | Cost of water | Mixture cost |
|:------------:|:-------------:|:------------:|
|     30       |      0        |     24       |

Ratio = `(24 - 0) : (30 - 24) = 24 : 6 = 4 : 1`

So milk : water = 4 : 1

**Answer: 4 : 1 (Milk : Water)**

#### Problem 11: Number System — HCF & LCM

> Find the smallest number that leaves a remainder of 5 when divided by 8, 12, and 15.

**Solution:**

The number N must satisfy: N ≡ 5 (mod 8), N ≡ 5 (mod 12), N ≡ 5 (mod 15)
So N = LCM(8, 12, 15) × k + 5
LCM(8, 12, 15) = 2³ × 3 × 5 = 120
Smallest number (k=0): N = 120 + 5 = 125

**Answer: 125**

#### Problem 12: Permutation — Seating Arrangement

> In how many ways can 5 boys and 3 girls be seated such that no two girls sit together?

**Solution:**

First seat the 5 boys: 5! = 120 ways
This creates 6 gaps (4 between + 2 at ends): _ B _ B _ B _ B _ B _
Choose 3 gaps for girls: `C(6,3) = 20` ways
Arrange girls in chosen gaps: 3! = 6
Total = `120 × 20 × 6 = 14,400`

**Answer: 14,400**

#### Problem 13: Probability — Dice

> Two unbiased dice are thrown. Find the probability that the sum is at least 10.

**Solution:**

Total outcomes = 6 × 6 = 36
Favorable (sum ≥ 10):
(4,6), (5,5), (5,6), (6,4), (6,5), (6,6) = 6 outcomes
Probability = 6/36 = 1/6

**Answer: 1/6**

#### Problem 14: Time, Speed & Distance — Boat & Stream

> A boat travels 30 km upstream and 30 km downstream in 8 hours. If the speed of the stream is 5 km/h, find the speed of the boat in still water.

**Solution:**

Let boat speed = x km/h
Upstream speed = (x - 5), Time = 30/(x-5)
Downstream speed = (x + 5), Time = 30/(x+5)
Total time: `30/(x-5) + 30/(x+5) = 8`
`30(x+5 + x-5) / (x²-25) = 8`
`30(2x) / (x²-25) = 8`
`60x = 8(x²-25)`
`60x = 8x² - 200`
`8x² - 60x - 200 = 0`
`2x² - 15x - 50 = 0`
`(2x + 5)(x - 10) = 0`
x = 10 (x = -2.5 invalid)

**Answer: 10 km/h**

#### Problem 15: Simple Interest

> A sum of money doubles itself in 8 years at simple interest. Find the rate of interest.

**Solution:**

If sum doubles, Interest = P (the original amount)
`SI = (P × R × T) / 100`
`P = (P × R × 8) / 100`
`R = 100/8 = 12.5%`

**Answer: 12.5% per annum**

#### Problem 16: Percentage — Population

> The population of a town increases by 5% annually. If the current population is 80,000, what will it be after 3 years?

**Solution:**

`P = 80,000 × (1 + 5/100)³`
`P = 80,000 × (1.05)³`
`P = 80,000 × 1.157625`
`P = 92,610`

**Answer: 92,610**

#### Problem 17: Ratio — Partnership

> A and B invest in a business in the ratio 3:5. A withdraws his capital after 8 months. If the total annual profit is Rs. 56,000, find A's share.

**Solution:**

A's investment = 3 × 8 = 24 (units × months)
B's investment = 5 × 12 = 60
Profit ratio A:B = 24:60 = 2:5
A's share = `(2/7) × 56,000 = Rs. 16,000`

**Answer: Rs. 16,000**

#### Problem 18: Time & Work — Pipes

> Two pipes A and B can fill a tank in 20 and 30 minutes respectively. A third pipe C can empty it in 15 minutes. If all three are opened together, how long will it take to fill the tank?

**Solution:**

Rate: A = 1/20, B = 1/30, C = -1/15
Combined rate = `1/20 + 1/30 - 1/15 = (3+2-4)/60 = 1/60`
Time = 60 minutes

**Answer: 60 minutes**

#### Problem 19: Averages — Age Problem

> The average age of a family of 5 members is 25 years. If the grandfather is included, the average increases by 4 years. Find the grandfather's age.

**Solution:**

Total age of 5 members = 5 × 25 = 125
New average = 25 + 4 = 29
Total age of 6 members = 6 × 29 = 174
Grandfather's age = 174 - 125 = 49

**Answer: 49 years**

#### Problem 20: Probability — Ball Selection

> A bag contains 4 red, 5 blue, and 6 green balls. Three balls are drawn at random. Find the probability that all three are of different colors.

**Solution:**

Total balls = 15
Total outcomes = `C(15,3) = 455`
Favorable = 1 red × 1 blue × 1 green = `C(4,1) × C(5,1) × C(6,1) = 4 × 5 × 6 = 120`
Probability = `120/455 = 24/91`

**Answer: 24/91**

### 3.3 Logical Reasoning Shortcuts

#### Syllogisms

**Rule of thumb for "All/Some/No" statements:**

| Statement | Venn Interpretation | Quick Check |
|-----------|-------------------|-------------|
| All A are B | A inside B | "Some A are B" is also true |
| Some A are B | A and B overlap | Cannot say "All A are B" |
| No A is B | Disjoint circles | "Some A are not B" is also true |
| Some A are not B | A partially outside B | Cannot say "No A is B" |

**Shortcut method (Ravish Sood's technique):**
- Combine two statements using the middle term
- Check if middle term is distributed at least once
- Elimination method: cross out options that contradict known true statements

#### Blood Relations

**Quick reference:**

| Relation | Meaning |
|----------|---------|
| Father's/Mother's father | Grandfather |
| Father's/Mother's mother | Grandmother |
| Father's brother | Uncle |
| Father's sister | Aunt |
| Mother's brother | Maternal uncle |
| Mother's sister | Aunt |
| Brother's/Sister's son | Nephew |
| Brother's/Sister's daughter | Niece |
| Son's/Daughter's son | Grandson |
| Son's/Daughter's daughter | Granddaughter |
| Husband's/Wife's father | Father-in-law |
| Husband's/Wife's mother | Mother-in-law |

**Shortcuts for solving:**
- Draw a family tree top-down (oldest on top)
- Use + for male, - for female, ↔ for marriage, → for children
- Replace pronouns with actual names
- Work backwards from the question to find the relationship

#### Arrangements (Linear & Circular)

**Linear arrangement shortcut:**
- Fix the first condition person's position
- Work left-to-right filling in what you know
- Use "not" conditions to eliminate
- Draw placeholders: ___ ___ ___ ___

**Circular arrangement shortcut:**
- Fix one person at a position (say, the top)
- Work clockwise/anticlockwise as given
- Draw a circle with positions labeled
- Use relative positions ("to the left of", "opposite")

**Puzzle types:**
- Floor-and-flat puzzles: Draw a building, number floors, label flats as A/B or 1/2
- Comparison puzzles: Use >, <, = notations in a chain
- Scheduling (days/months): Draw a calendar grid

#### Coding-Decoding

**Common patterns:**

| Type | Example | Logic |
|------|---------|-------|
| Letter shift | CAT → DDU | Each letter +1 position (+1,+1,+1) |
| Reverse | ABC → CBA | Reverse the string |
| Vowel replacement | CAT → C_T | Vowels coded as numbers (A=1, E=2, etc.) |
| Pattern-based | 123 → 236 | Each digit × 2 |
