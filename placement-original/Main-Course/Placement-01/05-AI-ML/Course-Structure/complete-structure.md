## 📋 File Naming Conventions

### Lectures
- `01-topic-name.md` - Markdown format
- Include objectives, content, examples
- Reference additional resources

### Labs
- `lab-01-descriptive-name.py` - Python scripts
- `lab-01-descriptive-name.ipynb` - Jupyter notebooks
- Include step-by-step instructions
- Provide expected outputs

### Assignments
- `assignment-01-topic.py` - Programming assignments
- `assignment-01-topic.md` - Written assignments
- Include rubrics and deadlines

### Projects
- Separate folder for each project
- Include `README.md` with instructions
- Provide starter code and datasets
- Include evaluation criteria

### Datasets
- Use descriptive filenames
- Include data dictionaries
- Provide source information
- Multiple formats when applicable

## 🔧 Standard Files in Each Week

1. **README.md** - Week overview and navigation
2. **requirements.txt** - Python package dependencies
3. **environment.yml** - Conda environment specification
4. **schedule.md** - Detailed daily schedule
5. **objectives.md** - Learning objectives and outcomes

## 📊 Assessment Structure

### Weekly (60%)
- **Quizzes**: 20% (2-3 per week)
- **Lab Assignments**: 25% (Hands-on exercises)
- **Mini Projects**: 15% (Weekly projects)

### Major Projects (25%)
- **Mid-term Project**: 10% (Week 10)
- **Capstone Project**: 15% (Week 20)

### Final Evaluation (15%)
- **Comprehensive Exam**: 10%
- **Portfolio Presentation**: 5%

## 🚀 Getting Started

1. **Clone/Download** the course structure
2. **Set up environment** using provided configuration files
3. **Follow weekly schedule** in Course-Materials/Schedule/
4. **Complete assignments** in order
5. **Submit projects** according to guidelines
6. **Track progress** using provided checklists

This structure supports a complete 20-week AI/ML learning journey from beginner to advanced level.
