# 🎯 Master Placement Preparation Syllabus
*Complete 6-Month Roadmap*

## Phase 1: Foundation (Month 1-2)
### Programming Fundamentals
- **Java/Python/C++** (choose one): 3-4 weeks
- **Time Complexity**: Big-O analysis
- **Basic DSA**: Arrays, strings, basic math

### Core CS Subjects (Parallel Study)
- **DBMS**: SQL basics, normalization
- **OS**: Process management, memory management
- **CN**: OSI model, TCP/IP, HTTP

## Phase 2: Data Structures & Algorithms (Month 2-4)
### Linear Structures (Week 5-8)
- Arrays, Linked Lists, Stacks, Queues
- **Target**: 50 easy problems

### Non-Linear Structures (Week 9-12)
- Trees, Graphs, Heaps, Hashing
- **Target**: 75 medium problems

### Advanced Techniques (Week 13-16)
- DP, Greedy, Backtracking, Sliding Window
- **Target**: 50 medium + 25 hard problems

## Phase 3: System Design & Projects (Month 4-5)
### Low-Level Design
- OOP principles, design patterns
- **Projects**: Parking lot, library system

### High-Level Design
- Scalability, databases, caching
- **Systems**: URL shortener, chat app, social feed

## Phase 4: Interview Preparation (Month 5-6)
### Technical Rounds
- **DSA Practice**: 2-3 problems daily
- **System Design**: 2 systems weekly
- **CS Fundamentals**: Topic-wise revision

### Behavioral & HR
- Resume building, project explanations
- Common HR questions, company research

## Weekly Schedule Template
```
Monday-Wednesday: DSA (3-4 hours)
Thursday: System Design (2-3 hours)
Friday: CS Subjects (2-3 hours)
Saturday: Mock interviews, revision
Sunday: Projects, resume work
```

## Success Metrics
- **DSA**: 300+ problems solved
- **System Design**: 15+ systems designed
- **Projects**: 3-4 complete projects
- **Mock Interviews**: 20+ sessions
