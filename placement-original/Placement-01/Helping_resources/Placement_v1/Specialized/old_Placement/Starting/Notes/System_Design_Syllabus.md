# SECTION 1: Core CS Subjects

## 6. System Design (Low-Level & High-Level)

### A. Low-Level Design (LLD)

- Class diagrams, relationships, UML basics
- SOLID principles: SRP, OCP, LSP, ISP, DIP
- Design patterns: Factory, Singleton, Observer, Adapter, Decorator, Strategy, Command, Template Method

### B. High-Level Design (HLD)

- Scalable systems: URL Shortener, Instagram, Uber, Chat System, News Feed, Search Engine
- Load balancing: round robin, least connections, weighted, IP hash
- Sharding, replication, partitioning
- Caching: Redis, Memcached, CDN, browser, DB, app cache
- Message queues: RabbitMQ, Kafka, SQS, Pub/Sub
- CAP theorem, consistent hashing, ACID vs BASE
- Database choices: SQL vs NoSQL, sharding, federation
- API design, microservices, event-driven, serverless, distributed tracing
