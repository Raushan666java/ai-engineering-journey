## 📝 **STUDY TECHNIQUES**

### **Active Learning**
1. **Before Coding:**
   - Draw diagrams
   - Work through examples manually
   - Predict edge cases

2. **While Coding:**
   - Comment each section
   - Test incrementally
   - Use debugger

3. **After Coding:**
   - Analyze complexity
   - Optimize further
   - Document learnings

### **Spaced Repetition**
- Review Day 1 content on Day 3
- Review Day 2 content on Day 4
- Full review on Day 7
- Weekly review thereafter

### **Practice Strategy**
1. **Easy Problems (30%):** Build confidence
2. **Medium Problems (50%):** Core practice
3. **Hard Problems (20%):** Push boundaries

1. Re-read problem carefully
2. Draw diagrams and examples
3. Check your notes

2. Use debugger
3. Test with small inputs
4. Check edge cases
