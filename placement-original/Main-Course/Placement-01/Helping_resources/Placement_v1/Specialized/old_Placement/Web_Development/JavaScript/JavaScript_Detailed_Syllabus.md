# JavaScript Detailed Syllabus

## 1. Introduction
- What is JavaScript?
- History and evolution
- JavaScript engines and runtime environments
- ECMAScript standards

## 2. Basics
- Syntax and statements
- Variables: var, let, const
- Data types: string, number, boolean, null, undefined, symbol, bigint
- Type conversion and coercion
- Operators: arithmetic, assignment, comparison, logical, bitwise, ternary
- Comments

## 3. Control Structures
- if, else, else if
- switch statement
- for, while, do-while loops
- break and continue

## 4. Functions
- Function declaration and expression
- Arrow functions
- Parameters, arguments, default parameters
- Return values
- Scope: global, local, block
- Closures
- IIFE (Immediately Invoked Function Expressions)
- Callback functions
- Higher-order functions

## 5. Objects and Arrays
- Object literals, properties, methods
- this keyword
- Prototypes and inheritance
- Object.create, Object.assign
- Array creation and manipulation
- Array methods: push, pop, shift, unshift, splice, slice, map, filter, reduce, forEach, find, includes, etc.
- Destructuring assignment
- Spread and rest operators

## 6. Strings and Numbers
- String methods: length, indexOf, slice, substring, substr, replace, split, join, trim, toUpperCase, toLowerCase, etc.
- Template literals
- Number methods: toFixed, toPrecision, parseInt, parseFloat, isNaN, isFinite
- Math object

## 7. Date and Time
- Date object creation
- Getting and setting date/time values
- Formatting dates

## 8. Error Handling
- try, catch, finally
- throw statement
- Custom error objects

## 9. DOM Manipulation
- What is the DOM?
- Selecting elements: getElementById, getElementsByClassName, getElementsByTagName, querySelector, querySelectorAll
- Changing content and attributes
- Creating, appending, removing elements
- Traversing the DOM
- Modifying styles and classes

## 10. Events
- Event handling: addEventListener, removeEventListener
- Event object, event propagation (bubbling and capturing)
- Common events: click, change, input, submit, mouse events, keyboard events
- Event delegation

## 11. ES6+ Features
- let and const
- Arrow functions
- Template literals
- Default, rest, and spread parameters
- Destructuring
- Enhanced object literals
- Classes and inheritance
- Modules: import/export
- Promises
- async/await
- Symbol, Set, Map, WeakSet, WeakMap

## 12. Asynchronous JavaScript
- Callbacks
- Promises
- async/await
- Event loop, call stack, task queue, microtasks
- setTimeout, setInterval, clearTimeout, clearInterval

## 13. JSON
- JSON syntax
- JSON.parse and JSON.stringify
- Fetching and sending JSON data

## 14. Local Storage and Session Storage
- localStorage and sessionStorage APIs
- Storing, retrieving, and removing data

## 15. Error and Debugging Tools
- Console methods: log, warn, error, table, time
- Debugging with browser dev tools
- Breakpoints, watch expressions, call stack

## 16. Best Practices
- Code organization and modularity
- Naming conventions
- Avoiding global variables
- Writing clean and maintainable code

- Introduction to TypeScript
