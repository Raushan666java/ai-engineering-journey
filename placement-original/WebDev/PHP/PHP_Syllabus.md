# PHP Complete Syllabus — Modern & Laravel-Ready

**Purpose:** Master PHP fundamentals through advanced OOP, modern syntax, Laravel integration, and interview preparation.

---

## 📚 Course Structure

### Part 1: OOP — Object Oriented Programming Features

1. **Classes and Traits**: Eloquent Model with "extends" and "use" (4 min)
2. **Aliases and Multi-Level "extends"**: User Model (3 min)
3. **"implements" vs "extends"**: Interfaces in Filament User Model (4 min)
4. **Interface with Trait**: Spatie Media Model (3 min)
5. **Override/Extend Functions** of Laravel Packages (3 min)
6. **Controller Response Methods**: "General" Controller or Traits (4 min)
7. **Visibility**: public/private/protected (3 min)
8. **Static, New Object and Laravel Auto-Resolving** (5 min)

### Part 2: Various PHP Features in Laravel

1. **Callback Functions or Closures** (4 min)
2. **IF-Else**: Ternary and Null Safe Operators (3 min)
3. **Variable Types and Return Types** (4 min)
4. **Try-Catching Exceptions and PHP Errors** (3 min)
5. **Composer**: All You Need To Know (5 min)

### Part 3: Bonus Topics

1. **PHP New Syntax in Latest Versions** (4 min)
2. **Popular Array Functions**: Open-Source Examples (5 min)
3. **Popular String Functions**: Open-Source Examples (4 min)

## 📖 Detailed Topic Breakdown

### 01. Introduction to PHP

- What is PHP? Server-side scripting overview
- PHP versions (7.4, 8.0, 8.1, 8.2, 8.3+)
- Installation: XAMPP, WAMP, Docker, Homestead
- First PHP script, echo, print, syntax basics

### 02. PHP Basics

- Variables, constants, data types
- Operators: arithmetic, comparison, logical, assignment
- Comments and code organization
- Type juggling and type casting

### 03. Control Structures

- if, else, elseif, switch
- Loops: for, while, do-while, foreach
- break, continue, return
- Alternative syntax for templates

### 04. Functions

- Function declaration, parameters, return values
- Variable scope: local, global, static
- Anonymous functions, closures
- Arrow functions (PHP 7.4+)
- Built-in functions overview

### 05. Arrays

- Indexed arrays, associative arrays, multidimensional arrays
- Array functions: array_map, array_filter, array_reduce
- array_merge, array_diff, array_intersect
- Sorting, searching, and manipulation
- Spread operator (...)

### 06. Strings

- String manipulation: concatenation, interpolation
- String functions: strlen, substr, str_replace, explode, implode
- Regular expressions: preg_match, preg_replace
- Heredoc and Nowdoc syntax

### 07. Forms and User Input

- GET and POST methods
- $\_GET, $\_POST, $\_REQUEST superglobals
- Form validation and sanitization
- File uploads: $\_FILES, move_uploaded_file

### 08. File Handling

- fopen, fread, fwrite, fclose
- file_get_contents, file_put_contents
- Directory operations: scandir, mkdir, rmdir
- File permissions and security

### 09. Sessions and Cookies

- session_start, $\_SESSION
- setcookie, $\_COOKIE
- Session security best practices
- Session vs. Cookie use cases

### 10. Error Handling

- Error types: notices, warnings, fatal errors
- try-catch blocks, throw, Exception
- Custom exception classes
- Error logging: error_log, display_errors

### 11. PHP and MySQL

- MySQLi vs. PDO
- Database connection, CRUD operations
- Prepared statements and parameterized queries
- SQL injection prevention
- Transactions and error handling

### 12. Object Oriented PHP

- Classes, objects, properties, methods
- Constructors, destructors
- Inheritance: extends, parent::
- Visibility: public, private, protected
- Static properties and methods
- Abstract classes and interfaces
- Traits and trait precedence
- Namespaces and autoloading (PSR-4)
- Magic methods: **construct, **get, **set, **toString
- Type hinting and return types

### 13. Advanced PHP

- Closures and callback functions
- Generators and yield
- Reflection API
- PHP 8 features: named arguments, attributes, union types, match expression
- PHP 8.1+: enums, readonly properties, fibers
- Composer dependency management
- PSR standards (PSR-1, PSR-4, PSR-12)

### 14. PHP and Web Development

- HTTP methods: GET, POST, PUT, DELETE
- RESTful API design
- JSON: json_encode, json_decode
- cURL and HTTP clients
- Authentication: sessions, JWT, OAuth

### 15. Security Best Practices

- Input validation and sanitization
- SQL injection prevention
- XSS (Cross-Site Scripting) prevention
- CSRF (Cross-Site Request Forgery) protection
- Password hashing: password_hash, password_verify
- Secure file uploads
- HTTPS and SSL/TLS

### 16. PHP Frameworks Overview

- Laravel fundamentals
- Symfony, CodeIgniter, Yii
- Framework comparison and use cases

### 17. Practice and Projects

- Build a CRUD application
- Create a REST API
- User authentication system
- File upload and management
- Interview questions and coding challenges
