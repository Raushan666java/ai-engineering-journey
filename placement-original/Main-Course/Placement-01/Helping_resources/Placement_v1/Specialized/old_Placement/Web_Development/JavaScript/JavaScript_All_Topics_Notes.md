# JavaScript All Topics: Comprehensive Notes

## 1. Introduction to JavaScript
- Scripting language for web development, runs in browsers and servers (Node.js).
- Dynamically typed, prototype-based, supports OOP and functional programming.

## 2. Variables and Data Types
- `var`, `let`, `const` for variable declaration.
- Data types: string, number, boolean, null, undefined, object, symbol (ES6).
- Type coercion and dynamic typing.

## 3. Operators
- Arithmetic: `+`, `-`, `*`, `/`, `%`, `**`
- Assignment: `=`, `+=`, `-=`
- Comparison: `==`, `===`, `!=`, `!==`, `>`, `<`, `>=`, `<=`
- Logical: `&&`, `||`, `!`
- Ternary: `condition ? expr1 : expr2`

## 4. Control Structures
- `if`, `else`, `switch`
- Loops: `for`, `while`, `do...while`, `for...in`, `for...of`
- `break`, `continue`

## 5. Functions
- Function declaration, expression, arrow functions (ES6)
- Parameters, default/rest/spread
- Closures and scope
- IIFE (Immediately Invoked Function Expression)

## 6. Objects and Arrays
- Object literals, properties, methods
- Array creation, methods (`push`, `pop`, `map`, `filter`, `reduce`)
- Destructuring (ES6)

## 7. Prototypes and Inheritance
- Prototype chain, `__proto__`, `Object.create()`
- ES6 classes, constructor, inheritance (`extends`, `super`)

## 8. The DOM (Document Object Model)
- Selecting elements: `getElementById`, `querySelector`, etc.
- Modifying content and attributes
- Event handling: `addEventListener`, event object

## 9. BOM (Browser Object Model)
- `window`, `navigator`, `location`, `history`, `screen`
- Dialogs: `alert`, `confirm`, `prompt`

## 10. Error Handling
- `try...catch...finally`, `throw`
- Custom errors

## 11. Asynchronous JavaScript
- Callbacks, Promises, `async`/`await`
- Event loop, microtasks, macrotasks

## 12. JSON
- `JSON.stringify()`, `JSON.parse()`
- Data exchange with servers

## 13. ES6+ Features
- `let`, `const`, arrow functions, template literals
- Destructuring, spread/rest, default parameters
- Classes, modules (`import`/`export`)
- Sets, Maps, Symbol, iterators, generators

## 14. Modules and Tooling
- ES6 modules, CommonJS, AMD
- Bundlers: Webpack, Parcel
- Transpilers: Babel

## 15. Best Practices
- Use strict mode (`'use strict';`)
- Modular code, avoid global variables
- Consistent naming, code style
- Error handling and debugging

## 16. Debugging and Development Tools
- Browser DevTools (Elements, Console, Network, Sources)
- Linters (ESLint), formatters (Prettier)

## 17. Security
- XSS, CSRF, input validation
- Secure coding practices

## 18. Modern JavaScript Ecosystem
- NPM/Yarn, package management
- Frameworks: React, Angular, Vue (overview)
- Node.js basics
