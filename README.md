## 🎯 Specialization Tracks

Our curriculum is mapped into high-impact career tracks:

### 🌟 Track 1: AI Automation Engineer (Target: Global/Remote)
Designed specifically for traditional developers (like Laravel/PHP engineers) transitioning into high-value AI Engineering roles.
- **Phase 1:** Python Programming (21 chapters) — From basic syntax to advanced concurrency.
- **Phase 2:** Machine Learning (10 chapters) — Classical ML algorithms through deep neural networks.
- **Phase 3:** AI Agent Engineer (14 chapters) — Master FastAPI, RAG architectures, LangGraph, and MCP.
- **Phase 4:** System Design (24 chapters) — Learn to architect scalable AI systems with HLD & LLD.
- **Phase 5:** AI Engineering from Scratch (20 phases) — End-to-end journey from raw math to autonomous agents.

### 🏛️ Track 2: Government IT Officer (IBPS SO / NIC Scientist)
An exhaustive, exam-focused roadmap covering 21 subjects across 98+ intensive modules.
- **Core Tech:** DBMS, Computer Networks, OS, Data Structures, OOP, Software Engineering.
- **Aptitude & Reasoning:** Quantitative aptitude, logical reasoning, data interpretation.
- **Domain Specific:** Banking Tech, Information Security, Computer Organization.
- **Holistic Prep:** General/Banking Awareness, English, Hindi, Marketing, and Interview preparation.

## 💻 Local Development

Want to read offline or contribute? Setting up the project locally is blazing fast.

### Prerequisites
- Python 3.8+
- pip (Python package installer)

### Setup Instructions

```bash
# 1. Clone the repository
git clone https://github.com/Raushan666java/ai-engineering-journey.git
cd ai-engineering-journey

# 2. Install required dependencies
pip install mkdocs-material mkdocs-glightbox

# 3. Start the local development server
python -m mkdocs serve
```
Visit `http://localhost:8000` to see your local instance running with live-reloading enabled.

```bash
# Build static site for production deployment
python -m mkdocs build --clean
```
