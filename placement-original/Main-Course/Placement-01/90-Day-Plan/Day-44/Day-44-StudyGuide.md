# Day 44 — Greedy Algorithms

## Learning Objectives
- Grasp the idea of greedy choices and prove correctness via exchange argument.
- Learn interval scheduling and interval partitioning.
- Understand Huffman coding and greedy coin change (canonical coin systems).

## Topics
- Interval Scheduling (sort by finish time)
- Interval Partitioning (number of rooms -> max heap / sweep line)
- Huffman coding using priority queue
- Greedy coin change for canonical denominations

## Practice Problems
- LeetCode 435: Non-overlapping Intervals
- LeetCode 253: Meeting Rooms II (min rooms)
- Huffman coding practice and construction
