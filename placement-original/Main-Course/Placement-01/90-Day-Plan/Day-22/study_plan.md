# Day 22 Study Plan: Graphs

## Daily Schedule (9 hours total)

### Morning Session (3 hours)
- Topic: Graph basics & representations
  - Read adjacency list vs adjacency matrix, directed vs undirected graphs
  - Implement adjacency list and basic traversal methods

### Afternoon Session (3 hours)
- Topic: BFS & DFS, short path algorithms
  - Implement BFS, DFS iteratively and recursively
  - Implement Dijkstra's algorithm and test simple weighted graphs

### Evening Session (3 hours)
- Topic: MST & Topological sort
  - Implement Kruskal's algorithm using Union-Find
  - Implement Topological sort (Kahn's algorithm and DFS-based)
  - Add tests & visualizer quiet mode

## Learning Objectives
- Be able to model graphs and choose the right representation
- Understand traversal patterns and how to detect connectivity/paths
- Understand shortest path algorithms and MST approaches
- Be comfortable with topological sort and cycle detection in directed graphs

## Expected Outcomes
- Working implementation of core graph algorithms with demonstration classes
- Visualizer with optional quiet mode to run quickly in CI
