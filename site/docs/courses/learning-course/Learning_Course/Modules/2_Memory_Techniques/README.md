# 🧠 Module 2: Memory Techniques

## Core Memory Methods

### 1. Spaced Repetition
**Schedule:**
- Day 1: Learn
- Day 3: Review
- Day 7: Review
- Day 21: Review
- Day 60: Review

**Tools:** Anki, Quizlet

### 2. Active Recall
**Instead of:** Re-reading notes
**Do:** Close book, write what you remember
**Practice:** Flashcards, self-testing

### 3. Elaborative Interrogation
**Ask:** Why is this true?
**Example:** "Why does quicksort work?" → Explain partitioning logic

### 4. Memory Palace
**Steps:**
1. Choose familiar location
2. Create mental route
3. Place information at specific spots
4. Walk through route to recall

## Practical Techniques

### For Programming Concepts
- **Analogies:** Compare algorithms to real-world processes
- **Visualization:** Draw data structures
- **Code by hand:** Write without IDE

### For Technical Facts
- **Acronyms:** Create memorable abbreviations
- **Stories:** Link facts in narrative
- **Chunking:** Group related information

## Daily Implementation
- [ ] Create flashcards for new concepts
- [ ] Use spaced repetition app
- [ ] Practice active recall during study breaks
- [ ] Build memory palace for complex topics
