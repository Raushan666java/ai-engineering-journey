### दैनिक प्रविष्टि के निर्देश

1. **ध्यान के तुरंत बाद भरें** — अनुभव ताज़ा रहते हुए लिखें। देरी से विवरण धुंधले हो जाते हैं।
2. **ईमानदार रहें** — यह डायरी आपके लिए है। अच्छे या बुरे अनुभव, दोनों को ईमानदारी से लिखें।
3. **संक्षिप्त रहें** — प्रविष्टि में 5 मिनट से अधिक न लगाएँ।
4. **मूल्यांकन न करें** — अनुभव को "अच्छा" या "बुरा" न कहें। बस रिकॉर्ड करें कि क्या हुआ।
5. **नियमित रहें** — हर दिन भरें, चाहे ध्यान 5 मिनट का ही क्यों न हुआ हो।
6. **सातत्य महत्वपूर्ण है** — एक भी दिन छोड़ने से श्रृंखला टूटती है। यदि समय न हो, तो केवल 2 मिनट का ध्यान करें और डायरी भरें।
7. **शारीरिक संवेदनाओं पर ध्यान दें** — ध्यान के दौरान शरीर में क्या हो रहा है, इसे नोट करें — गर्मी, ठंडक, कंपन, या कोई अन्य संवेदना।
8. **सपने भी नोट करें** — यदि ध्यान के बाद या रात में कोई सपना याद रहे, तो उसे भी लिखें। सपने अवचेतन के द्वार हैं।

### Printable Templates Usage Guide

1. **Print on A4 paper** — All templates are designed for A4 size.
2. **Use a binder** — Print multiple copies and keep them in a ring binder.
3. **Carry the mini-diary** — Template 4 fits in a pocket for quick notes during the day.
4. **Luminate your favorites** — Laminate Template 5 (112 checklist) and use a marker to track progress.
5. **Customize** — Feel free to modify any template to suit your personal practice.

  /**
   * Calculate the day of year for deterministic quote selection
   */
  private getDayOfYear(date: Date): number {
    const start = new Date(date.getFullYear(), 0, 0);
    const diff = date.getTime() - start.getTime();
    return Math.floor(diff / (1000 * 60 * 60 * 24));
  }

  /**
   * Calculate current practice streak (consecutive days)
   */
  getCurrentStreak(): number {
    if (this.entries.length === 0) return 0;

    const sortedDates = [...new Set(this.entries.map(e => e.date))].sort();
    let streak = 1;
    const today = new Date().toISOString().split('T')[0];

    // Check if the last entry is today or yesterday
    const lastDate = sortedDates[sortedDates.length - 1];
    const lastDateObj = new Date(lastDate);
    const todayObj = new Date(today);
    const diffDays = Math.floor((todayObj.getTime() - lastDateObj.getTime()) / (86400000));

    if (diffDays > 1) return 0;

    for (let i = sortedDates.length - 1; i > 0; i--) {
      const current = new Date(sortedDates[i]);
      const previous = new Date(sortedDates[i - 1]);
      const diff = (current.getTime() - previous.getTime()) / 86400000;
      if (diff === 1) {
        streak++;
      } else {
        break;
      }
    }
    return streak;
  }

  /**
   * Calculate longest ever streak
   */
  getLongestStreak(): number {
    if (this.entries.length === 0) return 0;

    const sortedDates = [...new Set(this.entries.map(e => e.date))].sort();
    let maxStreak = 1;
    let currentStreak = 1;

    for (let i = 1; i < sortedDates.length; i++) {
      const current = new Date(sortedDates[i]);
      const previous = new Date(sortedDates[i - 1]);
      const diff = (current.getTime() - previous.getTime()) / 86400000;
      if (diff === 1) {
        currentStreak++;
        maxStreak = Math.max(maxStreak, currentStreak);
      } else {
        currentStreak = 1;
      }
    }
    return maxStreak;
  }

  /**
   * Get comprehensive practice statistics
   */
  getStats(): PracticeStats {
    const totalDays = this.entries.length;
    const totalMinutes = this.entries.reduce((sum, e) => sum + e.durationMinutes, 0);
    const techniquesTried = new Set(this.entries.map(e => e.techniqueNumber)).size;
    const techniquesMastered = this.techniques.filter(t => t.rating >= 4).length;

    const categoryCount: Record<string, number> = {};
    for (const tech of this.techniques) {
      if (tech.sessionCount > 0) {
        categoryCount[tech.category] = (categoryCount[tech.category] || 0) + 1;
      }
    }

    const bestTechniques = this.techniques
      .filter(t => t.sessionCount > 0 && t.rating > 0)
      .sort((a, b) => b.rating - a.rating)
      .slice(0, 5)
      .map(t => ({ number: t.number, name: t.name, rating: t.rating }));

    const avgConcentration = this.entries.length > 0
      ? this.entries.reduce((sum, e) => sum + e.concentration, 0) / this.entries.length
      : 0;

    const avgSatisfaction = this.entries.length > 0
      ? this.entries.reduce((sum, e) => sum + e.satisfaction, 0) / this.entries.length
      : 0;

    const consistencyScore = totalDays > 0
      ? Math.round((this.getCurrentStreak() / totalDays) * 100)
      : 0;

    // Mood improvement tracking
    const moodImprovements = this.entries.map(e =>
      e.postMeditationMind - e.preMeditationMind
    );
    const avgMoodImprovement = moodImprovements.length > 0
      ? moodImprovements.reduce((a, b) => a + b, 0) / moodImprovements.length
      : 0;

    return {
      totalDays,
      totalMinutes,
      averageMinutesPerDay: totalDays > 0
        ? Math.round(totalMinutes / totalDays)
        : 0,
      currentStreak: this.getCurrentStreak(),
      longestStreak: this.getLongestStreak(),
      techniquesTried,
      techniquesMastered,
      topCategories: Object.entries(categoryCount)
        .sort(([, a], [, b]) => b - a)
        .map(([category, count]) => ({ category, count })),
      bestTechniques,
      averageConcentration: Math.round(avgConcentration * 10) / 10,
      averageSatisfaction: Math.round(avgSatisfaction * 10) / 10,
      consistencyScore,
    };
  }

  /**
   * Generate a weekly review from daily entries
   */
  generateWeeklyReview(weekNumber: number, weekDays: DailyEntry[]): WeeklyReview {
    const concentrationAvg = weekDays.length > 0
      ? weekDays.reduce((sum, e) => sum + e.concentration, 0) / weekDays.length
      : 0;

    const techniqueRatings: Map<number, number> = new Map();
    for (const entry of weekDays) {
      const current = techniqueRatings.get(entry.techniqueNumber) || 0;
      techniqueRatings.set(entry.techniqueNumber, current + entry.satisfaction);
    }

    let bestTechnique = 0;
    let bestRating = 0;
    for (const [num, rating] of techniqueRatings) {
      if (rating > bestRating) {
        bestRating = rating;
        bestTechnique = num;
      }
    }

    // Find the most common obstacle
    const obstacleCount: Map<string, number> = new Map();
    for (const entry of weekDays) {
      for (const obstacle of entry.obstacles) {
        obstacleCount.set(obstacle, (obstacleCount.get(obstacle) || 0) + 1);
      }
    }
    let biggestObstacle = '';
    let maxCount = 0;
    for (const [obs, count] of obstacleCount) {
      if (count > maxCount) {
        maxCount = count;
        biggestObstacle = obs;
      }
    }

    const dates = weekDays.map(e => e.date).sort();
    const review: WeeklyReview = {
      weekNumber,
      startDate: dates[0] || '',
      endDate: dates[dates.length - 1] || '',
      daysPracticed: weekDays.length,
      totalMinutes: weekDays.reduce((sum, e) => sum + e.durationMinutes, 0),
      averageMinutes: weekDays.length > 0
        ? Math.round(weekDays.reduce((sum, e) => sum + e.durationMinutes, 0) / weekDays.length)
        : 0,
      concentrationAvg: Math.round(concentrationAvg * 10) / 10,
      techniquesUsed: [...new Set(weekDays.map(e => e.techniqueNumber))],
      bestTechnique,
      biggestObstacle,
      nextWeekGoal: '',
    };

    this.weeklyReviews.push(review);
    return review;
  }

  generateMonthlyProgress(

      e.postMeditationMind - e.preMeditationMind
    );
    const avgImprovement = improvements.length > 0
      ? improvements.reduce((a, b) => a + b, 0) / improvements.length
      : 0;

    const report: MonthlyProgress = {
      month,
      year,
      daysPracticed: monthDays.length,
      totalDays: new Date(year, this.getMonthIndex(month) + 1, 0).getDate(),
      averageDailyMinutes: monthDays.length > 0
        ? Math.round(monthDays.reduce((sum, e) => sum + e.durationMinutes, 0) / monthDays.length)
        : 0,
      newTechniques: techniquesThisMonth.size,
      techniquesWith3PlusSessions: techniques3Plus,
      deepSilenceCount,
      longestSession: maxSession,
      maxStreak: this.getLongestStreak(),
      chaptersRead: new Set(monthDays.filter(e => e.techniqueNumber)
        .map(e => Math.ceil(e.techniqueNumber / 6))).size,
      bestTechnique: this.techniques
        .filter(t => t.sessionCount > 0)
        .sort((a, b) => b.rating - a.rating)[0]?.number || 0,
      biggestChallenge: '',
      keyLearning: '',
      nextMonthGoals: goals,
      selfRating: 0,
      wellnessRating: 0,
      moodImprovement: Math.round(avgImprovement * 10) / 10,
    };

    this.monthlyProgress.push(report);
    return report;
  }

### सामान्य प्रश्न (साधना संबंधी)

**प्रश्न: क्या एक दिन में एक से अधिक विधि कर सकते हैं?**
उत्तर: हाँ, लेकिन ओशो की सलाह है कि एक समय में एक ही विधि को कम से कम 3 दिन लगातार करें, फिर बदलें।

**प्रश्न: ध्यान का सबसे अच्छा समय क्या है?**
उत्तर: सुबह 4-6 बजे (ब्रह्म मुहूर्त) सबसे अच्छा माना जाता है, लेकिन जो समय आप नियमित रूप से दे सकते हैं, वही सबसे अच्छा है।

**प्रश्न: क्या मैं एक ही विधि को बार-बार कर सकता हूँ?**
उत्तर: बिल्कुल। यदि कोई विधि आपको गहराई में ले जाती है, तो उसे तब तक करें जब तक वह स्वाभाविक रूप से छूट न जाए।

**प्रश्न: अगर ध्यान में कुछ अनुभव न हो तो क्या करें?**
उत्तर: ओशो कहते हैं — "कुछ न होना" भी एक अनुभव है। बस धैर्य रखें और नियमित रहें। फल अपने समय पर आता है।

**प्रश्न: क्या साथ में संगीत बजा सकते हैं?**
उत्तर: यह विधि पर निर्भर करता है। ध्वनि विधियों में बाहरी संगीत सहायक हो सकता है, लेकिन साक्षी विधियों में मौन बेहतर है।

**प्रश्न: ध्यान के दौरान नींद आए तो क्या करें?**
उत्तर: ओशो कहते हैं — यदि नींद आ रही है, तो सो जाएँ। लेकिन जागरूकता से सोएँ। धीरे-धीरे नींद और जागरण के बीच का अंतर मिट जाएगा।

**प्रश्न: क्या मैं चलते या काम करते हुए ध्यान कर सकता हूँ?**
उत्तर: हाँ, ओशो ने इस पर विशेष जोर दिया है। ध्यान को जीवन का अंग बनाना चाहिए, न कि जीवन से अलग।

**प्रश्न: कितने दिनों में परिणाम दिखने लगते हैं?**
उत्तर: यह व्यक्ति और विधि पर निर्भर करता है। कुछ को तुरंत अनुभव होता है, कुछ को महीनों लग सकते हैं। धैर्य रखें — कोई प्रतिस्पर्धा नहीं है।

**प्रश्न: क्या तंत्र ध्यान खतरनाक हो सकता है?**
उत्तर: ओशो कहते हैं — उचित मार्गदर्शन में तंत्र पूरी तरह सुरक्षित है। बिना गुरु के गहरी विधियाँ न करें।

**प्रश्न: एक दिन में कितने मिनट ध्यान करना चाहिए?**
उत्तर: शुरुआत में 15-20 मिनट पर्याप्त है। धीरे-धीरे बढ़ाकर 45-60 मिनट कर सकते हैं। गुणवत्ता महत्वपूर्ण है, मात्रा नहीं।
