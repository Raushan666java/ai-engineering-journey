# DAY 8: INTERFACES & EXCEPTIONS - STUDY PLAN

## 9-hour plan (Morning/Afternoon/Evening)

### Morning Session (9:00 - 12:00)
1. Basics of interfaces (read `InterfacesComplete.java`)
2. Multiple inheritance via interfaces & default/static methods
3. Functional interfaces & lambdas

### Afternoon Session (2:00 - 5:00)
1. Abstract classes (read `AbstractClassesComplete.java`)
2. Template Method pattern
3. Abstract class with fields & constructors

### Evening Session (7:00 - 10:00)
1. Exception handling guide (`ExceptionHandlingComplete.java`)
2. Try-with-resources, custom exceptions
3. LeetCode practice: `LargestNumber.java` and `SortCharactersByFrequency.java`
4. Practice problems: `Day8PracticeProblems.java`

---

## Goals for the Day
- Understand interface vs abstract classes
- Use functional interfaces and lambdas
- Handle exceptions correctly; choose checked vs unchecked appropriately
- Apply Observer and Strategy patterns using interfaces

---

## Study Tips
- Code every example by hand
- Use small test harnesses to run examples
- Practice lambda usage in collections
- Apply try-with-resources for all I/O code

---

**After completing this day you should be confident in using interfaces, functional interfaces and exception handling effectively.**
