# Learning How to Learn

> **Master the universal meta-skill: accelerate learning across every course in this repository.**
> 10 chapters · 130 Q&As · Practical techniques grounded in cognitive science.

---

## Course Overview

This course teaches you **how to learn anything** — from GATE CS theory to coding interviews to new frameworks. Every technique is demonstrated with worked examples from the 27+ courses in this repository.

You'll learn:
- How your brain encodes, stores, and retrieves information
- The 5 core learning techniques that outperform all others
- Memory systems that let you retain anything
- How to beat procrastination and build deep focus
- Domain-specific strategies for DSA, GATE, coding interviews, and new frameworks
- Meta-learning: how to build a lifelong learning system

---

## Prerequisites

- **Basic programming knowledge** (any language) — code examples use Java but concepts apply universally
- **Willingness to practice** — reading alone won't change your learning; you must **do** the exercises

## How to Read Each Chapter

Every chapter follows this structure:

```
Learning Objectives → Q&A Content → Chapter Summary → Exercises → Further Reading
```

- **Learning Objectives:** What you'll know after completing the chapter
- **Q&A Content:** Questions and answers with compilable code examples
- **Chapter Summary:** Key takeaways in 3–5 bullet points
- **Exercises:** Hands-on practice (use these — they're the most important part)
- **Further Reading:** Links to related chapters and courses
