## Traversal Techniques
- **DFS:** Inorder, Preorder, Postorder
- **BFS:** Level Order, Zigzag
- **Morris:** Space-optimized traversal

## Common Patterns
- **Recursion:** Most tree problems
- **Level Order BFS:** Queue-based traversal
- **DFS with Stack:** Iterative traversal
- **Parent Pointers:** LCA, Path problems
