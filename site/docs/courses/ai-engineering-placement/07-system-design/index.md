# 07 — System Design

## Overview

Learn to design scalable, reliable, and maintainable systems. Covers microservices, message queues, caching, database scaling, and real-world case studies including URL shortener, ChatGPT, and WhatsApp.

1. Read sub-chapters in order
2. For each: read theory → run code → review Q&A → take quiz → do exercises
3. Mark complete when all sub-chapters done
