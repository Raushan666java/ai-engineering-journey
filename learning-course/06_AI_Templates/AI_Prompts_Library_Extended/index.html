🤖 AI Prompts Library for Learning

Core Learning Prompts​

Concept Explanation Prompts​

Feynman Technique Assistant​

Act as a learning coach. I want to use the Feynman Technique to understand [CONCEPT].

First, let me explain the concept in simple terms:
[YOUR EXPLANATION]

Please:
1. Identify gaps or unclear parts in my explanation
2. Ask clarifying questions about confusing areas
3. Suggest better analogies or examples
4. Help me refine my understanding
5. Test my knowledge with follow-up questions

Simple Explanation Generator​

Explain [COMPLEX CONCEPT] using:
- Simple, everyday language (8th-grade level)
- Real-world analogies
- Step-by-step breakdown
- Visual descriptions
- Common examples

Make it so clear that a child could understand it.

Multi-Perspective Explanation​

Explain [CONCEPT] from these different perspectives:
1. Beginner (first time learning)
2. Practical (how it's used in real projects)
3. Technical (detailed implementation)
4. Interview (what employers want to know)
5. Teaching (how to explain to others)

Memory Enhancement Prompts​

Memory Palace Creator​

Help me create a memory palace for [TOPIC/LIST OF ITEMS].

Requirements:
- Use [FAMILIAR LOCATION] as the setting
- Create vivid, bizarre, memorable imagery
- Include action and emotion
- Connect items logically to locations
- Make it personally meaningful

Provide:
1. Detailed route through the location
2. Specific imagery for each item
3. Story connecting all elements
4. Memory triggers and associations

Mnemonic Generator​

Create memorable mnemonics for:
[LIST OF ITEMS TO REMEMBER]

Provide:
1. Acronyms using first letters
2. Rhyming phrases
3. Visual associations
4. Story-based mnemonics
5. Number-letter substitutions (if applicable)

Make them funny, bizarre, or personally meaningful for better retention.

Spaced Repetition Card Creator​

Create Anki flashcards for [TOPIC]. Format each as:

Q: [Question]
A: [Answer]

Requirements:
- One concept per card
- Clear, specific questions
- Concise but complete answers
- Include examples when helpful
- Use cloze deletion for complex information
- Create 10-15 cards covering key aspects

Focus on: [SPECIFIC AREAS TO EMPHASIZE]

Problem-Solving Prompts​

Custom Problem Generator​

Generate [NUMBER] practice problems for [TOPIC/SKILL].

Specifications:
- Difficulty level: [BEGINNER/INTERMEDIATE/ADVANCED]
- Focus areas: [SPECIFIC CONCEPTS]
- Problem types: [CODING/THEORETICAL/APPLICATION]
- Include solutions and explanations
- Gradually increase complexity
- Cover edge cases and common mistakes

For each problem, provide:
1. Clear problem statement
2. Input/output examples
3. Constraints and assumptions
4. Step-by-step solution
5. Time/space complexity analysis
6. Alternative approaches

Debugging Assistant​

I'm having trouble with this code/concept:
[PASTE CODE OR DESCRIBE PROBLEM]

Please help me:
1. Identify the specific issue
2. Explain why it's happening
3. Suggest multiple solutions
4. Explain the reasoning behind each solution
5. Help me understand the underlying concepts
6. Provide similar examples for practice

Guide me through the debugging process step-by-step.

Solution Optimizer​

I solved this problem: [PROBLEM DESCRIPTION]
My solution: [YOUR SOLUTION]

Please help me:
1. Analyze time and space complexity
2. Identify potential optimizations
3. Suggest alternative approaches
4. Point out edge cases I might have missed
5. Explain trade-offs between different solutions
6. Provide cleaner or more readable versions

Focus on helping me understand WHY each optimization works.

Create a personalized study plan for me:

Goals: [YOUR LEARNING OBJECTIVES]
Timeline: [AVAILABLE TIME PERIOD]

Available time per day: [HOURS]
Learning style preferences: [VISUAL/AUDITORY/KINESTHETIC]

Progress Analyzer​

Analyze my learning progress:

Data from past week:
- Topics studied: [LIST]
- Time spent: [HOURS PER TOPIC]
- Problems solved: [NUMBERS AND TYPES]
- Difficulty areas: [CHALLENGES FACED]
- Confidence levels: [SELF-ASSESSMENT]

Please:
1. Identify patterns in my learning
2. Suggest areas for improvement
3. Recommend focus areas for next week
4. Adjust study strategies if needed
5. Set realistic goals for upcoming period

Interview Preparation Prompts​

Mock Interview Conductor​

Conduct a mock technical interview for [POSITION TYPE].

Interview format:
1. Start with behavioral questions
2. Present coding problems of increasing difficulty
3. Ask follow-up questions about solutions
4. Discuss system design (if applicable)
5. Provide constructive feedback

After each response, provide:
- Feedback on communication clarity
- Technical accuracy assessment
- Suggestions for improvement
- Follow-up questions to test deeper understanding

Make it realistic but supportive.

Interview Question Generator​

Generate interview questions for [ROLE/COMPANY TYPE]:

Categories needed:
- Behavioral questions (5)
- Technical coding problems (3 easy, 3 medium, 2 hard)
- System design scenarios (2)
- Conceptual questions (5)

For each question, provide:
1. The question itself
2. What the interviewer is looking for
3. Good answer framework
4. Common mistakes to avoid
5. Follow-up questions they might ask

Suggest specific improvements with reasoning.

Prompt Optimization Tips​

Effective Prompt Structure​

[ROLE]: Act as [specific expert role]
[CONTEXT]: Given this situation/information
[TASK]: Please [specific action requested]
[FORMAT]: Provide response in [desired format]
[CONSTRAINTS]: Within these limitations
[EXAMPLES]: Similar to [reference examples]

Iterative Improvement​

Based on your previous response about [TOPIC], please:
1. Dive deeper into [SPECIFIC ASPECT]
2. Provide more examples of [CONCEPT]
3. Clarify the connection between [A] and [B]
4. Suggest practical applications
5. Address potential misconceptions

Continue building on our previous discussion.

Quality Control​

Before providing your final answer, please:
1. Double-check factual accuracy
2. Ensure logical consistency
3. Verify examples are correct
4. Consider alternative perspectives
5. Identify any assumptions made
6. Suggest ways to verify the information

Then provide your comprehensive response.

Usage Guidelines​

Prompt Customization​

  • Replace [BRACKETS] with your specific information
  • Adjust complexity level to match your needs
  • Combine prompts for comprehensive assistance
  • Iterate and refine based on results

Best Practices​

  • Be specific about your learning context
  • Provide relevant background information
  • Ask for explanations of AI reasoning
  • Request multiple approaches when helpful
  • Use follow-up questions for clarification

Ethical Considerations​

  • Use AI for learning, not cheating
  • Verify important information independently
  • Maintain critical thinking skills
  • Give credit when using AI assistance
  • Focus on understanding, not just answers
