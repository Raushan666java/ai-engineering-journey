# Technical Interview Preparation

## DSA Interview
- Review common patterns: Two pointers, Sliding window, BFS/DFS
- Practice explaining algorithm approach before coding
- Focus on time and space complexity analysis
- Practice writing clean, bug-free code

## Java Interview
- Be ready to explain OOP concepts with examples
- Know Collections framework internals
- Prepare for multithreading questions
- Practice implementing design patterns

## System Design Interview
- Follow structured approach:
  1. Requirements clarification
  2. High-level design
  3. Detailed component design
  4. Scaling and optimization
- Practice drawing clear diagrams

## DBMS Interview
- Practice writing complex SQL queries
- Understand indexing and query optimization
- Know normalization forms with examples
- Prepare for transaction and concurrency questions

## Mock Interview Schedule
- Week 1-4: DSA focus (2 mocks/week)
- Week 5-6: Java focus (2 mocks/week)
- Week 7-8: System Design focus (2 mocks/week)
- Week 9-10: Mixed topics (2 mocks/week)
- Week 11-12: Company-specific preparation
