# Artificial Intelligence & Machine Learning Syllabus

## AI Basics

- What is AI? Applications
- Search algorithms: DFS, BFS, A\*
- Knowledge representation: graphs, trees, logic
- Game playing: minimax, alpha-beta pruning, decision trees

## Machine Learning

- Supervised vs unsupervised learning
- Algorithms: linear/logistic regression, decision trees, random forests, KNN, SVM, K-means, Naive Bayes, PCA
- Evaluation metrics: accuracy, precision, recall, F1 score, ROC
- Cross-validation, overfitting, regularization
- ML pipeline: data preprocessing, feature engineering, model selection, training, evaluation, deployment
- Tools: Jupyter, scikit-learn, Pandas, NumPy, Matplotlib

## Generative AI (GenAI)

- Introduction: GenAI vs predictive AI, applications (chatbots, image generation, code completion)
- Key concepts: transformers, attention, pretrained models (GPT, BERT, Claude, Gemini), language vs foundation models, fine-tuning, prompt engineering
- Tools & frameworks: OpenAI, Hugging Face, LangChain, Ollama, LLaMA, Mistral, Google Vertex AI, Azure OpenAI, AWS Bedrock
- Prompt engineering: patterns, role-based, few-shot/zero-shot, chain-of-thought
