# Jenkins for DevOps Syllabus

- Introduction to Jenkins: CI/CD concepts
- Installation and setup
- Jenkins architecture: master, agents
- Jobs: freestyle, pipeline, multibranch
- Pipeline as code: Jenkinsfile syntax, stages, steps
- Plugins: installation, management, popular plugins
- Integrating with Git, GitHub, Docker, Kubernetes
- Build triggers: SCM polling, webhook, scheduled
- Credentials and secrets management
- Distributed builds: agents, nodes
- Monitoring and logging
- Security: user roles, matrix authorization, secrets
- Best practices: pipeline design, error handling, notifications
- Real-world scenarios: automated testing, deployment, rollback
