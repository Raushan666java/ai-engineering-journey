# 10. Community and Resources

## Official Resources

### Documentation
- **Laravel Documentation**: https://laravel.com/docs
  - Comprehensive, well-organized documentation
  - Updated with each release
  - Code examples and explanations
  - Available in multiple languages

### Laravel Website
- **Main Website**: https://laravel.com
  - Product information
  - Ecosystem overview
  - Partner directory
  - Release announcements

### Laravel Blog
- **Official Blog**: https://blog.laravel.com
  - Release announcements
  - Feature spotlights
  - Community highlights
  - Written by Taylor Otwell and the Laravel team

### Laravel News
- **Laravel News**: https://laravel-news.com
  - Daily Laravel news and tutorials
  - Package reviews
  - Job listings
  - Community tutorials and articles

## Learning Resources

### Laracasts
- **Website**: https://laracasts.com
- Video tutorial platform by Jeffrey Way
- Thousands of lessons on Laravel, PHP, and web development
- Series for beginners to advanced developers
- Forums for questions and discussions
- Free and premium content

### Laravel Podcast
- **Website**: https://laravelpodcast.com
- Hosted by Matt Stauffer
- Interviews with Laravel team members and community leaders
- Discussions about Laravel features and ecosystem
- Web development best practices

### Books
- **Laravel: Up & Running** by Matt Stauffer
- **Laravel Testing Decoded** by Jeffrey Way
- **Laravel Queues in Action** by Mohamed Said
- **Domain-Driven Design in Laravel** by Jesse Griffin
- **Laravel Beyond CRUD** by Freek Van der Herten and Brent Roose

## Contributing to Laravel

### Ways to Contribute
- **Code Contributions**: Submit pull requests
- **Documentation**: Improve or translate documentation
- **Bug Reports**: Submit issues on GitHub
- **Financial Support**: GitHub sponsors or Laravel Partners program
- **Community Support**: Help others in forums and chat

### Contribution Guidelines
- **Laravel Contribution Guide**: https://laravel.com/docs/contributions
- Follow coding style and standards
- Write tests for new features
- Submit pull requests to the correct branch

## Best Learning Methods
- Subscribe to Laravel News for daily updates
- Join the Laravel Discord for real-time help and discussions
- Watch Laracasts series to learn new features and techniques
- Follow key Laravel developers on Twitter
- Attend local Laravel meetups or online conferences
- Contribute to open-source Laravel packages
- Build and share your own Laravel packages
- Participate in forums by asking and answering questions
