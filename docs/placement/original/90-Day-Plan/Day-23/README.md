# Day 23: Advanced Graphs — Topological Sort, SCC, Bellman-Ford, Floyd-Warshall

## Overview
This day covers advanced graph algorithms and patterns:
- Topological sort (Kahn / DFS) and cycle detection in directed graphs
- Strongly connected components (Kosaraju's algorithm)
- Shortest paths with negative weights (Bellman-Ford)
- All pairs shortest paths (Floyd-Warshall)
