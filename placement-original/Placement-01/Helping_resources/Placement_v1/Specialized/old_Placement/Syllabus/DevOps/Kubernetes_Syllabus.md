# Kubernetes for DevOps Syllabus

- Kubernetes architecture: master, worker nodes, etcd, API server
- Pods: definition, multi-container pods, lifecycle
- Services: ClusterIP, NodePort, LoadBalancer, ExternalName
- Deployments: rolling updates, replica sets, scaling
- ConfigMaps & Secrets: configuration, sensitive data management
- Namespaces: resource isolation, multi-tenancy
- Ingress: HTTP routing, load balancing, SSL termination
- Persistent Volumes: storage abstraction, dynamic provisioning
- StatefulSets: stateful applications, ordered deployment
- DaemonSets: node-level services, system daemons
- Jobs & CronJobs: batch processing, scheduled tasks
- Helm: package manager, templating, chart management
- Monitoring: Prometheus, Grafana integration
- Logging: ELK stack, Fluentd
- Security: RBAC, Network Policies, Pod Security Policies
- Troubleshooting: kubectl, logs, events, metrics
