# Docker for DevOps Syllabus

- Introduction to containers and Docker
- Installing Docker and Docker Compose
- Docker architecture: daemon, client, registry
- Images: building, pulling, pushing, tagging
- Dockerfile: syntax, instructions, best practices
- Containers: running, stopping, removing, inspecting
- Volumes: data persistence, bind mounts, named volumes
- Networks: bridge, host, overlay, custom networks
- Docker Compose: multi-container orchestration
- Environment variables and secrets
- Logging and monitoring containers
- Security: image scanning, user namespaces, least privilege
- Troubleshooting: logs, exec, stats
- Integrating Docker with CI/CD pipelines
- Real-world scenarios: dockerizing applications, deploying microservices
