# ⌨️ VS Code — 100% Keyboard Workflow (Linux)

> Zero mouse • Zero trackpad • Keyboard only

---

## 🧭 Navigation (Files, Editors, UI)

```text
Ctrl + P              → Quick open file
Ctrl + Shift + P      → Command Palette (everything)
Ctrl + Tab            → Next editor
Ctrl + Shift + Tab    → Previous editor
Ctrl + 1 / 2 / 3      → Focus editor group
Ctrl + K, Ctrl + ←/→ → Move editor group
Ctrl + B              → Toggle sidebar
Ctrl + J              → Toggle panel
Ctrl + `              → Toggle terminal
Ctrl + \              → Split editor
Ctrl + W              → Close current editor
Ctrl + K, Ctrl + W    → Close all editors
Ctrl + K, Ctrl + O    → Open folder
```

---

## 📂 Explorer (Keyboard Only)

```text
Ctrl + Shift + E      → Focus Explorer

→                    → Expand folder
←                    → Collapse folder
Enter                → Open file
F2                   → Rename file
Delete               → Delete file
Ctrl + N              → New file
Ctrl + Shift + N      → New window
```

## ✏️ Editing (Power Mode)

